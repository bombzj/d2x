## 原生存档：格式与边界

来源：[docs/modules/SAVES.md](../modules/SAVES.md)。

自有PD2城镇宿主沿用原生PD2 D2S：v96头、固定段、校验和、Skills最大职业行数及原JM／jf／kf结构，默认目录`saves/pd2`。不写D2X私有标记，也不把原生档转成私有格式；此前带`D2XPD2`头标记的试验档明确拒绝，须使用原生角色副本或重新建角，不静默迁移。原版与PD2目录、资源配置保持隔离，载入仍须通过完整内容与边界校验。

完整物品逐件保留原format；format<102使用9位属性ID，102及以后使用10位，终止符分别为511／1023。format<103使用MPQ的S12列，103使用S13列，104及以后使用当前Save列；compact仍用当前列。新物品采用104，旧101与新104可以同档共存。磁盘读写、宿主网络投影与客户端读取共用`content/pd2/item_encoding.hpp`的格式选择；独立网络ItemStat增量仍为9位。职业库存／个人仓库／方块尺寸取当前Inventory表。

当前核心SHA256 `17d5fb1b049d8076226d27295487b49c8b5f2629553c193a01aa1e3d8afaba57`的保存RVA `0x39A510`、读取`0x39AD40`确认：kf之后可有`70 64 82 0A`扩展头，依次为su（3+count×2，count≤128）、bk（6）、st（64）、ht（3）、xp（3）、hc（130字节）。解析检查完整顺序、版本、长度及尾部；内容作为原生元数据保留在`nativeSaveSections`固定段之后，保存时原样写回，不把未知含义的字段重置或伪造。无扩展的旧格式正文也由原生读取入口接受，新建角色可使用该正文。共享文件不导入；扩展状态仍未成为自有宿主可写玩法，额外热键的物品来源与复杂库存变更组合尚未完整认证。

`--load`、名册、租约、备份和正常退局保存复用既有流程；使用原档副本验证，未支持字段、版本或内容明确拒绝，不回退重读。TCP/IP仍受既有小于8192字节的传输上限约束；全部品质、扩展热键、复杂装备及原生客户端网络传档兼容仍需覆盖。


运行态PD2技能、佣兵攻击和地图程序不因存档可读而获得实现；技能宿主已接入普通五幕区域及七职业差异程序，完整技能组合仍待验收，详见[PD2宿主边界](../architecture/PD2_COMPATIBILITY.md#自有pd2城镇宿主)。[存档模块](../modules/SAVES.md)未明确标注PD2的原格式说明仍指原版LoD路径。
