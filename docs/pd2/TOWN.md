# PD2城镇与经济差异

本页维护NPC服务和经济差异；地图Gheed价格已核当前41d49，其余NPC服务地址仍限定17d5规则基线，版本身份见[版本与证据](BUILDS.md)。公共交互／资格归[NPC交易](../gameplay/npc/TRADE.md)，物品加工归[物品](ITEMS.md)。

## 价格与维修

D2Common ordinal10107的原价格入口为RVA0x29D60，17d5的调用位移0x29D7E被核心主表替换到RVA0x3A18E0→0x383060→0x2E8140；旧核心对应0x39F5B0→0x380D00→0x2E6490。末项是完整改写的价格函数，不能解释为回落未修改原函数。

显式PD2差异包括每件维修折后价格上限250000。当前41d49的385020先经37C560检查Level137–210，再检查NPC147及价格操作2；满足时读玩家属性87，以ECX=1000000、EDX=100、XMM2=100−reducedprices调用37C510，否则委托2E8140。该分支没有0..99减价钳制；37C510沿double乘后除、只夹正向INT_MAX，返回DWORD原位型。17d5对应383060／37A740／37A6F0，不能把383060当作41d49价格入口。

地图Gheed的本地权威扣费和本地／远程客户端报价共用`gameplay/items/pd2/pricing.hpp`，城镇赌博继续沿原普通价格函数。客户端推算装备折扣时不读取未鉴定护符的隐藏属性；原ITEMS_IsCharmUsable调用ITEMS_CheckRequirements，后者要求鉴定，不能让不生效的未知护符阻塞整张报价。缺少其他必要输入仍保留未知，全部装备、词缀、任务减价与费用组合尚未认证；客户端报价不替代服务端扣费。

## NPC与佣兵服务

C2S32／33／34／35／36／38／61／62沿既有长度。17d5的33回调0x393380（旧0x391010）检查后委托原D2Game出售RVA0xCF570，并非直接计价函数。36的0x394EA0与62的0x394EE0共用资格0x394E60，再委托原D2Game hire0xD0060／revive0xCFB90；委托关系不证明全部佣兵资格已恢复。39长度为12、回调0x395A90返回0，不能发送原版5字节治疗消息。

普通NPC服务与任务奖励保留确认会话、NPC身份、任务字段及服务器资源变化的裁定。自有宿主复用`src/server/systems/{npc,merchant,crafting}`及对应hosting准备，具体资格继续由各域持有。佣兵装备／服务与战斗程序分别维护，见[怪物与伙伴](MONSTERS.md#召唤实体与伙伴)。

自有宿主的Npc／Towner／NpcStationary、JarJar与NpcOutOfTown消费当前MPQ与DS1准备的公共NPC规则；消费者包含杰海因／守卫、Ormus／Alkor、Cain／Anya及原459／461／543标记的MapAI转交，覆盖和原版依据见[NPC交互](../gameplay/npc/INTERACTIONS.md#宿主npc移动与地图动作)。这些原版剧情缓冲不扩展为PD2额外MapAI来源。既有PD2 ScriptedNpc及场景控制器仍优先使用其专用程序；PD2额外任务、原版完整演出时序和多人组合仍未据此认证。

CN商店原图布局的格顶为42（原版62），第二按钮使用buysellbtn/frame4出售图形，绘制与命中共用布局；依据为目标buysell.dc6和当前交互消费者。货架数量是具体会话状态，不作为固定商店规则。收到维修回执不等于已证明实际恢复耐久。

## CN专属存储与金币

此项限定mdll1 SHA-256 `6d6b8bf38e1a47a172b18715b5d4d89542332b4f61264efc3e61602e9d43e90a`，不归为ProjectDiablo核心共享仓库功能。9D/function19由mdll1的0x1E060/case1→0x1DFD0读取packet+0x18 DWORD，写玩家扩展+0x42；m_getZYLPD2SharedGold（0x14BB0）读取该值，0x14E70／0x14F90用于显示和金额输入，0x227D0初始化发送，0x2D9D0保存。

0x1E670的共享存入／取出分支0x25／0x26只返回成功而未执行转账；参考CN BH的US_PUTGOLD／US_TAKEGOLD也为空操作。0xC370／0xC420的仓库页链表操作不能当作金币转账。D2X独立同步并只读显示19的余额，保留材料初始化屏障，不把共享余额写入个人goldbank，不发送虚构转账。完整分页／材料协议由[CN存储取证](../resources/PD2_CN_DLL_ANALYSIS.md#个人与账号共享仓库的范围)维护，本地宿主不实现共享／材料仓库。

## 待核实与未完成

完整五幕、佣兵资格、任务奖励、全部价目／减价／实际维修、赌博与多人服务组合尚未完整核对。扩展预设区域已允许管理旅行，范围见[地图基线](MAPS.md#普通五幕与扩展区域)；这不代表其中的特殊经济规则已接入自有宿主。失败回执、服务器拒绝及未知输入保留真实结果。
