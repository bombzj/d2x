# PD2地图物品与词缀程序

本页负责地图物品→实例→人口／单位属性→掉落的调用链。目标身份沿用[版本与证据](BUILDS.md)，布局及区域索引见[地图](MAPS.md)。下文“接入”指存在对应的内容准备、权威执行或协议消费者；普通开图路径不代表全部地图程序已完成。

## 内容与实例

`src/content/pd2/map_data.cpp`从当前Misc.pSpell12准备全部物品的len、missiletype及原物品记录索引，路由来自ItemStatCost.Divide，状态来自States.map／198。玩法只接收`gameplay/maps/pd2`的纯值，不读取MPQ或执行DLL。

`src/server/systems/travel/pd2/maps.cpp`的普通入口检查Harrogath、地狱、等级80及古代人任务完成资格；资格例外、PvP和专属控制器仍拒绝。当前核心`0x3810A0`读取任务槽0x27的bit0：包装器`0x30A800`链接配套Common ordinal10174／RVA0x2D0F0，直接读取`quest*16+bit`，不执行编号加一；该槽是RiteOfPassage／39，不是EveOfDestruction／40。先冻结物品实际原生属性及revision，再用公共World异步准备区域；准备或程序不满足时不消耗地图。成功才提交消耗、真实门户规则和两端房间保留，并用55广播最多24项**原始**属性及门户GUID／类型、区域、品质、原物品索引，不能广播转换后的清单。已进入第五幕的玩家随开门事务接收报告；中途加入／随后来到第五幕的玩家由Travel补发，接收凭据只在可靠事实接受后发布。

当前一个游戏保留一份开图上下文，目标及后续原出口的区域准备共享该不可变实例。已有管理旅行区域不能直接重新绑定；重复开图／回收尚未完成。Travel持有异步开图待办，加载期间自动续办同一物品revision及原玩家／区域代次，不要求客户端再次使用；提交前重新检查归属、资格和物品版本，失效不扣物品。实例和临时来源不写入D2S，物品仍使用原PD2格式，不迁移旧档。

DRLG的邻房预载也必须传递实例：`world/rooms.cpp`从已准备区域或实际邻房取得同一上下文，再准备扩展子区域；原五幕及城镇不继承它。出口命令与提前预载不能各自产生一份地图身份，否则第二层会因上下文冲突拒绝进入。子层重新使用原物品属性，地图状态不重复叠加。

重复开图不能直接解释为允许同房多实例：当前核心`0x3810A0`首先检查Game+0x1DF4，正数且不为0x28即拒绝；普通开图在末尾至少写为10。该字段还驱动随机／专属事件，不是单纯的门户数量。后续回收必须核实事件结束对该字段、区域及门户的共同清理，不能仅删除D2X的一份实例指针就放行下一张图。

## 路由和单位属性

依据当前核心RVA `0x3810A0`、`0x388FD0`、`0x389040`、`0x388A40`；消费者为`property_program.cpp`、`attributes/pd2/map_values.cpp`、`effects/pd2/map_state.cpp`。

| Divide | 执行 |
| --- | --- |
| 0 | 不进入单位列表；500的存在单独表示强制事件 |
| 1024 | 原ID及参数进入怪物列表，不能当作24 |
| 其他小于1000 | 余数为怪物属性ID |
| 1000–1999 | 余数为玩家属性ID |
| 2000–2999 | 余数为全局程序号，保留参数及值 |
| 3000–3999 | 暂存原属性，最后追加怪物列表；432–436在单位上采样物理伤害 |

普通怪物属性仅给MonStats.Align为零的单位；独立的破免分支仍检查全部怪物。数值与装备、技能共用原生StatList及事件注册。怪物与玩家均使用CombatEffectSet的真实状态198；先填满原列表，再一次合并入单位，不能先发布空列表再逐项模拟装备。

怪物出生候选同时携带待发布效果，ActorPublication与Effects共同复验／提交；带物品光环的混合出生也继承该初始清单。当前States.map的plrstaydeath、monstaydeath、bossstaydeath均空白，按公共死亡流程撤销数值及状态位，不保留常驻尸体词缀。`stageDamageStates`在撤销前冻结PD2死亡掉落所需的FullStats；后续异步掉落读取此快照，不能为获得额外TC而将效果继续挂在尸体上。休眠重建从实例重新准备状态，压缩记录仍不增加存档字段。状态／掉落与原DLL的完整逐帧顺序仍待核对。

432–436分别生成闪电、冰冷、火焰、毒、魔法最小／最大伤害。百分比采用有符号float转换，物理基数采用无符号转换，先除100再乘。最小值零写1；最大值及长度最后写回。冰冷／毒长度为非零低WORD参数，否则25／125。同键写入覆盖，不能重复相加。

怪物目标76按无符号`maxhp + (maxhp / 100) * value`直接改基础最大生命，超过INT32_MAX封顶，并写432=1标记；玩家76仍走正常属性求值。其余普通输入零按原程序写1。369虽名map_defense，当前描述是StrCorruptNum且无StatOp；保留原ID，不能据名称添加防御百分比。

玩家进入／离开、出口、门户／传送点、管理旅行、跨区传送及复活，在人物事务中准备地图来源与资源上限，再发布位置。离图撤销来源；同一实例不重复叠加。

## 全局程序

| 号 | 规则及消费者 |
| --- | --- |
| 0 | 人口准备前，密度乘`1 + uint32(value) / 100.f` |
| 1 | 改MonReg区域等级；据此准备怪物战斗数值，并传递权威掉落等级 |
| 2 | 稀有／精英数量乘上述比例，保留BYTE窄化 |
| 3 | 加原生怪物类、rarity=1；已有13种时覆盖末项 |
| 4 | Skirmish密度／稀有数量乘`value / 100.f`；追加76／25／329／331／330／332／357／493，死亡程序另读493 |
| 5 | `0x38A000→0x36FAF0`对原预设地图首领及类1044再调用一次原出生程序；值只判正数，不作概率。人口游标区分原DS1身份和额外调用 |
| 6 | `0x3709E0`创建后按独立CRT百分比调用`0x3632D0`自动腐化属性程序 |
| 10 | `0x388A40`要求首个程序10的value等于区域且低WORD非零，读取基础抗性，按原CMOVLE链依次写火／冰／电／毒／物理／魔法调整；保留32位运算及跨通道继承，不自行改为85破免算法 |
| 11 | 创建后先过原IsSocketable再抽CRT百分比；主ItemTypes检查后，n2Handed底材抽2–4，否则1–2，使用物品的PD2单位随机，再受底材／等级／尺寸上限约束 |
| 12 | 273追加怪物来源；死亡时按百分比再执行一次原TC |
| 13 | 创建前CRT百分比设置原ALWAYSETH语义；不合资格的底材忽略标志，保留自然无形掷数 |
| 14 | 追加76=100及276=treacherous；耳朵配方的职业物品概率仍由原279–285属性执行，不按treacherous名称另造奖励 |
| 7／8／9／15 | 字段／路由已识别，首领技能板、腐化暗金、材料／珠宝、宝藏等后继执行未形成完整消费者，开图拒绝；不能据名称发奖 |

0–4及12／14依据`0x389510`。特殊地图、随机／强制事件和PvP需独立控制器，普通属性程序不能替代。

## 地图掉落

依据`0x378660→0x377DE0`。`MapLootRules`以原生MonStats类967（当前TCStartDontUseOrChange）的正常TC为锚，按原代码偏移链接当前TreasureClassEx；候选、权重及参数仍读MPQ。地图首领资格来自六组原核心身份集合，不等同于MonStats.boss或Unique等级。

| 单位属性 | 原TC偏移／程序 |
| --- | --- |
| 494／495／496／497 | +982／983／984／985：首饰、武器、护甲、合成材料 |
| 502／506 | +986／988：护身符、珠宝 |
| 279／280／281／285／282／283／284 | +1114／1129／1108／1139／1100／1091／1095，按此顺序处理职业物品 |
| 273 | 百分比重跑本体TC，不转换成MF |
| 493 | 正数时普通怪物多一次本体TC；地图首领用25%门槛并保留额外随机调用。非首领的分类掉落阈值乘2 |

小弟标记排除上述额外掉落。494–497及502／506无属性也掷数；职业物品仅正数时掷数。152／153、164／165、171／172、186／187及197–199另有本体TC调用。额外TC与后继抽取交错使用同一怪物随机；内容侧合并各次唯一物品占用，权威只提交一次结果。

自动腐化和无形／孔数另用CRT及物品随机。掉落准备捕获期望CRT，安装时复验并连同候选结果更新，背压不再次掷数。`applyPd2AutomaticCorruption`也供方块破坏产生的新稀有物品使用：扫描当前CubeMain阈值并忽略属性chance，保持当前物品身份；它不是带材料的手动WSS操作。

地图词缀额外TC已有消费者；`0x377DE0`前半段全局稀有材料、特殊品质地图、首领／事件奖励及全部随机交错仍未齐，不能宣称完整掉落等价。

## 未完成边界
