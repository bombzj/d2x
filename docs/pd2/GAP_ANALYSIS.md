# PD2 方向未完成功能分析

> 基于 `docs/pd2/` 各分册与 `BASELINE.md` 整理，记录当前实现与 PD2 目标之间的差距。

## P0 — 基础正确性（影响大量数值/随机/存档）

| 缺口 | 说明 |
|------|------|
| 全库函数语义闭合 | 当前核心只有定点分析，无与旧版 20,196 函数等量对应的完整契约；共享原生绑定、随机、百分比、属性、事件辅助函数未闭合 |
| 战斗种子/吸血/关键数值 | 所有 critical/vampirism 调用者、种子来源、出生/接触采样交错、失败重试与提交边界未验证 |
| 数值消费端有符号/浮点/溢出边界 | 未逐项核对 |

## 其他缺口

- **Quick Cast／技能栏**：PD2模式快速施法与绑定技能栏统一由Ctrl+Z菜单的Quick Cast设置控制，提交施放后延迟恢复原手技能。引导、目标版本的手位恢复、充能组合及原生技能栏布局仍待核对。见[快速施法](CLIENT_INTEGRATION.md#客户端接入快速施法)。
- **原生 PD2 客户端互通**：未认证
- **新账号注册**：未重测
- **CN 无窗口模式/房间详情**：未开放
- **天梯/资料/成员肖像/中文消息编码**：待核实

## 跨模块共性缺口

1. **全库函数覆盖**：仅定点分析，无完整语义闭合
2. **多人交错验证**：随机轨迹、同帧排序、背压、失败恢复在多数战斗/地图/技能功能中未验证
3. **像素级验收**：几乎所有视觉功能缺少原客户端逐像素对照
4. **Boss 场景完整性**：多个 Boss 专用分支已接入但完整场景待原版对照
5. **存档/恢复**：复杂物品存取、Iron Golem 材料、跨角色与 HC 持久化未经验证
