# 事件与延迟执行逐函数说明

本册默认核心SHA-256为`17d5fb1b049d8076226d27295487b49c8b5f2629553c193a01aa1e3d8afaba57`，ImageBase=0x10000000，地址为RVA。事件号、装备事件编号与网络包号是不同命名空间。原定点导出位于reference/pd2-cn-analysis/town-queries；说明只依据静态函数体，不认证全部运行时交错。

## 36AED0 打包目标并登记延迟物品事件

**定位与用途。** 范围36AED0–36AF1D，证据`pd2-item-cast-schedule/0x1036aed0.json`。把未来执行所需的事件编号、目标类型和GUID存入事件7，并指定36AE60为回调；自身不施法、不改伤害。

**ABI。** ECX是游戏上下文；EDX原样透传给3166D0，作为事件所属单位。三个栈输入依次为到期帧、事件编号（只取低字节）、可空目标；RET 12。反编译签名漏掉ECX／EDX，不能据它把该函数当无所属单位的全局定时器。

**打包分支。** 初始化编码为事件编号低字节、GUID为0。目标为空时保持这两个初值；目标存在且unitType为3或无符号>=6时，将编码OR FF00，GUID仍0；其他类型取目标+0C的GUID，将类型低字节左移8后OR进编码。

**登记调用。** 3166D0接收ECX=原游戏、EDX=原所属单位，栈为`7, 到期帧, 36AE60, 编码, GUID`。本函数不加4帧或5帧，期限由调用者预先决定；也不在此检查所属单位／游戏指针、已有同类事件或重复登记。

**重点。** 类型FF是“回到自身”的特殊标记，不是空目标。空目标编码为类型0、GUID0，回调将保留空目标。登记只保存身份而非目标指针，因此到期时必须重新解析；目标是否仍存在不能在登记时一次性决定。

**副作用与未知。** 事件插入及同帧排序属于3166D0真实目标；本体无随机。编码只保存事件编号低8位，不能把超255的输入当独立事件。不能从此函数单独推导原MonsterModifier队列对重复、删除和线程的全部保证。

## 36AE60 还原延迟目标并触发物品事件

**定位与用途。** 36AE60–36AECF，证据`pd2-item-events-runtime/0x1036ae60.json`。消费36AED0登记的目标身份，转入347670物品事件分派；不自行决定触发概率或替代技能。

**ABI。** ECX=游戏、EDX=所属单位；三个栈参数中的第一个在本体未读取，第二个为打包编码，第三个为目标GUID；RET 12。不能把未读参数推断为不存在，也不将其猜成帧数参与逻辑。

**执行顺序。** 游戏或单位为空退出；单位首DWORD无符号>=6退出。编码低8位为事件号，次低8位为目标类型；事件号FF退出。目标类型FF时直接调用347670，参数依次为所属单位、游戏、事件号、所属单位、0。

普通目标类型分支先令目标为空。只有GUID非零时才调用39F4C0，传ECX=游戏、EDX=GUID、栈参数=类型；其返回值作为目标。随后无论找到与否调用347670(所属单位,游戏,事件号,目标或空,0)。未对非FF类型做额外0..5检查，依赖查找器及登记输入。

**关键区别。** GUID0不会查找，因此真实身份0是否可用不能在这里假设；查找失败保持空目标，不回自身。相反，类型FF完全忽略GUID并强制自身。事件号FF直接不分派。注册时的目标不存在与触发时目标消失可以得到相同空指针，但不能与自身路径合并。

**副作用与边界。** 347670可能触发技能、属性和后续事件，本体没有独立随机或属性写入。原生概率、施法资格、装备采样和防递归归下游，不因回调调用成功就认证整个装备触发完成。D2X应保存类型／GUID并在执行时重新查身份，不能跨帧保存原指针或把空目标替换为自己。
