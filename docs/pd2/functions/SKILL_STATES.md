# 技能状态逐函数说明

默认核心身份与地址口径沿[版本表](../BUILDS.md)。以下地址均为核心RVA；桥接安装与实际函数体分别核实，不把相近地址当跨版本对应。

## 306960 狂乱完整等级按层数缩放

**版本与ABI。** 17d5范围306960–306BA3；41d49实际对应306AF0，桥接3A5DE0。四个栈参数为单位、游戏、技能ID、等级，RET16；成功返回1，拒绝返回0。17d5桥接3A3A00从EBX和三个原栈参数构造这组输入；两处D2Game安装位移2966F／296B0均在Do009，不含Do109。

**前置条件。** 单位与游戏非空，37A340的Skills记录有效，并要求30DE80取得已用技能、3094D0取得其数据；AuraState必须在States范围内。先用完整技能等级求AuraLenCalc并加当前游戏帧，再查询原状态；不存在则分配带到期事件的状态列表，分配失败返回0。

**写入顺序。** 刷新到期帧并登记RemoveState；读取列表属性169并加1；在完整等级求Skills+144的Calc4，取两者的有符号最小值为层数。写169为层数、351为实际技能等级。依次读取六项AuraStat，编号有效才求完整等级对应AuraStatCalc；以37A6F0计算`value * count / uint32(maximum)`，分母至少1，再写属性，包括零结果。68另写同值至69。最后刷新该单位被动技能。

**边界与副作用。** Calc4为零时不补成等级；负上限也不改成正数。列表到期、分配、状态位、属性和被动刷新均为副作用，函数不直接掷随机；公式自身的全部输入依赖须沿调用者分析。当前资源的147 Frenzy与152 Berserk均使用Do009，怪物Do109保留原函数。

## 36C020 PD2状态列表挂载

**版本与ABI。** 17d5范围36C020–36C754，41d49实际对应36D940。一个栈参数为D2Curse描述符，返回列表指针或空。描述符包含来源、目标、技能、等级、时长、第一属性和值、状态及移除回调；本体会修改时长和第一属性值。证据为`town-queries/pd2-status-callbacks`及`town-queries/current-41d/curse-audit`。

**受理。** 目标和States记录必须存在。怪物要求有效MonStats／MonStats2，拒绝NPC及无ISATT资格；特殊状态58／60还经身份／怪物集合等条件拒绝，具体集合不由数值分支推断。玩家间state60另有拒绝。通过30C4A0读取Curse标志。

**数值顺序。** state89独立读取目标109及504；随后Curse状态除196外再走同组分支。109非零时计算`duration * (100-resistance) / 100`；504非零且第一属性非零时计算`primary * (100-effectiveness) / 100`。玩家两项大于75时各自截75，其他单位不封顶。均调用37A6F0，缩放后为零立即返回空；原始零且没有缩放不拒绝。若89也标为Curse，两个分支顺序执行。

**列表与分配。** Curse分支按来源max_curses+1及目标现有列表的curse_slots维护容量，扫描顺序、有限期限及同状态列表分别参与选择；196还触发移除和魔法伤害后继，不能只解释为普通覆盖。非Curse按状态查询。匹配技能／等级的既有列表可复用，原始期限非零才续期；较低等级可以被拒绝，其余按原选择移除后分配。新列表写状态、技能／等级、首属性和槽数，按描述符回调或原默认回调登记。完整列表／AI准入契约仍需分别核调用者，数值分支不证明整函数全部对应。

**到期与安装。** 非零时长加游戏帧并登记事件；负值按32位有符号原生事件帧消费，不先转成新的永久状态。17d5的39F370桥接由七处指定原Game CALL和核心直接消费者使用，并非原Game挂载函数的全局替换。未安装的内视、Clay Golem及神殿调用点不据同名原函数扩大规则范围。
