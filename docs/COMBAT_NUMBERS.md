# 战斗数值

本轮按运行时 MPQ 的 `Properties.txt`、`ItemStatCost.txt`、装备基础表、`CharStats.txt`、`DifficultyLevels.txt` 和怪物三难度表取值。`reference/d2moo/source/D2Common/src/Items/ItemMods.cpp` 用于核对属性函数，`reference/d2moo/source/D2Game/src/UNIT/SUnitDmg.cpp` 用于核对物理增伤、抗性、减伤、吸收与中毒单位。玩法层只消费内容层类型化的属性，不读取 MPQ 或物品展示文本。

## 入口与顺序

- `content/item_properties.cpp` 标出需要在生成实例时掷值的原属性函数；`content/equipment_modifiers.cpp` 和 `content/equipment_combat.cpp` 按原行、掷值及物品归属生成角色与逐武器修正。未知函数不猜效果。
- `gameplay/character/attributes.cpp` 由职业、等级、已分配点、有效装备和限时效果统一派生资源、命中、防御和抗性；`gameplay/items/equipment_stats.cpp` 派生每把武器的定点物理伤害、护甲和盾牌格挡。失效装备不参与修正。
- `gameplay/combat/weapon_elements.cpp` 在普通近战命中或箭矢／投掷发射时掷元素附伤、毒素和致命一击；即时元素范围与角色面板共用 `attackElementRanges`。弹体保留发射快照；`combat.cpp` 对每种伤害查怪物对应抗性。持续毒素在模拟帧中结算，死亡仍走同一个经验与掉落入口。
- `gameplay/combat/damage_resolution.cpp` 将来袭伤害转成 1/256 生命单位，按固定减伤、抗性、百分比吸收和固定吸收顺序结算。四种元素抗性先应用当前难度的 MPQ 惩罚，普通上限 75%，加上限属性最多 95%；物理抗性最高 50%。冰冷和毒素持续时间另行受抗性、免冰冻与毒素长度修正影响。
- `gameplay/combat/stat_modifiers.hpp` 是物品、技能、怪物、祭坛及环境效果共用的数值载体。`gameplay/effects/state.*` 以受影响单位的容器、独立来源、原状态 ID 与实例句柄管理状态；冰封装甲已接入，开始／替换／到期／死亡移除时重算派生值，生命周期和扩展入口见 [技能](SKILLS.md#状态效果系统)。需要具体技能、怪物或祭坛施加的效果仍须逐个核对触发条件后接入。

角色面板显示已经参与当前结算的生命、法力、耐力、命中、防御、格挡、四抗、物理／魔法抗性、固定减伤及部分持续状态修正。`invchar.dc6` 的两组伤害／命中框分别对应左右技能图标，依据 [Blizzard 角色面板说明](https://classic.battle.net/diablo2exp/basics/characters.shtml)：普通攻击显示当前武器物理伤害及即时元素附伤，投掷显示投掷基础值，已接入原 MPQ 的火弹、火球、冰霜新星显示与实际施法共用的技能等级／协同伤害；无需命中检定的法术留空命中率。传送、取消召唤与无法用固定伤害表示的静电力场留空伤害。旋风、跳跃攻击、战嗥等未实现技能留空，演示参数及普通攻击替代已删除。面板的物理范围使用原角色面板的整数呈现方式；毒素属于持续伤害，不加进即时范围。命名管道 `status.combat` 暴露每把武器的物理伤害、各类元素范围和其它已解析修正，方便验收。

## 武器属性加成与本轮确认

TXT 字段名由 `DataTable` 统一按 ASCII 忽略大小写匹配，保留原列顺序、重复列、单元格和行号。当前 MPQ 使用 `StrBonus`／`DexBonus`，D2MOO `ItemsTbls.cpp` 的字段绑定使用小写；此前严格匹配导致武器两项系数被遗漏。物理伤害按 `SUnitDmg.cpp::SUNITDMG_ApplyDamageBonuses` 的武器系数乘角色属性／100 纳入百分比增伤，定点精度为 1/256，面板取整数。

Windows 运行中通过角色面板加点：手斧原基础 3–6、力量系数 100；力量 30 时实际 3.8984375–7.796875，面板 3–7，力量 35 时实际 4.046875–8.09765625，面板 4–8。单点提升未跨整数时面板可以保持原整数，实际伤害仍更新。此证据覆盖派生与面板，不等同于所有技能和战斗规则已完成。

## 新增效果与边界

共同属性解析保留 ItemStatCost stat/layer、原值和按等级派生值。未鉴定、失效或非当前武器组装备不贡献数值；背包护身符经共用鉴定／等级／职业／属性需求及破损、NOEQUIP 检查后参与，箱内／方块内不参与。护身符本轮仅核对源码链，未运行比对数值，FHR 等无消费者的字段不视为完成，详见 [护身符核对](ITEM_COMPLETION.md#护身符核对2026-09-26)。武器自身增强伤害先乘基础伤害，再加武器固定伤害；角色／其它装备增伤在后，投掷使用同一顺序。劣质物品的 75% 基础伤害／防御与三分之一最大耐久已接入，需求百分比、额外堆叠、无法破坏与最大耐久修正由库存共用。

- 生命／法力吸取使用实际物理伤害、MonStats 三难度 Drain 和 DifficultyLevels 分母，武器上的吸取只随该武器攻击。
- 压碎性打击按目标当前生命及普通／首领类别结算，远程减半，正物抗减免；撕裂伤口使用原等级分段与 200 帧持续时间。中毒／撕裂期间停止怪物自然回复。
- 恢复生命、法力恢复速度、击杀回复已经有实际消费者；补充投掷数量、修复耐久由原属性速率驱动，破损物品不自动修复。
- MF 与金币加成进入实际怪物／物体掉落；物品降价作用购买、赌博与修理。未知 TC 条目只暂缓自身。
- 全技能、职业、技能树、单技能、非本职业技能加成进入等级查询；能否正确施放仍取决于具体技能是否已实现。固定套装分级／整体加成已接件数查询，变量条件加成及其余 add func 仍缺。
- 装备 `passive_cold_mastery` 进入已接入冰系法术的伤害范围，`passive_cold_pierce` 与冰冷支配相加后降低非免疫怪物的有效冷抗。冰封球每枚子冰弹在生成时按原技能等级、施法者当前基础等级协同与装备确定范围；减速时长按半冻结时间、有效冷抗、MonStats.ColdEffect 与 DifficultyLevels.MonsterColdDivisor 的顺序计算，逐枚命中无 NextHit 间隔。源码范围与未核实边界见 [冰封球](SKILLS.md#冰封球依据与当前实现)；本次未构建或运行验收。

FCR 进入已接入法术的原施法动作速率；本次普通 A1／TH／S3／S4 接入原 AnimData、IAS 递减收益、基础武器速度及命中帧。逐武器命中与 IAS 不再混用副手，近战与弹体分别保留原定点掷值／增伤顺序。对恶魔／不死系的伤害和命中、钝器对不死系 50% 增伤、忽略防御及百分比减防已有消费者；完整 MonType 分层加成尚缺。武器元素附伤改为 1/256 生命单位掷值；毒素只在施加时过抗性，较弱速率不替换较强速率，持续扣血不重复触发受击动作。范围爆炸和移动毒云与火球共用导弹效果执行器，药瓶不继承装备武器附伤。瘟疫标枪和爆炸箭已按原协同、技能命中、武器元素及独立子弹体数值接入，技能延迟／扣蓝时机和伤害边界见 [亚马逊技能](AMAZON_SKILLS.md)。完整入口与明确缺口见 [通用攻击](COMMON_ATTACKS.md)。

FHR／FBR、穿透、怪物格挡、武器专精／完整致命攻击被动、触发、充能、光环、无形、镶嵌／符文及其余技能效果仍缺。不能因为说明可显示或 stat 被解析就视为效果完成。物品详细完成度见 ITEM_COMPLETION.md。

正式角色存档为原版 D2S v96，不写项目规则指纹：实例保留原词缀掷值；限时效果、怪物毒素／撕裂、飞行弹体和物品自动恢复计时不跨局。此前技能状态重构有构建记录；当前通用攻击与导弹效果修订已通过 Windows Release 编译并更新 dist/current，按用户要求未运行测试或游戏，之前力量加点的运行证据不覆盖本批。
