# 物品与掉落完成度

当前磁盘格式为原版 D2S v96，不写内部格式版本或规则指纹。2026-09-26 Windows Release 构建通过；使用现有调试管道验证四种品质生成与拾取、储物箱／方块往返、玩家装备、商店购买与确认出售、佣兵装备及 D2S 重载。未新增测试脚本或专用测试程序，未逐条验证所有物品属性。

## 数据与入口

- 运行时 MPQ：Weapons、Armor、Misc、ItemTypes、ItemRatio、TreasureClassEx、MagicPrefix／Suffix、RarePrefix／Suffix、UniqueItems、SetItems、Sets、QualityItems、LowQualityItems、Properties、ItemStatCost、NPC、Gamble、DifficultyLevels 和语言 TBL。
- `content/item_properties.cpp` 将原属性指令与实例掷值解析成共同统计值，保留原 stat、layer、原值与按等级换算后的效果值。装备、说明和定价共用解析结果；不从界面文字反推效果。
- `content/item_descriptions.cpp` 按 ItemStatCost 的说明优先级、函数、正负文本与 TBL 生成说明，合并元素／毒素伤害；商店与背包共用同一提示框。
- `content/item_pricing.cpp` 按基础表、词缀／品质费用、ItemStatCost、NPC 倍率形成购买、出售和单件修理报价。尚不能解释的属性计价分支拒绝报价，不按普通价格出售。
- `content/item_loot.cpp` 与 `gameplay/loot` 处理 TC、品质和实例；`gameplay/items` 负责数量、持久身份、位置、需求、耐久与事务。UI 只提交购买／修理等命令。

地面白色菱形的原因是商店提前缓存了商品背包图标，`ItemChange` 旧逻辑据此跳过地面动画加载，落入几何替身分支。现分别检查图标和地面动画缓存（包含空帧），任一缺失都调用共用加载器；适用于所有物品，不按箭矢代码修补。地面图形仍由当前 MPQ 的物品表 `flippyfile`（含特殊物品覆盖）选择，播放一次并停在末帧；不使用背包 `invfile`，缺原图时加载报错，不再绘制菱形／圆点替身。资源核对：当前 `misc.txt` 的 `aqv/cqv` 均指向 `flpqvr.dc6`，共 1 方向、17 帧，末帧为 20×16 的斜放箭袋，原偏移 (-10, 4)，转为左上角后 (-10, -12)。图像直接从当前 MPQ 导出查看；偏移核对 Diablerie `DC6.DrawFrames` 的底边 pivot 及 DGEngine `DC6ImageContainer`。沿用 Act1 调色板，与 Diablerie Loot 一致；OpenDiablo2 NewItem 使用 Units 调色板，参考之间不一致，不能据此武断更换。白色菱形已按上述缓存缺口修复，实际游戏显示仍待用户验收，未声称逐像素一致；本轮未构建、测试、运行游戏或打包。

地面放置由 `InventoryService::resolve/checkPlacement` 统一处理，装备／腰带事务草稿沿用同一世界碰撞回调并检查自身草稿物品。依据 D2MOO `Items.cpp`、`ItemMode.cpp`、`D2Collision.cpp`：单格物品，`COLLIDE_MASK_SPAWN`（0x3e01）与源点到候选点的 WALL／DOOR field（0x801），逐圈找最近空格，搜索半径小于 50。怪物和物体掉落保留原 (2,3) 偏移起点，不再先按角色行走网格挪落点；阻挡石头／对象由当前 MPQ `Objects` 各模式占位决定，存活怪物／NPC／佣兵由 `MonStats2.SizeX` 和原单位 presence pattern 决定，玩家用原单位尺寸。已有物品动态查询，拾取／移走即释放格子，不按物品名、背包尺寸或图片包围盒排间距。地面取放的阻隔同样用 WALL／DOOR，避免将可落物但不可站人的格子误判为不可取放。大图像仍可能伸到相邻格，不承诺像素完全不相交；跨 Region 边界搜落点仍未接入。无空位的批量掉落不排队重试、不重抽。

所有地面物品的绘制与悬停命中共用实际当前动画帧；落地后仍停末帧。地面悬停使用 Diablerie `Loot.selected` → `Materials.SetRendererHighlighted` 的亮度 3、对比度 1.01，保留原图尺寸／偏移／透明度；指向图像或其标题均可触发。打开背包只屏蔽面板覆盖区域，不全局禁用场景加亮。当前 MPQ `jav` 的 `flpjav.dc6` 共 17 帧，末帧 59×26、原偏移 (-28,11)，转换后 (-28,-15)，原像素绘制；用户已对照原游戏确认标枪长度一致，未加入缩放特例。这些修改未构建、测试、运行游戏或打包，尚待画面验收。
