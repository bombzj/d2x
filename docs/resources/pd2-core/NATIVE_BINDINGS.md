# 原生地址解析与跳板归并

这些入口解析原版模块的函数或全局地址，并缓存解析结果；它们不是1,115份新增玩法。版本选择器比较`1.0.13.60`与`1.0.13.64`，分别选择表槽0／1。正值表示模块RVA，负值表示导出ordinal，零表示该槽没有登记地址。此处保留两个槽位不代表全部PD2补丁支持另一原版版本。

`0x3A17B0`的模块编号与主补丁表不同，完整编号如下。82,290个CRT登记的E9跳板均已按原5字节相对位移核对，并归并到这些解析器；每个别名地址见[ALIASES.csv](ALIASES.csv)。119个解析器与固定公开BH头的模块＋1.13c地址匹配，名称仅作线索；没有复制其实现。
