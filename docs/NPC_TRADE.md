# NPC 购买实施顺序

数据始终在启动时从原 MPQ 读取。`content/vendor_*` 适配 `npc.txt`、`misc/weapons/armor.txt`、`itemtypes.txt` 和 `storepage.txt`；`gameplay/npc` 生成并持有会话货架，处理购买；`presentation` 只显示报价并提交命令。货架不从 MPQ 抽取为独立文件。用户提供的中文原版商店／背包截图留在本机忽略目录 `artifacts/reference-ui/npc-shop-inventory-cn.png`，供后续箱子界面参考。

1. 读取商人及物品的原表列，生成有身份、数量和价格的普通品质货架。常驻货物可重复购买；随机货物售出后消失。
2. 打开交易时校验 NPC 距离；购买时校验当前仍在同区与该商人交谈、余额、库存和背包空间。NPC 在交易中走动不会使已经打开的商店失效；已售随机货物在本局维持。
3. NPC 初次互动先打开菜单，再进入 Talk 或 Trade；商店用 MPQ 原面板、分类标签、底部按钮和物品图标，左侧货架紧靠右侧背包，货品悬停时就近显示名称和售价。商店页来自物品类型的 `StorePage`，各 NPC 货品来自各自原商人列；武器第一页放满后使用第二个武器页。右键货品直接提交购买；左键打开确认框，可点击 YES、按 Enter 完成，NO、Esc 取消。named pipe 提供交谈、查询与购买命令。

原版商店等级公式、普通难度第一幕等级上限 12、25 级后普通随机货品停止及武器页溢出规则参照本地 `reference/d2moo/source/D2Game/src/UNIT/SUnitNpc.cpp`；噩梦／地狱不应用普通难度等级上限。玩家购买使用 `npc.txt` 的 `sell mult`，防具基础价按防御值调整，来自 `reference/d2moo/source/D2Common/src/Items/Items.cpp`。随机种子由地图种子与 NPC 实体 ID 组成，货架在会话开始时生成；v82 角色存档载入后开始新的一局，售出状态重置。常驻货品可重复购买。旧商店截图和参考链接留在忽略的 `artifacts/ui-review-20260923/`；本轮从 Akara 和 Charsi 购买书与箭袋并检查实际物品事务，键鼠交互仍待人工验收。

NPC 菜单的矩形背景仍是现有 UI 绘制，原 MPQ 中尚未核实对应的专用背景。当前只上架原表中可生成、图形完整且普通基础价格可计算的装备与常驻物品；书的初始页数与附加价格现从 `misc.txt` 和 `books.txt` 读取。魔法、优质／劣质货品的完整计价仍未接入。噩梦／地狱达到商店物品等级 25 后，原版普通随机货品停止，当前因此主要显示常驻货品，不能把缺失的魔法货品当成完整原版库存。出售、回购、赌博、修理、任务折扣及原版刷新时机也暂缓；超过原两页容量时的翻页文字属于现有适配。
