## 坐标与知识

`playerCell`复用`nativeFeetCell`，以`floor(position + 0.5)`将DynamicPath世界脚点还原为原生整数脚格。局部Grid保留原半格中心约定；候选传送点按实际输入的`floor(landing)`取整。规划、即时TeleportTargets和普通RemoteCombat保持同一输入域，不用显示小数距离再次裁剪满距离中继。

碰撞只取客户端完整发布页，不受屏幕、小地图范围、Layer或图元刷新阈值限制。储存矩形随知识增长，0xffff为未知，不推断地图边界；跨步行边界两侧已知页共同验证路线和占地，区域归属只限制探索目标。生成布局、隐藏预设及额外reveal不能补出碰撞。

| 知识 | 来源、用途与生命周期 |
| --- | --- |
| 地形／物件 | 完整页及正常碰撞发布；长期规划不叠加远处怪物、NPC或其他玩家 |
| 单位核查 | 本地原生路径实际进入且有07订阅的房间；邻房07不等于核查完成，08不等于死亡 |
| 已走边 | 本人确认位置间短连续可通采样；纠正／传送／换区不补成步行边，未采样边仍可由完整碰撞证明可通 |
| 自然图元 | 城镇全显及种子／布局匹配的历史.map／.ma；仅作结构偏好和地标，不授权碰撞、身份或解锁 |
| 目标／入口坐标 | 真实历史观察或可辨识图元作接近线索，交互必须重新取得实际指派；角色蓝门不缓存成永久连接 |
| populationMemory | 游戏／区域／幕种子下的订阅、敌人GUID、指派、最后位置／时间及精英身份；跨步骤、补给和同局计划保留，死亡移除，重订阅等250ms后失效缺席线索 |
| rememberedDrops | 当前计划已见目标物品，跨步骤／战斗／临时离区保留；新计划清空，来源房间重订阅短等仍缺席则撤销，实际归属才结案 |

知识按游戏隔离、跨区保留，不写D2S或动态GUID文件；自然图元持久化归[自动地图](../gameplay/world/AUTOMAP.md#跨进程探索保存)。同类怪物的一个静态坐标不能代表全群。历史敌人仅引导重访，不授权攻击、碰撞或清场完成。

## 探索通路

普通探索合并两类方向：已知碰撞与未知地形交界、已核查与未核查单位范围之间的合法交界。完整角色占地与真实开口宽度决定站位；同类、同朝向相连边格合成稳定通路，持方向、站位集合及局部证据。不使用房间中心巡游、near图回溯或瓦片收益打分。

按实际路线成本、方向连续性及可用线索选通路；承诺分支随开口前移提取新站位，不逐帧换方向。无明确目标／经验／承诺时，优先道路核查与可进入已知地面的单位观察，再用地形边界。道路偏好关闭时同站位优先单位通路。已知目标暂无完整路线时，比较到开口成本、剩余距离和朝向；目标只给方向，不补未知边。

到点停稳后，`observationStatus／passageObservationReady`检查脚点房间、07订阅、碰撞发布及消息稳定窗口，不等待稀疏Host采样精确等于终点。稳定而无新增观察时暂缓该通路，局部证据改变才重试；不能因别处多几个格子清空全部暂缓。观测完成不代替交互、死亡或旅行结果。

无可达方向仅表示当前知识下无执行目标，不证明整区已清空。可用Teleport时可从孤立落点回到同区域实际确认、步行连通范围更大的已知地面；不要求落点带步行采样边，每跳仍验房间、地形和技能。没有合法恢复则有界失败，不补造房间图。

### 图元与视觉线索

AutomapSketch保留真实笔画，较弱地影响通路排序；NPC服务地标由已全显城镇的真实原点／变体提供。到线索处等正常指派，私人任务位变化可使NPC缺席记录失效，相同快照不触发重试。

唯一可辨识物件图标只供approachKnown；knownTargetPosition仍表示真实观察。旅行缺精确连接时可接近自然入口图元：保留当前候选，其余按距离；8格内无对应指派则本局跳过该区域／目的地候选，无法接近暂缓30秒。图元选择、量化及身份限制归[自动地图](../gameplay/world/AUTOMAP.md#跨进程探索保存)。

找未知出口或洞口时，只有鲜血荒地（`LEVEL_BLOODMOOR`，`Levels.Id=2`）使用`observedNavigationPaths`的土路线索。从冰冷之原起，连接探索使用普通通路和该区域已有的其他线索。道路线索只来自`revealVisibleTiles`实际观察到的原土路地板。附近路段须本人在订阅区、消息／地形稳定且有短程真实通路才记已核查，传送飞越不核查中间道路。剩余相连分支形成道路通路，复用承诺、成本和执行。可切弯、可传送。纹理在桥或预设处中断后仅保留前向偏好，改用普通通路；不拼河岸、不推断桥和道路端点。

瓦特之厅仅找Nihlathak时使用[ai_terrain_clues.cpp](../../src/app/debug/ai_terrain_clues.cpp)。当前MPQ LvlPrest864四张Nihl模板核对中央interior.dt1 main0／sub1、2组合与Init69同臂关系，映射+X／-Y／+Y／-X。运行只读真实视口确认的墙面，不按本局种子选模板；完整双块才定向，缺一、冲突或模板异常恢复普通探索。中央观察位途中固定，失败先让正常恢复运行5秒；八个证据按游戏／种子／原点保留，换局清除。末端大厅不等于找到或杀死目标。

通用图形识别、完整墙／河／路拓扑、封闭轮廓空白推断及图标联合消歧未实现。固定地图经验的数据依据与配置见[地图经验](../development/DEBUG_AI.md#地图经验配置)。

## 目标核查

找树、物件／NPC、指定猎杀、清场和缺失门户共用searchTarget／searchArea。本轮记录按目标、区域、种子及触发保存，步骤／补给不清空；新触发、目标丢失、新计划／游戏或种子变化建立相应轮次。候选来自已取得地形内未核查站位及本轮未探开口，范围内目标可经范围外绕行。

延迟目标按“实际触发 → 初等 → 本轮核查／有界观察 → 真实指派”推进。openedObjects仅认实际OPENED及正常静默投影，首次见已开保守从此刻计时；无回执演出由前置成立的任务步骤起算。waitMs不证明出生，早到目标立即接管，出生前的空房覆盖不算本轮已查。

普通目标范围耗尽、不可达或超时明确停止。预期出生目标核查耗尽后进入target-search-appearance，继续至原截止；变化可重估，否则按max(waitMs,1000ms)仅撤销退订范围的旧覆盖并重访，持续订阅范围直接等消息。不重放触发、不清地形、不延总预算。最终报告已查／未发布范围和absenceProven=false。

candidateRooms是显式资源知识，不是通用房间图探索：庇护所以实际402所在房间为锚，按配置四向7间房末端核查，选定一臂后保留至核查结束。依据D2MOO DRLGMAZE_PlaceArcaneSanctuary及当前LvlMaze的12×12瓦片，运行取锚点实际宽高；不能预测随机哪臂是召唤者。returnViaWaypoint只在候选房间搜索使用，核查换臂时比较直接路线与正常回城／已解锁本层点，保留覆盖，每次分支切换仅决定一次。

## 路线与缓存

普通门在步行规划副本中可操作：当前MPQ OperateFn8／61且Selectable0，仅移除这些门的占位，保留底层地形及其他物件。实际移动／落点仍用真实碰撞，子导航正常开门，同门持续关闭12秒失败；任务机关不套例外。传送可用且路线需开门时优先尝试合法绕门，无解才用开门后备。

传送以稀疏已知站位图规划，不保证连续地形全局最优。落点只读驻留地形／物件，不叠加动态单位；逐跳验能力、邻接、距离和Levels.Teleport限制，值0禁用、2验0x0804射线。中间地面不要求步行连通；Do27最终安置仍由服务器处理，不提前要求请求点无单位。

历史地形有路线但远端未驻留时，实时搜索可返回最靠后的可执行前段Partial及原objective；抵达后恢复观察续接，不把中继当完成。已有合法待探通路不因历史结构路线存在而被改判ExecutionBlocked。真正无前段时才检查结构／普通恢复；物件碰撞确有未到期过渡可等正常发布，不为地区／NPC加固定延迟。

同目标、同通路承诺的成功路线可跨知识／执行修订复用，但开口和每条边必须通过当前复验。实际脚格在旧节点时截取后缀；与最近传送回执一致的修正落点可接已请求中继下一节点，失败才重算，不先走回请求点。普通探索frontierRoute使用同一回执跳过已执行中继。拒绝旧结果即移除，避免反复扫描；目标改变、开口失效或偏离路线仍重规划。

`Execution::requiresDoor`仅在完整落点占地已发布且实际被门阻挡时触发绕门；实时窗口边缘缺十字邻格不等于关门，远端记忆步行段不因此整条失效。精确中继保留零容差，普通坐标目标规划与到达共用原生脚格容差。

## 局部执行与接敌

长期路线只含地形／物件，动态单位在下一执行段检查。`visitNavigationPresence`为navigationGrid和navigationBlockers的共同占地来源，自身／当前交互目标按正常路径处理，保留宠物、中立、尸体和非实体模式规则；重叠阻挡逐身份归因。

城镇和野外局部绕行调用公共Grid.nativePlayerPath，整数目标限18格前视以符合Straight／AStar范围。必须确有位移且到候选邻格，不把墙前截断当成功；已提交原生路径保留到结束，允许多转弯。中立单位只绕行或等待，城镇不攻击。无简短绕行则发布BlockedStep，交给[路段战斗](../development/DEBUG_AI_RUNTIME.md#战斗与路段交接)，不等角色被包围。

普通中继在末端6格内可规划续段，保持前进方向和必要转角；城镇转角可取4格净空修正，townWalkLane保存bend与已验证resume，能前向切回即可续行，不越过接回点再折返。真实纠正清旧段，exactPoint／最终交互不放宽。旧townTurnBaseMs／MinMs／MaxMs配置可读但无效果。

单位接近先确认已知完整路线，再用RemoteTown.nativeInteractionApproach预览公共原生路径的末格是否满足交互；50格只表示请求范围，不能证明能走到。可完成则普通RemoteControl.interact沿手动点击接近／自动交互，不要求实心中心可站；不能完成继续地形中继，缺观察返回needs-observation。已提交接近保留，不被短停或无关门抢占；尚未交互而停滞15秒时，同一子目标先接回地形路线一次，再有界失败。下一段需传送时先位移再交接。

拾取复用nativePickupReach，在物品周边找可站且可拾的位置；失败排除该点及近邻，最多8个。物品格可站且具备合法Teleport时可直接落地，否则换侧；提交后等真实归属，不重发未知拾取。接敌同样以当前技能范围／射线筛站位，怪物中心不作站位；路线结果不证明击杀。

步行边界从已取得两侧碰撞提取合法开口，允许斜桥与拐弯，不强求垂直三格。历史开口不被当前驻留窗口裁掉；对侧未知只接近获取知识。父AI在18格前视内选择实时可穿开口，原生路径末格须真正越界，受阻换同连接候选或等待／清路；不靠停在本侧判跨区。独立debug-walk出口只接近，不自动跨层。

出城无额外固定等待。首次传送选择期间继续步行；拒绝或原3秒期限无位移时沿路线前进一原生格再试，不追加3秒冷却。技能／资源／地形资格仍走普通功能，首次位移前不插途经攻击，成功或换区结束恢复。

### 有界恢复

静态局部碰撞未变、双方在max(1200ms,2×walkRetryMs)内未离开各自4格邻域、相距不超过2格且至少4次移动提交时，可提前needs-replan；父层保留目标立即从实际脚点重算，暂禁可选走道偏移。离开8格或地形变更恢复偏移，同局部仅提前交接一次，不重置总预算。

真正双端失配依据新的本人位置校验及持续无进展，而非单个旧96。服务端停在所报终点至少2秒（高延迟更长），本地也停或中间有碰撞时，共用恢复沿已加载短段返回Host已观察脚点附近；不写位置。每子目标最多两轮，保持15秒无进展及原总期限。双方超过50格时优先范围内双端可达指针，再范围内，再范围外；使用正常坐标请求等待原0x15纠正，不用超范围02／04／13静默请求替代。3秒无可用短段失败。

相同入口／指派在局部恢复后连续三轮失败且确认脚点未离开2格邻域，父层明确停止；坐标中继同样跨重规划计三轮，不靠冷却清零。真实进展、新指派、任务／目标变化按所属生命周期重置。通行纠正后的有界重试另见[执行契约](../development/DEBUG_AI_RUNTIME.md#通行与事件)。

## 旅行与传送点

区域旅行使用本幕已解析Vis、实际出口／门户、观察连接位置及本人传送点资格，保留进入方向和落点。按所在区域的步行／传送能力估价：城镇步行，评估后续野外段时分开技能资源资格与当前城镇禁令。未知段使用AI搜索成本，不证明可通或最短。

已选区域序列按真实换区推进，目标改变、偏离、连接否定或接近失败才重算。普通步行连接的失败成本跨同局任务保留，实际成功跨该连接或换局才清除，门户到达不算步行成功。同一行程有可行路线时不因估价波动折回已访问前缀；无路仍可用合法恢复。

回城统一比较普通路线、实际蓝门、当前传送点及新开蓝门；已可直接交互的来源接近成本为0，仍计操作／换场。额外传送点中转须至少节省max(16,当前成本×10%)，成本不是秒数。未知蓝门对端不借普通反向出口坐标。补给后在城内重选仍缺任务，不强制旧蓝门返程。

决策用解锁只保留knownWaypointAreas：初次总表未知时在城镇正常查询63，实际激活增量加入，正常跨幕城镇按原自动解锁和MPQ索引加入；新完整63校正，旧快照不覆盖后来激活。同房间计划重启保留，新游戏清空，不回写协议副本或D2S，最终仍由真实菜单与Host裁决。

传送点先用当前指派，再真实历史位置、自然图元及已核经验searchHint。到记忆处无指派而有普通路时，本旅程暂缓来源，实际指派可重新启用，解锁资格不删除。总表未知可打开已知点查询；完整表否定目的地或来源失败时不循环查询。普通路线为空且本层有点、仍有潜在合法目的地时才搜索未知来源，不抢占可行普通路。

城镇捷径只负责到达选定点，成功后结束自身期限，恢复原目的地与visitedAreas；来源开窗失败则暂缓并从实际区域重算。跨幕无来源先正常回城；新进程无完整目标幕路线时，可先到本人已解锁的目标幕点恢复观察，同幕不采用此中转。

顺路仅处理实际见过的点，危险、任务服务、已提交旅行优先。无个人结果时暂缓30秒且离开16格后再试，世界mode不证明解锁。activateAllWaypoints的强制策略只维护在[配置入口](../development/DEBUG_AI.md#输入与组合)。

同层传送台只用真实指派，步行图加入本人实际位移确认的有向连接，不猜外观配对。具备且区域允许Teleport时，规划忽略暂时缺蓝／冷却并排除传送台，施法另验资源。未知对端只能正常探索可步行到达的台；接近执行预算30秒，提交后普通RemoteControl按延迟同来源最多补点两次，新操作或本人重定位停止。AI等三个观察间隔加500ms，无结果停用该次指派和旧连接、尝试其他路；连续16次搬移无新知识明确阻塞。原规则归[物件](../gameplay/world/OBJECTS.md#同层传送台边界)。

## 生命周期与预算

NavigationWorldKey隔离游戏／区域代次、种子、幕、难度和配置。碰撞以全局32×32不可变块、路径复制目录及稀疏执行覆盖发布；内容未变复用块，变化页及两格邻域更新边界，地图重物化仍需扫描，不是全管线零复制。单位订阅覆盖已记录后不逐帧展开，后台只复制目录／知识元数据，不降低知识更新频率。

单区知识上限8Mi格，超限明确报错；观察路线缓存最多64项。换局／换区取消旧作业，退出取消并等Worker结束；几何reset清回调采样快照，不能只凭尺寸和局部修订复用旧原点。结果逐边复验，临时单位占位不重复创建同语义远程作业。

旅行估价单独低优先级，缓存16项，固定起点等完成，不挤掉未完任务反复排队；只完整路线用于成本，未就绪保留距离／未知段估价，不挂起输入。仅一个就绪任务条件或沿既有行走时跳过多分支估价。每2ms协作检查紧急任务，输入复验仍在前台。

长期路线可在等待期间保留，防御后从实际脚点接合法后缀，必要时求回起点短段；仅恢复同一步骤移动，不重放交互。起点保留最多64项、60秒未用或地形域变更失效。

明确区分Complete、Partial、NoRoute、NeedObservation、StartBlocked、StartUnavailable、Cancelled和ResourceLimited；起点缺碰撞不能伪装探索耗尽。性能计数及坐标格式统一见[导航诊断](../development/DEBUG_AI_DIAGNOSTICS.md#慢搜索与无路现场导出)。
