# 能力与缺口

目标：基于经典 Diablo II MPQ 的 C++ 引擎；当前为单机 MVP，不是完整原版重实现。

| 系统 | 已实现 | 尚未实现／限制 |
| --- | --- | --- |
| 资源 | MPQ 优先级、TXT、DS1、DT1、DC6、DCC、COF、字体和音效 | 不保证任意补丁、MOD；不支持 D2R |
| 地图 | 第一幕 39 项目录均有地形入口；Levels 1–37 已接双向路线；四类二级边界、悬崖及洞口、营地过渡、原河桥预设及道路地板已接入 | 崔斯特瑞姆／牛场任务入口未实现；通用 LvlSub 主题／传送点未完成；道路路径为适配而非完整原算法；键鼠往返及门交互未人工验收 |
| 行走 | 等距投影、5×5 子格碰撞、A*、WASD、走跑、耐力；跨野外边界和点击洞口／楼梯 | 非原版逐帧移动；键鼠完整路线尚待人工验收 |
| 角色 | 野蛮人 COF/DCC 多层、16 方向、移动／攻击／施法／受击／死亡 | 职业选择、装备外观、成长与完整职业规则 |

| 怪物 | 原表名单、密度、群组、随从；附近房间创建、远处休眠；基础沉沦魔、僵尸、骷髅、腐化罗格原动画及公共近战 | 仅 fallen1、zombie1、skeleton1、corruptrogue1 注册原外观；战斗数值仍是 MVP，共享追击／近战非完整专属 AI；其他变体与复杂类型保留替身，Boss、远程、复活、抗性、精英词缀未实现 |

| HUD | MPQ 经典底栏、生命／法力球、左右技能槽、按需展开菜单、原表图标 | 非完整原版菜单系统；自动地图仍是自有碰撞轮廓显示 |

连续主线：

`罗格营地 → 血腥荒地 → 冰冷之原 → 石块旷野 → 地下通道一层 → 黑暗森林 → 黑色荒地 → 泰摩高地 → 修道院大门 → 外侧回廊 → 兵营 → 监牢三层 → 内侧回廊 → 大教堂 → 地下墓穴四层`

支线：邪恶洞窟、洞窟一／二层、地下通道二层、地洞一／二层、深坑一／二层、埋骨之地及两座墓穴、遗忘之塔入口及五层。外侧回廊／大教堂按原表 Depend／Offset 连接依赖关卡，兵营按原朝向及坐标偏移接入回廊。崔斯特瑞姆地形可独立查看，任务传送门尚未实现。

兵营：采用原版 10×14 房间、四房起始环、主题房、定向回廊连接房、监牢楼梯及铁匠房。入口跟随外侧回廊变体；普通入口为 `--level 28`，回廊方向可通过 `--level 27 --variant 0..2` 选择。资源检查与打包共用迷宫家族元数据；缺某家族资源不禁用其他家族。三个回廊朝向均已有短帧启动记录。

监牢：12×12 房间与四房起始环；一层放传送点房，二层放 Pitspawn 特殊房，三层楼梯接内侧回廊。地下墓穴：一层使用四向固定入口房，二／三层使用横向或纵向固定入口房；二层放传送点房，下楼梯接原版第四层预设。门状态、传送点功能、首领行为、任务及键鼠往返不因地形加载通过而视为完成。

牛场：独立 80×80 地形，原悬崖、中间、转角、边缘四类 LvlSub 模板按分组匹配和变体替换，放置原营地、池塘、围栏、沼泽及石块预设。牛王原身份已识别，行为仍使用敌对替身。通过 `--level 39` 查看；没有伪造洞口或无条件红门，任务开启／返回规则尚未实现。

主线野外：洞口先于中间、转角、边缘替换，跨区接边和原预设占用受保护；空白宏格不再铺基础草地或创建刷怪房间。按已核实方向查表接入河岸和桥变体，道路使用原两格宽栅格化及 256 项 DT1 地板转换表。宏格路径沿用项目 Grid 寻路与平滑，是适配实现，不保证原版道路形状或随机流一致；未加入原营地专用道路端点。石阵、艾尼弗斯树与塔入口放置失败会明确拒绝地图，不再静默遗漏。

主线悬崖：按相邻关卡接触区拆分边界，保护连接段，选择原悬崖转角与直段；优先扫描悬崖洞口，未找到时保留普通洞口分支。营地过渡按原方向查表选择固定文件槽位，种子 1 已实际触发并加载 TownSTrans2。二者仍是当前矩形区域布局上的适配，非原版逐随机流一致实现。

通用 LvlSub 主题阻塞：当前挂载源的 `data/global/tiles/act1/outdoors/trees.ds1` 为 v12、6960 字节，偏移 6744 声明 14 个分组，余下只有 13 个完整的 16 字节分组及 4 字节，无法读取第 14 组完整边界。资源查询明确拒绝截断数据；未删减分组、未修改原 MPQ。需核对合法完整资源或有依据的版本解释后再接主题执行器。

仍待逐项补齐：道路原路径选择及端点、通用 LvlSub 地形主题／神殿／传送点、崔斯特瑞姆与牛场任务传送门，以及更广泛种子下的原布局一致性。39/39 只表示目录地形覆盖，不表示这些规则已完成；本阶段按最新指令提交源码，保留这些缺口。

## 怪物实施顺序

最新范围调整：先补简单普通近战类型并提交，不做 Boss 和复杂行为。本轮已逐项接入 `skeleton1` 与 `corruptrogue1`，各自验证后再进入下一项；此前完整专属 AI 顺序保留为后续计划，不宣称已完成。未核实的数值、资源和规则明确暂缓，中立单位不使用敌对替身。

基础骷髅使用原 `SK/1hs`，腐化罗格使用 `CR/1hs`；采用各自 MonStats2 允许的轻甲、斧、圆盾及轻型装饰组件。站立／行走／攻击／死亡四套动作均要求 COF 组件完整。只接基础 ID，不把同族不同配色／装备变体直接映射为同一已实现外观。新增类型暂时显式复用原公共近战 MVP 数值和逻辑，专属 AI、原表战斗参数及动画命中时刻仍未实现；替身标记撤除表示已使用自己的原外观和可运行近战类型，不表示原版行为等价。

1. 公共近战 AI：修复隔墙攻击、攻击范围与移动停距不一致、失效路径、同帧玩家死亡后的追加攻击。沿用现有 MVP 数值，不视为原版攻击动画／命中判定实现。验证：开放地面追击、障碍绕行、隔墙不伤害、进入攻击距离停止追击、眩晕／冰冷、玩家死亡、远处休眠及读档恢复。
2. 僵尸：先从 MonStats 的 AI、各难度 aip 参数及 MonStats2／动画数据导入已核实规则，再接独立决策；包括接近概率、警觉距离、近身游走、A1／A2 和埋骨之地分支。验证真实 zombie1 的移动、攻击决策、难度参数及保存恢复，不把替身当僵尸验收。
3. 沉沦魔：按原 AI 实现攻击决策、同伴死亡反应、逃跑及回战，独立保存决策随机状态与计时。验证击杀同伴后的响应、恢复追击、群体行为和跨区保存；当前 `fallen1` 原外观不代表这些行为已实现。
4. 萨满：先完成尸体身份与可复活资格、施法目标、动画事件及投射物，再实现沉沦魔复活与远程攻击。验证复活不重复掉落／计数、不复活不合法尸体、遮挡及保存一致性，未完成前保留真实身份的替身。
5. 更多怪物：依次接骷髅近战、腐化罗格近战、骷髅／罗格弓手、刺猬类投射物，最后各类精英／首领；每次只扩一个家族。原外观、动作、AI 参数、攻击规则、资源收集和真实身份全部接入并验证后，才撤销该家族替身标记。

每项共用门槛：Windows 构建；现有游戏场景运行及截图；本项关键行为证据；同规则保存／恢复；涉及美术时检查原资源及独立包。只启动三帧不能证明 AI 正确。若新增持久状态，同步快照校验、存档格式和规则指纹，旧档不静默迁移。

公共近战的隔墙不伤害、动态绕行、眩晕／冰冷、跳跃与死亡等定向行为尚未取得完整运行证据，保留人工验收缺口。新增骷髅、腐化罗格分别完成 600 帧原场景运行、恢复继续 300 帧以及独立包 300 帧运行；这些检查证明加载与保存路径可用，不等于专属 AI 验收。最新指令已授权提交本阶段源码，不再等待地图／复杂 AI 全部实现。

## 其他缺口

地图工作暂停，保留以下缺口；不在怪物实现期间混改。

1. 野外规则：核对截断主题资源、原道路路径／端点、通用 LvlSub、传送点与地形主题。
2. 地图交互：门碰撞与状态、传送点、崔斯特瑞姆／牛场任务入口、完整键鼠跨区验收。
3. 怪物实现：逐个替换行为与动画；不改原始怪物身份。
4. 物品执行：TC → 基础物品 → 品质／词缀 → 完整装备属性。
5. 任务、商店、成长与原版技能规则。

以上是缺口清单，不代表已授权自动开始下一项。
