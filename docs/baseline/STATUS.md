# 能力与缺口

目标：基于经典 Diablo II MPQ 的 C++ 引擎；当前为单机 MVP，不是完整原版重实现。

| 系统 | 已实现 | 尚未实现／限制 |
| --- | --- | --- |
| 资源 | MPQ 优先级、TXT、DS1、DT1、DC6、DCC、COF、字体和音效 | 不保证任意补丁、MOD；不支持 D2R |
| 地图 | 第一幕 39 项目录、31 项地形；Levels 1–26 双向连接 | 兵营、监牢、地下墓穴一至三层、牛场；完整道路、河桥、悬崖及 LvlSub |
| 行走 | 等距投影、5×5 子格碰撞、A*、WASD、走跑、耐力；跨野外边界和点击洞口／楼梯 | 非原版逐帧移动；键鼠完整路线尚待人工验收 |
| 角色 | 野蛮人 COF/DCC 多层、16 方向、移动／攻击／施法／受击／死亡 | 职业选择、装备外观、成长与完整职业规则 |
| 技能 | 火球、冰霜新星、旋风斩、传送、跳跃攻击、战吼 | 参数和部分效果仍是早期 MVP；技能树、技能等级、职业限制 |
| 怪物 | 原表名单、密度、群组、随从、固定首领；附近房间创建，远处休眠 | 多数外观和 AI 用沉沦魔替身；远程、复活、抗性、精英词缀等 |
| 物品数据 | 完整包 659 条物品、734 条怪物、852 条 TC；类型与基础参数 | 已导入数据不等于属性、词缀和装备效果已执行；当前 34 种物品美术 |
| 掉落 | 原版落地动画、名称、走近拾取、地面归属 | TC 执行、NoDrop 结算、金币、品质与词缀生成；自定掉落已停用 |
| 容器 | 包裹、腰带、私人箱；拖放、交换、合并、拆分、整件转移；13 种药剂 | 完整穿戴槽与装备属性；资料片大箱布局 |
| HUD | MPQ 经典底栏、生命／法力球、左右技能槽、按需展开菜单、原表图标 | 非完整原版菜单系统；自动地图仍是自有碰撞轮廓显示 |
| NPC／物件 | 原位置静态外观、恢复、私人箱交互 | 完整对话、商店、任务、门状态和地图箱子掉落 |
| 存档 | 项目格式 v3；角色、区域、待生成怪物、物品、种子、校验与备份 | 不支持 `.d2s`、跨规则迁移；自选预设需相同配置 |
| 平台 | C++20/CMake；Windows 已有构建运行记录 | Linux 尚未实际编译运行；无联网 |

连续主线：

`罗格营地 → 血腥荒地 → 冰冷之原 → 石块旷野 → 地下通道一层 → 黑暗森林 → 黑色荒地 → 泰摩高地 → 修道院大门`

支线：邪恶洞窟、洞窟一／二层、地下通道二层、地洞一／二层、深坑一／二层、埋骨之地及两座墓穴、遗忘之塔入口及五层。外侧回廊、内侧回廊、大教堂、安达利尔层和崔斯特瑞姆暂仍独立查看。

建议后续按边界分工：

1. 野外细节：原版道路、河桥、悬崖、LvlSub、传送点与地形主题。
2. 后半幕地图：兵营／监牢／地下墓穴生成、修道院内部连接、门碰撞。
3. 怪物实现：逐个替换行为与动画；不改原始怪物身份。
4. 物品执行：TC → 基础物品 → 品质／词缀 → 完整装备属性。
5. 任务、商店、成长与原版技能规则。

以上是缺口清单，不代表已授权自动开始下一项。
