# 客户端契约与本地适配基线

更新：2026-10-03。对应 [技术改造方案](../TECHNICAL_REFACTOR_PLAN.md) P1 的人物、库存、角色／技能 UI、NPC 对白／菜单和任务日志；P1 全部 UI 迁移尚未完成。

## 已实施：移动与受控人物视图

| 入口 | 职责与依赖 |
| --- | --- |
| [`contracts/actor.hpp`](../../src/contracts/actor.hpp) | `MoveIntent` 表达目的地；`ActorView` 表达 ID／区域、位置／朝向、动作显示、移动速度、光照与可见着色。只包含 `core` 和标准库，不包含角色、怪物、会话或资源 |
| [`IActorClient`](../../src/client/actor_client.hpp) | 返回当前受控人物的值视图，接受移动、停止与走跑切换；适配器绑定受控身份，UI 不选择权限或任意玩家 |
| [`LocalActorClient`](../../src/client/local_actor_client.cpp) | 借用 `GameSession`，将移动／停止／走跑转为原命令，将当前权威人物映射为视图；只有实现需要完整玩法状态 |
| [`application.cpp`](../../src/app/application.cpp) | 依次创建会话、适配器、场景与控制器；销毁顺序保证借用对象有效 |
| [`controller.cpp`](../../src/presentation/controller.cpp) | 两处鼠标地面移动入口改走 `IActorClient`；死亡／切区输入判断改读人物视图 |
| [`scene_view.cpp`](../../src/presentation/scene_view.cpp)、[`world_renderer.cpp`](../../src/presentation/world/world_renderer.cpp) | 人物位置／朝向／动作帧／速度／颜色、相机与人物光照消费视图；COF／DCC 帧数裁剪与实际绘制仍由表现层处理 |

`d2x_client_api` 是仅依赖 `d2x_core` 的接口目标；`d2x_client` 提供库存值查询，`d2x_local_client` 的会话依赖为 `PRIVATE`。应用组装本地实现，已迁移的表现入口使用接口。`ActorView` 是当前进程的值契约，不是网络包格式，也不承诺当前数据能直接映射原 D2GS。

动作显示保留原分支优先级和已有帧映射，包括死亡、施法、持续施法、闪电序列、武器攻击、格挡与突进。冷冻／蛛网减速、脚步间隔和光照沿用原派生值；这次迁移没有增加技能或怪物参数。快照在主线程同步读取，不保留跨步内部指针。

## 已实施：库存视图与意图

包裹、腰带、仓库和方块读取 `InventoryView`，手势通过 `IInventoryClient` 预览／提交库存意图；`LocalInventoryClient` 绑定本人，沿用权威库存事务。提示文本通过显式上下文计算，界面不查询人物成长、原物品属性或随机流。库存查询与布局实现的实际编译依赖已隔离会话／模拟／完整世界状态；详细入口、版本约束及实际 UI 操作／保存恢复覆盖见 [库存基线](INVENTORY.md)。

## 已实施：角色与技能 UI

`CharacterView`／`ICharacterClient` 提供本人必要成长、派生数值、资源、技能元数据／等级／资格、选择与快捷绑定。角色面板、技能树、技能菜单和 HUD 读投影，分配／学习／选择／绑定提交 `CharacterIntent`。本地映射通过 `LocalCharacterClient`；显式上下文的角色伤害及技能／光环提示计算位于 `content/character/character_display.cpp`。

角色和库存投影按会话权威更新版本缓存；同一版本不重复构造，场景只在版本改变时复制。借用视图仅到下次读取／销毁，场景保留独立值，不保留权威指针。版本在固定步（含 `tick(0)`）、成功恢复及走跑设置后推进，不是网络包序号。入口、规则迁移、实际 UI 与保存验证见 [角色基线](CHARACTER.md)。

## 已实施：NPC 对白、菜单与任务日志

`QuestView`／`IQuestClient` 提供本人日志文本、启用／完成状态、幕页和已知真墓符号；UI 不解释任务阶段、库存材料或地图种子。`NpcConversationView`／`NpcSceneView`／`INpcClient` 提供请求对象的本人对白、类型化服务菜单和场景提示；服务命令转发原权威校验。任务回顾与菜单布局保持客户端显示操作。

`LocalQuestClient` 与 `LocalNpcClient` 是允许查询会话的兼容适配实现，按权威版本缓存；切换请求对象也刷新对白。场景保留独立值，接口不输出玩法／内容指针；权威完成事件携带对应转换的完成标志，不让 UI 从最终状态猜测。任务控制和 NPC 控制已抽为独立实现，保留主控制器手势顺序。

本地适配只绑定当前受控人物；场景任务感叹号也按其进度生成。未来远端适配使用本人私有数据和公开场景消息，不传其他玩家任务簿、库存或初见记录；这些界面投影也不包含地图种子。入口、编译依赖与实际覆盖见 [NPC／任务基线](NPC_QUEST.md)。

## 当前限制与下一步

`ActorView` 不携带任务、钱包、技能学习记录、背包或完整效果集合；本人库存与角色界面分别使用专门投影。当前尚未提供其他可见人物列表，也没有网络缓存、插值、预测或权威身份认证；未来远端适配必须从服务端公开状态填视图并提交意图，不能复用本地适配对权威内存的读取。

键盘移动仍通过应用固定步输入；攻击／施法、任务物品世界命中、地图与资源加载仍沿用会话入口。人物效果叠层、其他单位、商店货架／报价、地面拾取和佣兵详情仍有旧状态依赖，因此 `SceneView`／`SceneController` 仍借用会话，`d2x_presentation` 仍链接 `d2x_session`。内部事件尚未拆成带接收者语义的完整客户端消息。剩余 UI 迁移包括商店／佣兵查询、地图和客户端资源目录；总体顺序以改造方案为准，当前重点为 P3／P4 前置边界与通用技能执行。这些切片尚不构成完整客户端／服务端分离。
