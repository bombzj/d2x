# 第一幕任务

第一幕六项任务的角色进度按难度保存。任务次序为邪恶洞窟、埋骨之地、凯恩的搜寻、遗忘之塔、交易的工具、屠杀的姐妹；玩家仍可提前进入部分区域，进度以实际交谈、交互和击杀事件推进。任务资料始终从运行时 MPQ 读取：`Levels.txt` 决定区域，DS1 与 `Objects.txt` 决定物件，`MonStats.txt`／`SuperUniques.txt` 决定目标身份，`Hireling.txt`、物品表、TBL 和 `a1npc.txt` 决定奖励、图标文字和对话。引擎事件次序参考 `reference/d2moo/source/D2Game/src/QUESTS/ACT1/`。

| 任务 | 当前流程 |
| --- | --- |
| 邪恶洞窟 A1Q1 | 阿卡拉交谈；进入邪恶洞窟；杀尽已创建与待激活敌人；回阿卡拉领一个技能点，每难度可免费重置一次属性／技能。 |
| 埋骨之地 A1Q2 | 卡夏交谈或进入埋骨之地；击杀该区真实身份为血鸟的首领；回卡夏领取原 `Hireling.txt` 罗格佣兵。佣兵跟随并用 MPQ 箭矢和基础数值攻击。 |
| 凯恩的搜寻 A1Q4 | 黑暗森林点击 Inifuss 树取得树皮卷轴；阿卡拉翻译；按当前地图种子排列的五块原石头顺序点击；通过 MPQ 红门进入崔斯特瑞姆，点击囚笼救人；回阿卡拉领取按难度生成的戒指。译文卷轴提示石头顺序。若安达利尔先死，罗格自动救出凯恩，不能领取戒指，鉴定仍收费。 |
| 遗忘之塔 A1Q5 | 石块旷野读塔书，进入遗忘之塔并到第五层；击杀 `SuperUniques.txt` 的女伯爵完成。塔书叙述和 NPC 任务对话取原 MPQ。 |
| 交易的工具 A1Q3 | 恰西交谈，进入兵营；8 级后从原 Malus 物件取得 `hdm`；交还恰西，每难度可选背包里一件白色武器或护甲灌注为稀有物品。新词缀走现有 MPQ 随机流程，等级按原引擎角色等级规则。 |
| 屠杀的姐妹 A1Q6 | 凯恩交谈，进入地下墓穴第四层；击杀原安达利尔首领后按 MPQ 首杀 TC 结算掉落，出现回营地蓝门；向瓦瑞夫交谈并选“Go East”登记第一幕通关。第二幕地图与实际东行尚未实现。 |

## 代码入口

- `src/gameplay/quest/` 每项一个短规则文件；`src/gameplay/session/session_quests.cpp` 连接 NPC 与死亡事件，凯恩物件、卷轴、恰西灌注和安达利尔结局另分文件。
- `src/content/npc_dialogue.cpp` 从 MPQ 解析任务状态对白；`src/presentation/quest_panel.cpp` 用原 MPQ 任务背景、图标与 TBL 文字绘制，按 Q 打开。UI 只提交命令，不改任务状态。
- `src/persistence/save_codec.cpp` 保存三难度任务记录、佣兵和奖励点数；v84 与旧档不兼容。角色载入在营地开始新一局，石阵与任务物件由任务记录恢复。
- 管道 `quest-status` 读取任务阶段；`quest-panel` 配合 `screenshot` 查看原图面板。所有任务命令仍走正式会话规则。

## 已知边界

未实现的敌对首领沿项目约定保留真实身份、显示沉沦魔替身。佣兵的装备、复活、技能和完整仇恨尚未接入。女伯爵宝箱飞弹、安达利尔结尾动画与第二幕地图尚未实现；任务声音保留 MPQ 引用但不播放。此次短帧与管道冒烟涵盖任务地图、塔书、任务物件、安达利尔首杀、回城门和邪恶洞窟任务面板；六项完整键鼠流程仍待人工验收。
