# 存档

唯一磁盘格式为原版《毁灭之王》D2S v96。支持度变化不修改格式版本，不保存项目规则指纹或私有尾段；旧 `.d2xsave` 编码已删除，不读取、不转换、不迁移。原文件留在磁盘不动。当前世界只实现第一幕，载入在罗格营地开始新的一局。

正常启动从 `saves/` 列出可读取的 `.d2s`，`quick.d2s` 是命令行快速档，不作为可选角色。创建七职业资料片普通角色后立即保存，正常退出自动保存，删除须确认。姓名仍限制为 1–15 个 ASCII 字母、数字或连字符；不提供普通版转换和专家模式。

## 保存内容

- 角色名、职业、经验、等级、基础四维、未用点数、技能等级、F1–F8 绑定、两组左右鼠标技能和当前武器组，钱包／私人箱金币及生命、法力、耐力。
- 原 `Woo!` 任务段、`WS` 传送点段和 `0x7701` 初见段；映射三难度第一幕奖励与进度、NPC 初见及阿卡拉重置。凯恩代救对应 COMPLETEDBEFORE，不占用牛王 CUSTOM6。重置标志按原任务段每难度偏移 0x52 存储；石阵开启顺序等本局过程不保存为私有字段。
- 玩家装备（含两组手部）、背包、腰带、私人箱、方块及佣兵装备的原 `JM` 位流：普通／魔法／稀有／套装／暗金／超强／劣质品质、原编号、耐久、数量、书页、属性及五组套装附加属性列表。载入属性以原数值保留，不反推或重新掷词缀。
- 罗格佣兵原类型、名字偏移、种子、经验与死亡位；等级从原表和经验推导，存活佣兵进入新游戏时恢复基础生命。原档没有当前生命字段，不额外添加。
- 地图种子与当前难度。项目内部角色／物品／容器 ID 在进入会话时重新分配，随机状态使用新会话值；它们不进入 D2S。自选地图配置不是原格式字段，仍由启动参数决定。

重新进入会创建新的区域会话：怪物、尸体、怪物 AI 阶段、召唤物、弹体、蛛网、地面掉落、区域击杀数、死亡结算、回城门、NPC 走动位置和商店本局售出状态都重置。野外物体的开启状态、井水余量和祭坛效果也重置。普通游戏过程中离开区域再返回，当前会话仍保留区域状态；只有载入存档才开始新的一局。角色冰冷、毒素、蛛网减速、施法／攻击动作及其他短时效果不会跨局保存。死亡后载入目前以城镇 1 点生命复活；原版尸体取回规则尚未实现。

任务状态在新的一局延续；凯恩石阵、任务物件和 NPC 出现状态根据记录恢复，普通区域敌人重新生成。凯恩获救致谢和安达利尔死后各 NPC 的待播放反应对齐 D2MOO 的本局 GUID 列表，保存在 GameSession，载入时清空；不与跨局保存的 NPC 初见记录混用。

这里的新局不是对 D2S 执行“战斗状态清理”：D2S 本来就没有冰甲、未完成施法或地狱之火引导等字段。解码构造新的角色值对象，恢复时整体替换 `PlayerState`。待施法参数、目标、倒计时及引导进度均由角色自身拥有，随旧角色状态一同销毁；`Simulation` 不另存这两类状态，读档不再额外清空会话级施法槽。`CombatEffectSet` 的状态实例、来源、事件反应、句柄和绝对模拟帧也只存在于本局；技能等级／选择仍使用原 Skills.Id，不使用内部 SkillBehavior 枚举。编码仍逐项写入原 D2S 字段，不序列化角色内存对象；本次重构不改变格式或保存语义，不作为每个技能的重复存档验证项。原地切换职业的调试功能已移除。

走／跑选择：本地 D2MOO `PlrSave2.h/.cpp`、`GAME/Clients.h::D2PackedClientSaveFlags` 与独立 `@dschu012/d2s` 的 v96 头部定义均没有已定义的走跑选择字段。`0x24` 一带的状态／进度位和武器切换位不可据此解释成跑步；未知位也不占用。本项目把走跑开关与 mini panel 开关保存到运行目录的 `client-settings.json`，跨角色、快速读档和客户端重启恢复；首次启动或配置不可读时两者默认关闭。该文件只含 `running`、`miniPanelOpen` 两个布尔值，不属于 D2S 或原版 ini 格式，不参与角色存档迁移。耐力仍按原属性字段保存在 D2S；原版客户端的具体偏好文件及字段尚未核实。

偏好 JSON 的缺省键或类型错误只回退对应开关，保留另一有效字段；整体 JSON 损坏时使用默认值。写入复用 `persistence/save_file.cpp::writeFileAtomically`：独占锁目录、临时文件写入及刷新／关闭检查、原子替换，失败不截断原配置。仅保存成功后清除待保存标记；游戏中失败重试至少间隔两秒，正常离开会话时再尝试一次。持续失败会记录错误，跨角色使用当前内存选择，但不能保证重启后恢复未成功写入的选择。该机制不改变 D2S 编码或其既有备份流程；偏好文件和锁目录均忽略 Git。

## 操作

- F11 保存角色，Ctrl+F11 从存档在城镇开始新的一局；默认路径 `saves/quick.d2s`。
- Esc 先关闭面板／对话，无面板时打开游戏菜单。选择 Save and Exit Game 才返回角色列表：角色来自列表、`--load` 或指定了 `--save` 时先保存到当前存档路径，失败则留在原会话和菜单并显示错误。Return to Game 或再次 Esc 恢复游戏，不触发保存；Options 暂不执行。`--class` 且没有 `--save` 的临时角色不自动落盘。返回列表后清除上一局的地图／存档启动选项，不把新选择的角色写回上一角色文件；关闭窗口／调试 quit 与返回列表分开处理。
- 普通图形启动先选择或创建资料片角色，所选角色在正常退出时自动保存。`--load <路径>` 直接启动载入；`--save <路径>` 设置存档路径，并在正常退出时保存。只指定 `--load` 时沿用该路径；命令行直进游戏而未指定 `--save` 不自动保存。
- `--class <MPQ 职业名>` 直接构造新的一级角色，不经过前端、不读取或自动创建 D2S；与 `--load` 互斥。测试场景可通过 `Play.cmd -Class Sorceress` 新建，或 `Play.cmd -Load <输入.d2s> -Save <输出.d2s>` 从已有场景开始并保留原档；只有显式保存才把临时角色写入磁盘。
- 覆盖前保留上一份 `<路径>.bak`。快速载入若地图种子或难度与当前进程不同会拒绝，改用 `--load` 重启。窗口关闭、调试 quit 和帧数退出均先保存有归属的角色；失败则显示错误并保留当前会话，不以抛出异常销毁未保存角色。系统强制终止、断电和进程崩溃不在此保护范围内。

## 编码和校验

- `gameplay/session/character_save.hpp::CharacterSaveData` 是角色存档值边界，不包含区域怪物、弹体、NPC 运动、地面掉落和死亡结算。`characterSave()` 只收集角色和容器物品；`persistence/d2s_codec.cpp` 与 `d2s_header/fixed_sections/stats/skills/items/inventory` 逐项写入原字段，角色内存中的短时动作不被序列化。`session_restore.cpp` 校验新角色与装备、重建内部 ID 和空白新局，再提交状态。
- 原 `GameSession::snapshot()` 和整局世界校验已删除：现有测试及联机无调用，普通沉沦魔见尸记忆被误判为复活目标曾阻止保存。怪物 AI、商店售出、NPC 路径及战斗状态均不得作为角色保存的前置条件。库存值校验与 `LootState` 的小型状态接口仍有实际用途，不与整局快照混用。
- `AA55AA55`、原版本 96、长度、原循环移位累加校验和；小端低位优先位流，属性位宽来自 `ItemStatCost`。文件上限 16 MiB。保存先在内存编码并解码验证，再使用锁目录、同目录临时文件和备份原子替换。
- `CharStats/Experience/Skills/inventory` 及物品原表校验成长、技能、装备、箱子尺寸和属性；恢复时重算装备与角色派生值。磁盘不携带或检查本项目版本指纹。

## 支持边界

- 普通品质护身符的原生单词缀字段按 D2MOO 读写，允许其未鉴定状态，不将其转换成魔法品质；魔法护身符仍保留原前后缀、属性值和需求。原图案编号用于背包显示及往返。库存另按当前原表 `carry1` 拒绝同角色背包／方块／私人箱中重复的限带暗金，旧非法重复档明确报错，不静默删物品或迁移。2026-09-26 此批修改仅静态核对，未构建或运行往返；D2S 仍为 v96，无新私有字段和规则指纹。
- 不支持普通版、D2R、专家／死亡角色头、天梯、其他幕任务属性奖励或其他幕城镇。后续扩展支持仍使用同一原版格式。
- 尸体、铁魔、镶嵌物、符文之语、无形、个性化、耳朵、Crafted、自动词缀和 realm 数据目前拒绝。原档里的已知属性值可保留，但不代表全部技能触发或属性玩法已实现。
- 本项目生成物品若含未适配的 Properties 函数或没有真实掷值的随机套装附加属性，会拒绝保存并保留原文件，不少写属性。新角色的原版菜单装备外观字节目前使用空值；本项目角色列表按实际装备合成，原版客户端外观兼容尚未验收。
- 第一幕中间阶段会归并到原版持久任务位；进入新游戏后根据任务物件恢复进度，不保证本局动画／石阵／对白阶段逐项保留。生命、耐力等按原定点精度保存。
