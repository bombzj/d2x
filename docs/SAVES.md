# 存档与读取

怪物生成阶段将文件格式升级为版本 2，保存原始怪物／首领身份、生成来源、组号、稳定生成键，以及独立的刷怪种子和难度；旧版本 1 存档明确拒绝，未进行静默迁移。区域使用 Levels.txt ID，资料片与试玩不能混读；使用 `--variant` 或 `--preset` 的存档需保持同一场景配置。已完成完整源 MPQ 保存、单独新版精简包读取含怪物会话的普通运行检查。

第 6 项已接通会话存档。使用本项目的 `.d2xsave` 格式，不读取或写入 Diablo II 原生 `.d2s`。

- `F11` 保存，`Ctrl+F11` 读取，默认槽位为工作目录下的 `saves/quick.d2xsave`。
- `--load <路径>` 启动时载入；无法载入会明确退出，不悄悄开始新角色。
- `--save <路径>` 指定槽位并在正常退出时保存。未指定时不会自动存档。
- 同时指定时，先读取 load 路径；快捷保存和读取使用 save 路径。只指定 load 时，快捷操作使用该路径。
- 每次覆盖已有存档前保留上一份 `<路径>.bak`。备份可直接通过 `--load` 读取。

```powershell
.\build\bin\d2x.exe --save saves/hero.d2xsave
.\build\bin\d2x.exe --load saves/hero.d2xsave --save saves/hero.d2xsave
```

Linux 的选项相同，程序路径改为 `./build/bin/d2x`。存档按明确的小端整数和 IEEE 754 浮点编码，不直接保存编译器结构体布局，不依赖 Windows 指针或对象地址。格式按跨平台设计，Linux 尚未实际运行验证。

## 保存内容与恢复边界

保存玩家位置、生命／法力／耐力、动作计时、冷却、药效队列、当前及已访问区域的怪物、尸体、弹道、技能效果、击杀数；同时保存完整物品实例、数量、耐久、品质／等级字段、版本号、地面归属／容器格子、四个玩家容器、ID 分配游标、随机数状态和死亡结算记录。

保存的是最近完成的固定步状态。未执行的输入命令不进入存档；鼠标拖拽、窗口、相机、GPU 资源、音效事件、临时储物箱访问权和自动拾取／交互请求也不保存。若保存时正自动走向物品或 NPC，只从快照中去掉该请求对应的路径；当前游戏仍可继续行走。普通走路、战斗及技能状态照常保留。

读取成功后取消旧 UI 手势和待执行命令、重置相机，并重新绑定当前地图网格。读取箱子旁边的存档会保留人物位置和箱中物品，但必须再次正常交互才能打开箱子；不会凭存档恢复远程访问权。暂停状态作为界面偏好保留。读档之后要先松开原来按住的鼠标／移动键，才接受下一次持续输入。

## 格式与校验

`SessionSnapshot` 是独立的值模型。`persistence/save_codec.cpp` 管理文件版本、固定字段顺序和编解码；`save_file.cpp` 管理文件与备份；`GameSession` 校验世界关系，`InventoryService` 校验物品和占格。文件 I/O 不进入玩法固定步或渲染器。

版本 2 文件包含 magic、版本号、长度和 CRC32；文件上限 16 MiB，字符串和集合都有长度限制，重复键、未知位置类型和尾随数据均拒绝。加载后进一步检查：

- 数据／规则指纹、地图配置、数值范围、有效区域与坐标。
- 唯一 ID、分配游标、角色／怪物／弹道引用和已结算尸体。
- 刷怪难度、原怪物定义、替身实现对应、首领关联、生成来源与单区域生成键唯一性。
- 物品定义、数量／耐久／等级／版本、所有者、容器格子、矩形重叠和腰带装备对应容量。

先完整读取和验证临时快照，最后在同一线程无抛出提交；读档失败不修改当前会话。存档绑定启动时实际读取的原始数据及地图资源，并包含人工维护的玩法规则版本标识。换了相关 MPQ 内容或规则时明确拒绝，不把旧实例静默映射到另一套定义；暂不提供跨版本迁移。

写入使用目标目录下的临时文件，写完关闭后再替换，替换前更新 `.bak`。Windows 的替换集中使用 `MoveFileExW`，其他系统使用同文件系统的 rename。独占目录锁避免两个遵守此协议的进程同时写同一路径。若进程被强制终止遗留 `.lock` 目录，应先关闭相关进程、保留检查其中临时文件，再手动清理该锁目录。CRC 和指纹用于损坏／版本识别，不是防作弊或真实性签名；目前不承诺断电落盘持久性。

本轮完成 Windows 编译、原始资源启动保存、新精简 MPQ 独立读取、自动走近私人箱后保存、重新读取及覆盖产生备份、野外带怪物状态保存和恢复的普通运行检查。没有编写测试脚本、测试用例或专用测试程序；未自动化覆盖键盘热键、拖拽和所有战斗中途存读组合。
