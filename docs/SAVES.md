# 存档

`.d2xsave` v88 是角色存档，不兼容原版 `.d2s`。旧 v1–v87 拒绝载入，不静默迁移。角色可在野外保存；再次进入时从上次所在幕的城镇出生。当前世界路线只实现第一幕，因此实际出生地是罗格营地。

本次版本变更对应属性解释、稀有词缀规则、等级属性、最大耐久／额外堆叠及魔法及以上品质投掷武器数量 0（普通／劣质／优质耗尽移除） 的新语义；字节字段仍沿用原物品实例布局，旧格式明确拒绝，不迁移已有角色。赌博库存、商店刷新和自动修理／补充数量的计时只存在于本局。v88 未构建或运行验收。

## 保存内容

- 职业、经验、等级、属性与技能分配、未用点数、F1–F8 绑定、当前 I／II 武器组、分三难度的 NPC 初次见面记录、钱包和储物箱金币，以及生命、法力和耐力当前值。
- 三难度各六项第一幕任务进度、已领取技能点与免费重置标记，以及卡夏佣兵的原表行、名字、等级和生命。佣兵当前路径与攻击冷却不跨局保存。
- 两组手部装备、其余装备、腰带、背包、私人箱与赫拉迪克方块中的物品及其随机词缀、品质、数量、书的卷轴页数、耐久等实例数据。地面物品不属于角色存档。
- 已激活的传送点、地图种子、难度、当前地图配置与上次区域身份。地图配置和种子用于重建单机地图；刷怪种子不保存，新一局按当前启动参数重新规划人口。默认刷怪种子目前固定，因此不指定新种子时怪物位置可能重复。
- 角色和物品的 ID 游标、角色战斗随机状态与物品生成随机状态，用于避免持久物品 ID 冲突并继续生成物品。

重新进入会创建新的区域会话：怪物、尸体、怪物 AI 阶段、召唤物、弹体、蛛网、地面掉落、区域击杀数、死亡结算、回城门、NPC 走动位置和商店本局售出状态都重置。野外物体的开启状态、井水余量和祭坛效果也重置。普通游戏过程中离开区域再返回，当前会话仍保留区域状态；只有载入存档才开始新的一局。角色冰冷、毒素、蛛网减速、施法／攻击动作及其他短时效果不会跨局保存。死亡后载入目前以城镇 1 点生命复活；原版尸体取回规则尚未实现。

任务状态在新的一局延续；凯恩石阵、任务物件和 NPC 出现状态根据记录恢复，普通区域敌人重新生成。凯恩获救致谢和安达利尔死后各 NPC 的待播放反应对齐 D2MOO 的本局 GUID 列表，保存在 GameSession，载入时清空；不与跨局保存的 NPC 初见记录混用。

## 操作

- F11 保存角色，Ctrl+F11 从存档在城镇开始新的一局；默认路径 `saves/quick.d2xsave`。
- `--load <路径>` 启动载入；`--save <路径>` 设置存档路径，并在正常退出时保存。只指定 `--load` 时沿用该路径。未指定 `--save` 不自动保存。
- 覆盖前保留上一份 `<路径>.bak`。自选 `--variant/--preset` 需保持相同地图配置；快速载入若地图种子或难度与当前进程不同会拒绝，改用 `--load` 重启。

## 编码和校验

- `SessionSnapshot` 在内存中表示待保存角色；临时战斗效果会清除，生命／法力／耐力裁剪到无临时效果的上限。`persistence/save_codec.cpp` 的 v88 磁盘编码只选择持久字段。`gameplay/session/session_snapshot.cpp` 在载入时用当前 MPQ 重建一局并校验角色、任务、佣兵与物品，然后一次性提交。
- 固定小端及 IEEE 754 浮点；magic、版本、长度、CRC32。文件上限 16 MiB，集合与字符串限长。
- 按运行时 MPQ `CharStats.txt`、`Experience.txt`、`Skills.txt`、`SkillDesc.txt`、`inventory.txt` 和物品原表校验职业成长、技能前置、装备与箱子尺寸。恢复后从装备重算角色上限和战斗属性。
- 内容和规则指纹不符、地图配置不符、非法物品或 ID 冲突均拒绝；旧档不自动迁移。写入采用同目录临时文件与备份替换。
- 当前规则指纹为 `v122-item-properties-gambling`；v88 保留分难度 NPC 初见集合；运行时 TXT 字段按 ASCII 忽略大小写查找，使 StrBonus／DexBonus 等原列参与派生数值。旧指纹和旧格式文件不会静默载入。

v80 及更早版本中提到的“怪物读档”冒烟属于旧会话快照语义，不代表原版角色存档；v88 继续只保存角色状态和持久任务奖励。此前 v87 通过 Windows Release 构建和独立存档载入；当前 v88 没有构建或运行检查，没有新增测试脚本、用例或专用程序。
