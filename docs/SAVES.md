# 存档

项目格式 `.d2xsave` v14，不支持原版 `.d2s`。旧 v1–v13 明确拒绝，不静默迁移。v14 增加商人随机货品的已售 slot；v13 的物品已鉴定状态、原 DS1 路径 NPC 运动，以及物品品质原行、展示属性值和同局已掉落的限量暗金记录继续保存。属性当前只展示，不参与战斗。

## 操作

- F11 保存、Ctrl+F11 读取；默认 `saves/quick.d2xsave`。
- `--load <路径>` 启动载入，失败退出；`--save <路径>` 设置槽位并在正常退出保存。
- 同时指定时先 load，快捷操作使用 save 路径；只指定 load 时使用该路径。未指定 save 不自动保存。
- 覆盖前保留上一份 `<路径>.bak`，可直接读取备份。

## 保存边界

保存地图种子、刷怪种子、难度、玩家状态、当前／已访问区域、已创建怪物与尸体、待生成群组、弹道、效果、击杀数、物品／容器、NPC 路径运动、商人随机货品已售 slot、ID 游标、随机状态和死亡结算。

不保存 UI、GPU、相机、音效、输入队列、拖拽、当前 NPC 对话、临时储物箱访问权及走近出口／拾取／交互请求。对应自动路径只在快照中清除，不中断当前游戏。

启动 `--load` 按存档种子和难度重建地图。自选 `--variant/--preset` 仍需相同场景配置。快速读档不切换地图种子／难度，需用 `--load` 重启。

离区同时保存已创建与待生成怪物，返回不重刷。读档重置旧手势、临时请求和相机；先松开原有按键再操作。

## 编码和校验

- `SessionSnapshot` 是值模型；编码在 `persistence/save_codec.cpp`，文件操作在 `save_file.cpp`，世界校验在 `gameplay/session_snapshot.cpp`。
- 固定小端及 IEEE 754 浮点；magic、版本、长度、CRC32。文件上限 16 MiB，集合与字符串限长。
- 校验内容／规则指纹、地图配置、位置、唯一 ID、物品占格、怪物身份、生成键、群组及死亡结算。
- 待生成群组不能与已创建群组重复；待生成记录不预分配实体 ID。
- 完整读取和校验后提交状态，失败不修改会话。语义变更同步规则指纹，字段变更同步格式版本。
- 同目录临时文件与备份后替换；Windows 用 MoveFileExW，其他系统用 rename。目录锁防止并发写同一路径。
- 意外退出遗留锁时，先关闭相关进程并保留临时文件，再人工处理。不承诺断电持久性或防作弊。

当前未追加最终提交后的恢复、快捷键组合或 Linux 检查，见 [交接状态](baseline/DEVELOPMENT.md)。
