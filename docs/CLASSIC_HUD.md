# 经典底栏与技能选择

底栏使用完整经典 MPQ 的 `data/global/ui/panel/800ctrlpnl7.dc6`，以原始 800 像素布局整体缩放到窗口。左右技能槽、腰带、走跑按钮、耐力和球体共用 `hud_layout.hpp` 的坐标转换；不再常驻横排六张技能卡片。

## 球体与资源

旧实现先画球体、再画不透明面板，面板中的空球底图遮住了液体下半部，位置也未对齐。现在先使用球体原图轮廓遮住背后的世界，再画面板空球底图、按比例裁切的液体，最后画 `overlap.dc6` 的玻璃／手指前景。生命和法力分别读取 `hlthmana.dc6` 帧 0、1，裁切高度限制在 0～80 原始像素。

底栏、球体、按钮、技能图标使用原版 Sky 调色板；场景继续使用 Act1 调色板。腰带底行直接落在面板原有四个格子内，额外行使用 `ctrlpnl_popbelt.dc6`。

## 技能与操作

- 默认左右键普通攻击。点击左／右技能槽展开菜单，点击图标分配，点击外部、右键或 Esc 收起；选择菜单的鼠标手势不会继续施法或移动。
- 展开左／右技能菜单，悬停技能图标按 F1～F8 绑定到对应鼠标键；单按功能键只选择已绑定技能，不立即施法。技能 ID、图标、是否允许左键来自运行时 MPQ；绑定随 v22 存档保存。Shift + 左键可原地使用所选左技能。Ctrl+F1～Ctrl+F4 分别保留帮助、开发地图目录、碰撞视图、走近储物箱。
- 左键候选项遵循 `Skills.txt` 的 `leftskill` 字段。点击怪物时使用左键技能，普通点击空地仍然移动。
- 1～4 饮药，B 展开腰带；点击走跑按钮或空格切换走跑；I 或底栏中央按钮打开包裹。球体悬停显示当前值／上限。
- `T` 打开当前职业三页技能树；`--skills` 启动时打开技能树。节点、图标、页签和学习门槛来自运行时 MPQ，详见 [七职业技能树](SKILLS.md)。

技能图标通过 `Skills.txt` 的技能名和 `skilldesc` 关联 `SkillDesc.txt` 的 `IconCel`；旧表有直接 IconCel 时仍支持读取。图集根据职业选取，普通攻击使用通用图集。缺少原始素材明确报错，不以自绘图标补齐。未实现的主动技能指向敌人时使用普通攻击，指向空地不执行效果；被动技能暂只记录点数。

## 传送点菜单

普通传送点菜单使用运行时 MPQ 的 `800borderframe.dc6`、`waygatebackground.dc6`、`waygateicons.dc6` 和 `expwaygatetabs.dc6`（没有资料片页签时读取 `waygatetabs.dc6`），在左侧显示原边框、九个目的地槽位、激活／未激活图标与关闭格。目的地名称来自 `Levels.txt`，顺序由其 `Waypoint` 字段决定；实际可选与否仍由会话的激活记录控制。当前仅第一幕有可到达区域，其余原页签只展示，不允许选择。Ctrl+F2 开发目录继续使用独立界面与自由传送命令。此项随 Windows 构建通过，尚未打开菜单作画面验收。

## 边界与验证

七职业技能树各有 30 个 MPQ 节点、等级／前置门槛与技能点存档。八个 F1–F8 绑定由悬停左右技能菜单图标完成，绑定写入玩家存档；当前选中的鼠标技能仍是临时 UI 状态。女巫五项优先技能已接运行时 MPQ 数值及原资源，其他现有效果仍是演示实现。底栏中央原菜单按钮当前提供包裹入口，完整快捷菜单留待后续。Windows 构建、七职业技能树及女巫菜单截图和快捷键存读档已冒烟。

HUD 阶段已有 Windows 编译及完整源／精简 MPQ 的底栏、技能菜单和包裹截图记录；未编写测试脚本或用例，未进行完整键鼠验收或 Linux 运行。该阶段精简包未包含后续地图更新，当时存档为 v3；当前格式见 [开发与交接](baseline/DEVELOPMENT.md)。

历史精简 MPQ 包含 397 个资源，原始 MPQ 保留。当前程序直接读取完整 `assets/mpq2` 的底栏素材。
