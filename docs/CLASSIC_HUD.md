# 经典底栏与技能选择

底栏使用完整经典 MPQ 的 `data/global/ui/panel/800ctrlpnl7.dc6`，以原始 800 像素布局整体缩放到窗口。左右技能槽、腰带、走跑按钮、耐力和球体共用 `hud_layout.hpp` 的坐标转换；不再常驻横排六张技能卡片。

## 球体与资源

旧实现先画球体、再画不透明面板，面板中的空球底图遮住了液体下半部，位置也未对齐。现在先使用球体原图轮廓遮住背后的世界，再画面板空球底图、按比例裁切的液体，最后画 `overlap.dc6` 的玻璃／手指前景。生命和法力分别读取 `hlthmana.dc6` 帧 0、1，裁切高度限制在 0～80 原始像素。

底栏、球体、按钮、技能图标使用原版 Sky 调色板；场景继续使用 Act1 调色板。腰带底行直接落在面板原有四个格子内，额外行使用 `ctrlpnl_popbelt.dc6`。

默认鼠标使用原 MPQ 的 `data/global/ui/cursor/ohand.dc6` 和 Units 调色板，原始帧偏移配合帧高定位鼠标热点，依据 OpenDiablo2 `resource_paths.go`／`gui_manager.go`。此前误用 `gaunt.dc6` 后以边界颜色猜测透明索引的补丁已移除；正确图形使用 DC6 自身的透明像素。此修正尚待用户画面验收。

正常游戏不常驻 D2X／MPQ 资源字样、等级调试文字或快捷键提示，这些保留在 Ctrl+F3 调试视图中；用于衬托顶部文字的黑色渐变已移除。Tab 开关角落地图，V 交换左右，默认关闭；细节与标记缺口见 [自动地图](AUTOMAP.md)。

任务、角色、技能、交易、私人箱、方块和传送点侧栏复用 `classic_panel.hpp`／`panel_frame.cpp`。`800borderframe.dc6` 每侧五块大小不等，按 OpenDiablo2 `d2ui/frame.go` 的原坐标拼接，使用 Sky 调色板；不按等大方格拼接。每侧原尺寸 400×558，按可用高度等比例缩放并贴左右边缘，宽屏多出的宽度留给场景。内容与命中区域使用同一比例，场景中心随可见区域移动。

Q／红色 Quest Log 更新按钮进入任务日志，只显示已到达的第一幕页签；任务正文、剩余数、选中状态及已知边界见 [第一幕任务](ACT1_QUESTS.md)。这些侧栏和提示修改已构建；任务日志、商店、背包及 NPC 提示已在原 MPQ 运行中查看。

## 技能与操作

- 默认左右键普通攻击。点击左／右技能槽展开菜单，点击图标分配，点击外部、右键或 Esc 收起；选择菜单的鼠标手势不会继续施法或移动。
- 展开左／右技能菜单，悬停技能图标按 F1～F8 绑定到对应鼠标键；单按功能键只选择已绑定技能，不立即施法。技能 ID、图标、是否允许左键来自运行时 MPQ；绑定随当前存档保存。Shift + 左键可原地使用所选左技能。Ctrl+F1～Ctrl+F4 分别保留帮助、开发地图目录、碰撞视图、走近储物箱。
- 左键候选项遵循 `Skills.txt` 的 `leftskill` 字段。点击怪物时使用左键技能，普通点击空地仍然移动。
- 1～4 饮药，B 展开腰带；点击走跑按钮或空格切换走跑；I 打开包裹。底栏中央原按钮开关单人 mini panel，使用原 MPQ 的 `minipanel_s.dc6`、`minipanelbtn.dc6` 和 `menubutton.dc6`；七个图标分别进入角色、背包、技能树、自动地图、消息、任务日志和游戏菜单。消息与游戏菜单尚未实现，图标置灰并提示不可用。球体悬停显示当前值／上限。
- 资料片背包手部槽位有 I／II 两组，点击两侧原标签或按 W 切换；装备属性、主动武器伤害、弹药和角色手部外观使用当前组，另一组保存在角色存档。左右鼠标技能选择在本局按武器组分别记住；F1–F8 快捷绑定仍为角色级记录。
- `A`／`C` 打开角色面板，`S`／`T` 打开当前职业三页技能树；未用属性／技能点出现时，底栏 MPQ 红色按钮分别进入对应面板。方向键辅助移动。`--skills` 启动时打开技能树。节点、图标、页签和学习门槛来自运行时 MPQ，详见 [七职业技能树](SKILLS.md)。底栏经验条按当前级区间进度填充，悬停显示当前经验与下级阈值。

技能图标通过 `Skills.txt` 的技能名和 `skilldesc` 关联 `SkillDesc.txt` 的 `IconCel`；旧表有直接 IconCel 时仍支持读取。图集根据职业选取，普通攻击使用通用图集。缺少原始素材明确报错，不以自绘图标补齐。未实现的主动技能指向敌人时使用普通攻击，指向空地不执行效果；被动技能暂只记录点数。

## 传送点菜单

普通传送点菜单使用运行时 MPQ 的 `800borderframe.dc6`、`waygatebackground.dc6`、`waygateicons.dc6` 和 `expwaygatetabs.dc6`（没有资料片页签时读取 `waygatetabs.dc6`），在左侧显示原边框、九个目的地槽位、激活／未激活图标与关闭格。目的地名称来自 `Levels.txt`，顺序由其 `Waypoint` 字段决定；实际可选与否仍由会话的激活记录控制。当前仅第一幕有可到达区域，其余原页签只展示，不允许选择。Ctrl+F2 开发目录继续使用独立界面与自由传送命令。此项随 Windows 构建通过，尚未打开菜单作画面验收。

## 边界与验证

七职业技能树各有 30 个 MPQ 节点、等级／前置门槛与技能点存档。八个 F1–F8 绑定由悬停左右技能菜单图标完成，绑定写入玩家存档；当前选中的鼠标技能仍是临时 UI 状态。女巫五项优先技能已接运行时 MPQ 数值及原资源，其他现有效果仍是演示实现。底栏中央按钮只切换 mini panel，不再直接打开包裹；消息与游戏菜单待实现。Windows 构建、七职业技能树及女巫菜单截图和快捷键存读档已冒烟。

HUD 阶段有早期 Windows 底栏、技能菜单和包裹截图记录；当前程序直接读取完整 `assets/mpq2` 的底栏素材。本轮经验条、面板入口与快捷键改动见 [开发与交接](baseline/DEVELOPMENT.md) 的统一构建结果。

资料片背包以当前 MPQ 的 invchar6 为底图、invchar6Tab 为 II 组覆盖图，I／II 热区和物品框共用缩放。任务标题／正文使用当前 FontFormal12 保留原图参考中的大小写；标题按字形实际可见范围居中，透明留白不参与居中。界面字幕／通知时钟独立于世界固定步，打开 NPC 窗口不会冻结自动滚动。
