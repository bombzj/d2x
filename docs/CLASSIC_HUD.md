# 经典底栏与技能选择

底栏使用完整经典 MPQ 的 `data/global/ui/panel/800ctrlpnl7.dc6`，以原始 800 像素布局整体缩放到窗口。左右技能槽、腰带、走跑按钮、耐力和球体共用 `hud_layout.hpp` 的坐标转换；不再常驻横排六张技能卡片。

## 球体与资源

旧实现先画球体、再画不透明面板，面板中的空球底图遮住了液体下半部，位置也未对齐。现在先使用球体原图轮廓遮住背后的世界，再画面板空球底图、按比例裁切的液体，最后画 `overlap.dc6` 的玻璃／手指前景。生命和法力分别读取 `hlthmana.dc6` 帧 0、1，裁切高度限制在 0～80 原始像素。

底栏、球体、按钮、技能图标使用原版 Sky 调色板；场景继续使用 Act1 调色板。腰带底行直接落在面板原有四个格子内，额外行使用 `ctrlpnl_popbelt.dc6`。

## 技能与操作

- 默认左键普通攻击、右键火球。点击左／右技能槽展开菜单，点击图标分配，点击外部、右键或 Esc 收起；选择菜单的鼠标手势不会继续施法或移动。
- F5～F10 选择右键技能。左技能菜单打开时，快捷键改为选择允许绑定左键的技能；随后使用鼠标施放。Shift + 左键可原地向目标点施放所选左技能。
- 左键候选项遵循 `Skills.txt` 的 `leftskill` 字段。点击怪物时使用左键技能，普通点击空地仍然移动。
- 1～4 饮药，B 展开腰带；点击走跑按钮或空格切换走跑；I 或底栏中央按钮打开包裹。球体悬停显示当前值／上限。
- `--skills` 启动时展开右技能菜单，用于直接查看现有技能。

技能图标通过 `Skills.txt` 的技能名和 `skilldesc` 关联 `SkillDesc.txt` 的 `IconCel`；旧表有直接 IconCel 时仍支持读取。图集根据职业选取，普通攻击使用通用图集。缺少原始素材明确报错，不以自绘图标补齐。

## 传送点菜单

普通传送点菜单使用运行时 MPQ 的 `800borderframe.dc6`、`waygatebackground.dc6`、`waygateicons.dc6` 和 `expwaygatetabs.dc6`（没有资料片页签时读取 `waygatetabs.dc6`），在左侧显示原边框、九个目的地槽位、激活／未激活图标与关闭格。目的地名称来自 `Levels.txt`，顺序由其 `Waypoint` 字段决定；实际可选与否仍由会话的激活记录控制。当前仅第一幕有可到达区域，其余原页签只展示，不允许选择。F2 开发目录继续使用独立界面与自由传送命令。此项尚未构建或运行，边框拼接和命中坐标仍待画面验收。

## 边界与验证

本轮修复表现和选择行为，未改变现有技能战斗公式。职业技能树、学习等级、经验和属性点尚未实现；面板对应位置保留原底图，不显示虚构进度。六个快捷键仍为固定绑定，鼠标技能选择尚未写入存档。底栏中央原菜单按钮当前提供包裹入口，完整快捷菜单留待后续。

HUD 阶段已有 Windows 编译及完整源／精简 MPQ 的底栏、技能菜单和包裹截图记录；未编写测试脚本或用例，未进行完整键鼠验收或 Linux 运行。该阶段精简包未包含后续地图更新，当时存档为 v3；当前格式见 [开发与交接](baseline/DEVELOPMENT.md)。

新版精简 MPQ 包含 397 个资源，原始大 MPQ 保留。旧精简包缺少底栏资源，需要随源码一起更新；用户现有完整 mpq2 已包含所需文件，不需要另找素材。
