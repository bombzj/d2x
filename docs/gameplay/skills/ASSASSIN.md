PD2专项内容：[职业技能](../../pd2/CLASS_SKILLS.md)。本页保留原版／公共规则及必要的版本边界。

更新：2026-10-16。刺客30项职业技能已接入自研服务端；本页登记当前程序、原版依据与明确缺口。全部等级、装备、难度、多人及原版逐帧数值仍需分别核对。公共规范见[COMMON](COMMON.md)，准确性边界见[战斗公共规则](../../architecture/COMBAT_SHARED_RULES.md)。

当前SC、S2、武器序列及职业踢击由所属帧事件推进；DragonTalon按100%回绕重排，DragonFlight保留两次动作标记，Blade Fury使用持续单位事件。旧批量释放扫描已撤出，完整原全局交错与全部组合仍有缺口；见[内核对照](../../modules/SERVER_SYSTEMS.md#调度与动作的职责及迁移边界)。

蓄气唯一权威仍是公共效果列表中的原生状态及 `modifierlist_skill/level`、`progressive_*` 属性。满三层仅续期；终结取已存等级与当前最高等级的较大值，按状态顺序执行／移除。临时层数写回同一列表，不另建持久层数表。释放游标只记录当前步骤与已提交操作，用于容量重试，不承担新的玩法所有权。

`gameplay/skills/native_damage.*` 抽取物理→元素掷值及元素写入，`assassin_progressive.*` 提供层数、吸取、踢伤与释放步骤／路径；`combat/weapon_block.hpp` 共用最多32项的武器格挡参数层查询。近战接触入口不创建临时飞弹，来源与受击者分别消费自己的种子。普通怪物近战及旧接触入口的格挡游标只保留判定／动作完成度，避免背压重试重复掷数；原生技能／飞弹格挡仍走自己的完整接收链。全部接触组合与全局交错仍有缺口。

依据为当前MPQ、本地D2MOO `SkillAss.cpp`／`Skills.cpp`／`SUnitDmg.cpp`／`SequenceTbls.cpp`、AiThink与PlayerPets。原版1.13c `D2Game.dll`开始表VA `6FD27338`、执行表VA `6FD274A8`已定位，DLL版本身份见[资料来源](../../resources/THIRD_PARTY.md#原版113c静态与开发对照证据)。原版St24（`6FCB2DF0`）提前分配踢击接触；Do42（`6FCB5FE0`）保留取样及再次分配顺序，不能用动作帧才现算的一次普通近战替代。`SEED_InitLowSeed`同时初始化高字666。

心灵爆震的转换概率核对至原版 D2Game RVA `91610` 的 `SETLE` 与 D2Common ordinal `10832`／RVA `4E5E0` → `4DC30`；使用现有先除等级比例的递减函数。撤出回调 D2Game RVA `914F0` 明确将保存的最大生命左移 8 位，独立于圣骑士回调的原版写法。转换期限进入公共 RemoveState 队列；默认状态列表的计时器编辑只替换自己的处理器，保留转换回调。

陷阱使用真实原生类别、公共属性源与效果列表，六个陷阱技能按 `pettype` 共用容量。影子保留角色控制归属，数值与随机消费从真实怪物施法者读取，不构造替身玩家。AI 目标搜索已抽取为 `server/systems/ai/target_query.*`；技能列表保留原生追加次序，不能用 ID 排序代替影子大师的迭代顺序。新增元素填充覆盖非雇佣兵怪物原生吸取分支；持续技能参数随技能所有者撤出，不随单次动作销毁。纯单位技能继承允许在没有公开事实时正常提交权威属性；不伪造事件或消耗输出序号。原 0x7A 宠物归属包含刺客，解散不借管理删除实现。

近战底座拆开预分配、伤害／状态、耐久、攻击事件／反伤、最终受击／死亡动作。持有的踢击在实际排出时复验原生距离；影子使用自己的装备、随机与动作时钟，持续动作延长不重新创建动作。公共距离入口为 `gameplay/combat/geometry.*` 的 `unitMeleeReach`，参数保留玩家／怪物的原生差异。

客户端已接 MPQ 的蓄气叠层、A3 参数、终结技子体、投掷落地、陷阱火浪、喷火、尸爆、刃怒持续序列、心灵爆震散点及影子变身动画。斗篷 StateSet2 与亮度阶段核对至原版 `6FB223D0`／`6FB02F10`；当前环境照明仍使用现有光照适配，不能据此宣称整套原版调色与空间衰减精确。PD2专项说明见[职业技能：刺客渐进与陷阱表现](../../pd2/CLASS_SKILLS.md#职业技能刺客渐进与陷阱表现)。

零售CltDo57=B6F60的刀刃之盾附着飞弹分支已新增：先随存活主人定位，A1340按主人目标单位／路径目标／原朝向八组偏移取落点，子项用原path type14（BlessedHammer），保留TargetX／Y更新及公共剩余帧。使用已观察的目标／朝向，缺输入不猜方向；不以普通攻击目标代替路径目标。D2MOO SrvSt28只检查553声明和安装状态，SrvDo54执行原周期伤害，当前技能无CltDo，不能因此在收到状态158时额外创建553；当前只保留已出现553的消费者，未宣称自然播放入口完成。零售限定，未核PD2；新增源码已构建，行为仍待实测，完整附着精确路径、帧序与原调用来源仍待对照。

影子跟随使用逻辑区域、七个有序偏移、二十点历史、不同路径类型重试和远距房间随机探测。原版 `6FC67450`证实即使a7=0也进行出生探测，修正D2MOO旧反编译的相反条件；探测复用原生出生算法与房间随机，不创建替代单位。MonEquip只跳过连续类型段开头的超等级记录，后续已占槽位仍抽签；选槽保留宠物单位流，实际装备以游戏双种子构造，返回终值经复验后随召唤提交。强制装备不篡改真实鉴定／需求值，NOSELL、自然无形／加孔限制及修复耐久沿原构造参数；武器保留重采样所需系数和类型层。首个AI期限保留影子20帧、公共陷阱25帧及刀刃守卫Do44覆盖的1帧；伙伴调度响应房间重入的AI期限修订。完整出生属性／装备逐写回调与全局调度边界见[总计划](../../architecture/MULTIPLAYER.md#23-战斗重构实际阶段与剩余步骤)。

普通召唤出生搜索统一复用怪物−1／4探测入口，保留原房间边界及辅助碰撞，不另维护独立搜索算法；组件定义重复准备会重置计数与盾牌目录，不因影子前后两次准备而扩大随机范围。

[GENERAL](GENERAL.md)的隐藏Kick与怪物GargoyleTrap不计入这30项职业技能。后续按公共门槛核对开始／动作／接收事件与队列1／2的完整交错、全局随机及物品回调，再补齐装备／难度／PvP／背压／死亡中断矩阵与原版同条件逐帧数值对照。原版客户端加入自研宿主、Linux及整套调色／声音仍缺核对；原生无效的RoyalStrike客户端命中回调号不伪造实现，通用复合声音与个别怪物脚步资源门槛由表现底座负责。
