## PD2远端技能范围

当前CN资源有219个可见职业节点（195个主动、24个被动）及6个有等级的隐藏记录；上表的原版30项范围不适用于PD2。PD2只消费远端权威及目标MPQ，不准备自研宿主技能或本地PD2存档。七职业90级角色在本地原生PD2服务进行逐项检查；请求已发送、客户端弹体可见、服务器实际施放／伤害及完整组合是不同事实，不能以选技成功计为技能完成。

已补PD2 Blaze状态的移动留火、CltDo111喷流、98双手投掷、110／119火爪／火风暴及118分裂投掷的客户端入口；骨矛／圣光弹的额外弹数读取本人已核实属性投影，Charged Strike的数量使用当前Calc1而非只接受原版固定表达式。尸体召唤与骷髅溅射在本地原生PD2服务已有实际原包对照；完整随机、碰撞、数值、多人及像素时序仍未验收。具体程序和版本依据见[核心分析](../../resources/PD2_CN_DLL_ANALYSIS.md#角色技能树与客户端程序)。

Find Potion／Find Item的104已接原38／40尸体血迹，Sacrifice补齐原CltDo34；前者在本地原生PD2及原版模式核对尸体操作／血迹，后者在两种模式观察原血迹飞弹。112冲锋已接本人面向真实单位的路径、攻击阶段及末端坐标收敛，原生PD2已观察连续移动和击杀；地面目标、非本人／怪物及完整组合仍待覆盖。其余未恢复的专用／内部程序保持明确缺口；97跳跃已恢复本人经真实skill_move确认的原范围、路径速度、距离重力及落地时序，其他玩家／怪物和完整碰撞组合仍待覆盖。Mind Blast的PvP控制属性已核实来自原生map状态198，并接本人完整装备／状态／被动投影；资料不完整时仍保持未知；Desecrate生成的隐藏／udead尸体不放宽为普通可用尸体。需要近战武器、活目标、材料或尸体的技能须另备真实条件，未到达目标的请求不记作实战通过。

## 唯一归属与复用

职业页维护对应Skills行的专属算法及Clt／Srv差异；GENERAL维护通用十项。MONSTERS维护怪物专用程序和精英触发能力。COMPANIONS维护单位选技、等级与运行入口；ITEM_SKILLS维护物品来源和替代程序。同一技能被佣兵、怪物或物品使用时链接原规则页，不复制伤害、动作或弹体算法；仅记录使用者实际不同的条件。

物件机关与任务机关分别由[物件](../world/OBJECTS.md)和[任务系统](../quests/SYSTEM.md)负责；只有真实调用技能程序的部分进入技能台账。普通A1／A2、AI决策、MonUMod效果、状态／Overlay、弹体行和Skills行不是同一概念，不能全部计入职业技能完成数。跨技能行为族与弹体机制分别链接[COMMON](COMMON.md)及[攻击与弹体](../combat/ATTACKS.md)，不再建第二份公共规则。

## 逐项登记与待补范围

完整登记应以当前MPQ的Skills行为主键，保留ID／原名／使用者、CltSt／CltDo／SrvSt／SrvDo、弹体／状态关联、客户端支持、自研执行、公共函数、可定位的原版依据与缺口。SkillDesc／CharStats用于职业归属，MonStats／Hireling／物品来源用于交叉引用；未被技能树收录不等于无用途。保留行、空行与未引用程序分别标记，未知用途先归SPECIAL，不自行推断执行。

现有七职业和通用技能有逐项台账；怪物页含第二幕逐Skills行台账，同行者页按当前代码的执行家族归档。全部非职业原表行尚未形成完整逐ID清单；各职业仍须按公共门槛完成原版对齐，不能把目录分类齐备宣称为全技能审计完成。构建和自研运行情况只在当次交付中说明，不作为专题状态等级。当前状态及后续顺序见[基线](../../../BASELINE.md)与[总计划](../../architecture/MULTIPLAYER.md)。
