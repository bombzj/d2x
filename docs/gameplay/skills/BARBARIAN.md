# 野蛮人技能

更新：2026-10-11。自研宿主已接当前 MPQ 的 30 项野蛮人技能（126–155）：20 项主动、10 项被动。当前包与验证结果由[基线](../../../BASELINE.md)维护；入口齐备不表示全部装备、等级和多人组合已认证。

定义入口为 `src/content/skills/barbarian_data.cpp`；纯规则在 `gameplay/skills`，动作、移动、弹体、命中、状态和尸体消耗分别由 server 对应系统拥有。客户端读取原协议状态、播放当前 MPQ 原图并提交命令。MPQ 数值、公式、武器类型、状态、弹体及尸体尺寸动态准备；本地 D2MOO 的 `SkillBar.cpp`、`MissMode.cpp`、`SequenceTbls.cpp`、武器速度和路径函数仅作职责及算法证据，见[资料来源](../../resources/THIRD_PARTY.md)。

十项被动的提示和实际贡献共用`evaluateBarbarianPassive`；Frenzy、跳跃、尸体搜索及Berserk共用显式递减曲线，呐喊／武器协同及序列命中时钟使用[公共函数](COMMON.md#公共函数抽取)。抽取已纳入最终v39包的构建及第一幕有限冒烟，未专项复验全部野蛮人技能；下节冒烟属于此前野蛮人技能批。

## 生命周期与限制

学习、前置、技能上限、左右键、法力、充能和城镇资格仍按共用入口校验。六精通按真实武器类型匹配，同类加成取最高值；空手不冒充武器。双挥／双投／Frenzy 必须同时有两个合格武器，换装后释放复验来源；Whirlwind 允许单武器。投掷分别消耗各手真实数量，整次技能不重复扣法力。被动随有效技能等级和装备重新计算。

Find Potion／Find Item 搜索保留尸体显示并设置 `corpse_noselect`；Grim Ward 消耗并隐藏尸体。这些操作复用原死亡掉落完成资格，避免覆盖未提交的原掉落。尸体不可重复用于搜索、召唤、重生或其他消耗。Grim Ward 的恐惧原点固定为图腾位置。恐惧与嘲讽不控制首领或不允许切换 AI 的单位；War Cry／Stun 复用怪物眩晕资格和精英几率。

Battle Command 在被动求值前加入临时技能来源；协同仍只读基础技能等级。佣兵的临时全技能加成参与内容缓存重算，生效和到期都更新实际技能等级；刷新保留 Battle Orders 的生命上限，BO基数仍取装备后的未加成生命。状态、Frenzy 层数、移动动作、图腾、尸体标记和弹体不写 D2S；技能基础等级与选择沿原 v96 字段保存。旧准入指纹拒绝，具体见[存档](../../modules/SAVES.md)。

现有玩家武器路径对吸血／吸蓝、压碎／撕裂组合仍明确暂缓，不因野蛮人技能入口齐备而放宽；完整 PvP、多人争用、跨机器及 Linux 未认证。跳跃的原图飞行／落地序列已接，原客户端垂直高度曲线尚无已核实实现，不用自造高度替代。六精通的所有武器／层级及全部状态组合不作为代表冒烟的认证范围。
