# NPC交易与服务

普通货架由当前原服交谈0x38 action=1生成，9C action11／12更新商品；原0x32单件购买、0x33出售、0x35维修、0x34凯恩批量鉴定由RemoteInventory提交。价格、安置、资格、费用与结果均由原服决定。

公共商店面板只消费货架／库存值，左键手持物品投向货物区提交出售，修理模式左键提交维修。canRequestSale与quote分开：报价未知，不能以零金币伪造原服价格。买卖／维修／批量鉴定等待0x2A明确结果，相关物品提前变化不单独认定成功。

当前NPC GUID、货架来源、本人所有权、Cursor和交互代次发送前复验；结束／重开同一NPC交谈也使旧组合失效。失败／超时不自动重试消费操作。原参数见[物品命令](../../development/DEBUG_PIPE.md#联网物品操作)。

赌博、多买、精确报价、玩家交易、佣兵服务及灌注／重置／打孔／署名等任务服务尚未完整接入；没有本地VendorRuntime或旧任务奖励旁路。原服普通买卖／修理有限证据见[联网记录](../../modules/NETWORK.md#既有有限证据)。

本地D2MOO PlrTrade、SUnitNpc／SUnitProxy、Items及SCmd提供原协议／字段／服务规则证据；价格函数重建仍有舍入疑点，不作为客户端逐值定价依据。原货架图形与物品说明取当前MPQ，来源／许可见[资料来源](../../resources/THIRD_PARTY.md)。
