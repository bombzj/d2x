# NPC交易与服务

更新：2026-10-22。本页负责客户端商店交互与原NPC服务请求；货架、价格、成交与维修的权威规则归[ECONOMY](../items/ECONOMY.md)，任务物品加工归[QUEST_ITEMS](../items/QUEST_ITEMS.md)。

普通货架由交谈0x38 action=1生成，赌博用action=2，9C action11／12更新商品；原0x32购买及multibuy高位、0x33出售、0x35维修、0x34凯恩批量鉴定由RemoteInventory提交。原服和自研宿主共用请求；价格、安置、资格、费用与结果均由服务端决定。

公共商店面板只消费货架／库存值，左键手持物品投向货物区提交出售，修理模式左键提交维修。canRequestSale与quote分开：报价未知，不能以零金币伪造原服价格。买卖／维修／批量鉴定等待0x2A明确结果，相关物品提前变化不单独认定成功。

原版出售已装备物品可在2A成功后再发送9D action8卸装备；D2X接收端对已确认出售且已移除的原件只完成清理，不把迟到的移除消息重新投影为Cursor物品。部分维修的费用及恢复边界由经济页维护。

当前NPC GUID、货架来源、本人所有权、Cursor和交互代次发送前复验；结束／重开同一NPC交谈也使旧组合失效。失败／超时不自动重试消费操作。原参数见[物品命令](../../development/DEBUG_PIPE.md#联网物品操作)。

普通经济、个人赌博、回购、批量、充能修理与货架周期已接；灌注／打孔／署名收原38(action=0,npc,item)，等原58服务结果，再投影原物品与个人任务字。具体执行与限制分别见[经济](../items/ECONOMY.md)和[任务物品](../items/QUEST_ITEMS.md)。Akara免费重置已按原0x38 action0、parameter0及slot41资格实现；Warriv／Meshif同一消息的parameter按NPC身份解释为旅行目的地，不能统一当物品GUID。灌注／打孔／署名等服务的任务授予与消费见[任务系统](../quests/SYSTEM.md)所链接的各幕规则，罗格奖励与完整佣兵服务缺口见[佣兵](../characters/HIRELINGS.md)。玩家交易权威与取消／保存边界见[玩家交易](../items/PLAYER_TRADE.md)；没有本地VendorRuntime或旧奖励旁路。原服历史有限证据见[联网记录](../../modules/NETWORK.md#既有有限证据)。

本地D2MOO PlrTrade、SUnitNpc／SUnitProxy、Items及SCmd提供原协议／字段／服务规则证据；报价共用原字段纯函数，未知数据不授权金额，完整原服逐整数认证仍有限。原货架图形与说明取当前MPQ，来源／许可见[资料来源](../../resources/THIRD_PARTY.md)。

## PD2 CN城镇服务

固定Normal／TCP配置复用普通C2S 0x38/action1商店、action2赌博及0x32购买、0x33出售、0x35维修、0x34批量鉴定。只有服务端确认的NPC会话、当前GUID、交互代次与空Cursor可开店；普通货架9C/action11与移除action12沿版本化物品解码。货架原图进入共享缓存，不进入本人库存占格；preview与未知位置不开放交易，赌博物品只允许对应赌博购买。关闭／换区使旧请求与货架失效。

报价读取当前CN表、任务折扣和已确认的装备属性。当前核心D2Common价格替换入口RVA0x3A18E0→0x383060→0x2E8140；与原价计算逐项对照后，显式隔离每件维修折后上限250000，以及Gheed在原生区域137–210的百万金币赌博价与减价属性。城镇普通赌博使用主价格链。缺少词缀、耐久、任务或减价事实时保持未知，不以零价成交，也不因主公式相近声明全部PD2价格认证。地址与摘要见[DLL依据](../../resources/PD2_CN_DLL_ANALYSIS.md#城镇服务与计价的固定样本依据)。

普通购买与出售已实服核对：Charsi货架52件全部取得候选报价；回复药剂出售后金币增加1，再以1金币购回，新GUID进入腰带。0x2A的result表示操作类别（0购买／1出售／2维修），不能把非零result统一视为失败，仍须结合flags、金币与物品事实。维修全部收到对应回执，但现有法杖耐久已满，尚不能证明受损物品恢复。材料3:1转换已核对源扣3、目标加1及真实计数回执。阿卡拉实服47件货架也取得候选报价；原客户端截图与原buysell.dc6核对CN格子顶边为42像素，原版仍为62。绘制、悬停、买卖命中共用该布局；CN底部第二按钮按原frame4切出售模式，支持点选本人背包／装备出售，原Ctrl出售与手持投向货架保留。CN单件维修按钮保留，原版第二按钮的全部维修行为不改用到CN出售按钮；CN全部维修请求已接，原生全部维修界面手势尚待核实。商品继续取服务器位置，不按截图写死商品或价格。

治疗沿NPC交谈后的服务器资源事实，不发送原版5字节0x39；该目标0x39为12字节空回调。凯恩鉴定、雇佣／复活、灌注／打孔／署名／重置及旅行沿既有原请求并保留当前任务、费用、物品和NPC身份检查。佣兵新增腰带／鞋／手套格取当前Inventory.Hireling，缺格不补画。两名现有联调角色均1级；后续幕、佣兵与任务奖励实服测试按用户安排等待新角色，不能把源码开放当成资格与持久化已验证。

个人金币存取只允许已确认且同步的个人仓库；实服1金币存入／取回均核对钱包与银行的原属性变化。CN初始零银行属性可省略，存入只要求真实钱包金额，未知银行余额仍不显示或授权取出；目标容量交服务器裁决。方块合成只允许真实打开的方块；账号共享金币协议未闭合，继续拒绝。玩家交易沿已确认会话与锁定状态，双客户端完成／取消／断线尚未实测。更细边界与待验收项见[城镇分项](../../architecture/PD2_COMPATIBILITY.md#城镇交互逐项接入)。
