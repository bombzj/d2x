# 资料片佣兵

佣兵资格、费用、归属、同行、战斗和保存由服务端决定；客户端沿原MCP／D2GS消息显示和操作，不恢复旧本地执行器。当前源码准备第一幕罗格、第二幕沙漠守卫、第三幕铁狼和第五幕野蛮人的真实活动实体；第四幕没有独立佣兵类型。运行包和有限证据见[基线](../../../BASELINE.md)，技能归属见[同行者能力](../skills/COMPANIONS.md)。

## 原数据与执行入口

[hireling_content.cpp](../../../src/hosting/hireling_content.cpp)从当前MPQ的Hireling、MonStats／MonStats2、Skills、Missiles、MonSeq、States和AnimData准备身份、难度／等级段、基础成长、技能权重、原动画及装备后的技能和动作速度。技能使用佣兵自身等级、基础技能及佣兵装备贡献；不借用主人技能、精通或装备触发。缺失原数据或程序明确暂缓，不以沉沦魔替代中立佣兵。

[hireling.cpp](../../../src/server/systems/companions/hireling.cpp)负责服务，[hireling_control.cpp](../../../src/server/systems/companions/hireling_control.cpp)负责准备复验、出生、同行、选技和成长。技能动作、弹体、命中与效果分别归skills／missiles／combat／effects，伙伴生命与装备快照归monsters。hosting读取内容；server仅接收纯值规则。

| 类型 | 自身战斗和装备 |
| --- | --- |
| 罗格 | RogueMissile、Fire Arrow／Cold Arrow、Inner Sight；头盔／护甲／弓 |
| 沙漠守卫 | 普通近战、原MonSeq双释放Jab；Prayer／Defiance／Blessed Aim／Thorns／Holy Freeze／Might按原难度类型准备；头盔／护甲／长柄或长矛，拒绝盾 |
| 铁狼 | 火球／有界Inferno、冰尖柱／冰风暴／自身Frozen Armor、充能弹／闪电；头盔／护甲／单手剑／左手盾，拒绝双手剑 |
| 野蛮人 | 普通近战及原Bash／Stun；头盔／护甲／剑。这条佣兵入口不表示玩家野蛮人技能已接 |

Fn061按25格以内视线选敌，跟随门槛24、移动主人16、远距归位100；罗格／铁狼保留攻击选择偏置和近敌退避。步行主人不增加追赶速度，跑动／停步追赶采用原速度修正。跨区和主人Teleport带同行佣兵，取消旧区动作；光环和装甲从新运行态重新施用。多人敌对关系沿共享Participants，不由UI选敌。

武器伤害使用自身武器／STR或DEX、目标类型增伤和六通道；承伤使用自身防御、格挡、四抗、物理／魔法抗性、减伤／吸收以及状态。装备IAS／FCR／FHR／FBR、技能加成、生命、移动、吸血、压碎、撕裂、冻结／击退和生命击杀恢复已有消费者。佣兵吸血不套玩家难度吸取除数，目标Drain和抗性仍有效；首领伤害比例取DifficultyLevels。撕裂／毒伤保留实际来源和主人归功，佣兵独立击杀按自身经验份额。基础固定点回复叠加装备hpregen；毒／撕裂抑制自然回复，营地毒伤保留一点生命。装备触发技能及装备自带光环仍受公共物品消费者限制，与master相同，不由天然光环入口推定全符文之语支持。

主人开始DT时不立即杀佣兵；MPQ死亡动画ready时间到达后ownerDied同笔提交死亡记录，进入佣兵自身DT。回城复活和死亡保存等待这一事务完成，背压可延后不可提前。佣兵自身死亡停技能／通道／光环、清恢复状态，本局保留原尸体；复活移除旧实体。

原D2S v96保存type、名字偏移、seed、经验、死亡位和jf装备，等级按原经验曲线恢复；当前生命没有原字段，活佣兵入局按装备后满生命恢复，死佣兵不生成活动实体。临时AI、位置、光环、装甲、恢复队列和候选不入盘；规则指纹及旧档拒绝边界唯一维护于[存档](../../modules/SAVES.md)。

佣兵面板使用当前MPQ的npcinv、800borderframe、buysellbtn和原物品图；装备格取Inventory.Hireling。文字按原font6标题／font8数值及基线绘制，抗性使用TBL两行标题；生命居中，经验／属性数值右对齐。装备或冰甲／光环提升防御时显示原蓝色字体，负抗性显示原红色字体。关闭按钮按底图凹槽定位，绘制与点击共用边界。双手武器只画实际右手槽，空左手不重复武器或绘制盾牌轮廓；铁狼盾牌显示真实左手装备。原Hireling.Mode用于佣兵技能动画，MonStats的Jab序列优先；没有专用palshift的Hireable使用原组件像素。
