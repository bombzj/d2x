# 角色属性与成长

职责与保存值见 [角色模块](../../modules/CHARACTER.md)，战斗公式见 [战斗数值](../combat/NUMBERS.md)，装备效果的支持清单见 [物品完成度](../items/SUPPORT.md)。本页维护角色属性来源、派生顺序及面板行为。

## 原数据与规则

七职业的起点、每级／每点增长、移动／耐力参数由当前 MPQ `CharStats.txt` 提供，经验阈值取 `Experience.txt`。职业代码与原人物 token 为资源身份映射，不保存成长数值。物品属性依据 `Properties / ItemStatCost` 与实例掷值；玩法接收类型化定义，不读取 MPQ。

| 类型 | 内容与边界 |
| --- | --- |
| 持久基础 | 等级、经验、四维已分配点、未用属性／技能点；学习和重置由角色规则校验 |
| 派生快照 | 四维、资源上限／恢复、移动与动作速度、伤害、准确率、防御、格挡、抗性等已支持字段；重新计算，不作为独立派生值编码 |
| 当前资源 | 生命、法力、耐力当前值；上限变化后裁剪，按原 D2S 支持字段保存 |
| 效果来源 | 有效装备、背包护身符、技能被动和临时状态；未核实属性可以展示原值，不假定已有战斗消费者 |

固定派生链：`职业起点 / 成长 / 分配 → 装备需求闭包 → 装备贡献 → 被动与临时状态 → 派生与当前值裁剪`。装备不能靠自身贡献满足自身需求；未鉴定、破损、空投掷堆叠、非当前武器组等有效性以现有装备规则为准。面板和战斗共用派生结果，不能维护第二份属性副本。

## 移动与操作

移动读 `WalkVelocity / RunVelocity / RunDrain` 及有效装备的快速移动、护甲 speed、耐力消耗和恢复属性。快速移动使用核实的原引擎递减公式；玩家位移、步行动画及脚步读取同一派生值。默认步行，R 切换走跑，按住 Ctrl 临时跑步；特殊技能移动有各自规则。

A／C 打开原 `invchar.dc6` 面板；显示已支持派生字段，左右伤害／准确率跟随当前技能，经验条取当前职业原阈值。红色按钮取 `level.dc6 / skillpoints.dc6`；加点只提交命令。布局根据原图、用户截图及 OpenDiablo2 面板核对，Inventory 表不提供角色文字位置。

## 保存与证据边界

当前仅原 D2S v96，恢复重新计算装备和派生，不保存临时效果。新增持久语义须核对原字段、同步规则与 [存档文档](../../modules/SAVES.md)，不升级到私有格式或静默迁移内部旧档。

已有 Windows 七职业外观、升级／加点、部分存读档及面板截图证据；这些有限检查不认证全部属性组合、长期战斗或 Linux。准确批次见 [角色模块](../../modules/CHARACTER.md)，技能和药剂效果分别由其专题维护。
