# 角色属性与成长

角色视图和请求归[角色模块](../../modules/CHARACTER.md)。本人身份、基础属性、等级、经验、资源、可用点和技能等级来自原服；升级／学习／加点不在客户端执行。

## 原数据与显示

- CharStats／PlayerClass提供职业显示、基础动作和参数，Experience提供原等级门槛；Expansion分隔行不占职业编号。
- ItemStatCost.ValShift用于原服资源／属性单位转换。原绝对stat覆盖较旧紧凑资源采样；经验0x1A／1B为正增量，0x1C为绝对值。
- 人物／技能／HUD消费同一projectCharacterDisplay；未收到属性显示 `?`，缺武器／装备输入不重算最终伤害、命中或格挡。
- 提示复用当前MPQ与纯属性／等级公式；预览不改变副本，不据本地计算补升级或奖励。

## 操作与保存

人物面板提交0x3A分配属性、技能树提交0x3B学习，资格按已知点数、职业、原reqlevel＋基础等级、前置及上限校验；最终结果等原服回包，超时未知，不自动重试。0x2C事件2仅播放原cursor_level_up表现。

R／底栏切换走跑，按住Ctrl临时跑步；选择保存在客户端偏好。资源消耗／回复由原服决定。角色持久化由D2GS／D2DBS，独立D2S值不连接产品成长或恢复。实际升级与任务奖励完整验收仍缺，见[联网记录](../../modules/NETWORK.md#既有有限证据)。
