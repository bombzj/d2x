# 经典底栏与技能选择

底栏使用完整经典 MPQ 的 `data/global/ui/panel/800ctrlpnl7.dc6`，以原始 800 像素布局整体缩放到窗口。左右技能槽、腰带、走跑按钮、耐力和球体共用 `hud_layout.hpp` 的坐标转换；不再常驻横排六张技能卡片。

## 单机／联机共用游戏界面

两种模式使用同一 `SceneView::drawUi`、`ViewState` 和 `SceneController` 面板处理。共用底板／球体／体力／经验、左右技能槽及选择器、技能树、人物／加点、背包／装备／武器组、腰带、私人箱、方块／金币、NPC菜单／对白、普通商店、传送点、任务日志、佣兵面板及Esc菜单；地面物品原图／标签／拾取热区、品质色和敌人血条也共用绘制。独立联网HUD已删除；多人mini panel只切换当前MPQ原图和八个按钮的排列，组队／聊天入口暂不可用。

本地模式由Local客户端接口提供状态；联机由 `client/remote_ui_clients.cpp` 将原服副本投影到同样的值契约，命令映射到既有RemoteInventory／RemoteCombat／RealmSession。联机面板不创建GameSession、不加载本地角色存档、不执行本地库存或成长事务。世界绘制现已统一到SceneView::drawWorld，自动地图统一到SceneView::drawAutomap；RemoteScene只提交表现输入，侧栏显示和命中区域共用，联机场景中心随面板宽度调整。最新源码把原MPQ基础弹体、施法叠层和原服状态叠层也接到同一SceneAssets缓存及SceneView绘制；这部分已Release构建并入包，底栏／营地／NPC对白／基础施法已有限截图检查，全部面板鼠标交互尚未逐项认证，范围见联网模块。

联机背包拖放、装备、转移、交换、镶嵌等组合操作先提交Take，等待原服实际分配光标物品且请求间隔允许后再提交后续请求；死亡／断线／拒绝／超时终止队列，不自动重试。显示只随服务端回包更新。技能选择、学习、属性加点、腰带使用、箱子／方块／金币、普通买卖／维修／鉴定均接原有命令入口；左右技能也接联机坐标／敌对怪物施放输入，回城卷轴／书右键接既有RemoteControl回城门接口。R／空格切换走跑，B展开腰带，I／A／S／Q与mini panel打开同一套面板。

原服未提供的属性显示`?`；攻击伤害／命中率和最终格挡率不套单机计算。商店尚未接原客户端精确价格算法，使用“由服务器决定价格”的提示，购买时原服核价；任务日志原位流尚未投影，用`?`明确未知，允许查看限制。佣兵资料／雇佣／复活／装备、交易／赌博、任务物品特殊服务仍待原协议接入，共用面板已保留但不会执行单机逻辑。联机F1–F8绑定仅为当前入局的客户端偏好，不宣称写入原服角色。联机菜单不暂停服务端世界，Save and Exit提交原服退局；死亡恢复尚缺原服流程，不执行单机复活。毒素球体／蓝色体力和物品染色、完整动作／飞行效果仍未认证。

地面标签的原字体、碰撞布局和品质色使用同一快照；金币数量来自原位流。地面图按当前Levels.Pal加载，敌人名称读当前MonStats.NameStr与TBL；怪物生命使用D2MOO MonsterMode的0–128刻度，仅0x0C命中包剥离暗金标志位，未知生命不填假值。原服尚未投影的精英／暗金独立名字、修饰词和完整落地动画暂缺。

布局参考本地OpenDiablo2 `hud.go`／`globeWidget.go`／`mini_panel.go`，包括单／多人mini panel和原图坐标；物品位置／光标流程参考D2MOO ItemMode／原协议。当前资源始终读取MPQ，不导入参考代码。Windows Release打包，不运行游戏、不执行冒烟或测试；功能和画面等待用户查看。协议边界见[联网模块](../../modules/NETWORK.md#共用游戏界面)。

## 球体与资源

旧实现先画球体、再画不透明面板，面板中的空球底图遮住了液体下半部，位置也未对齐。现在先使用球体原图轮廓遮住背后的世界，再画面板空球底图、按比例裁切的液体，最后画 `overlap.dc6` 的玻璃／手指前景。生命和法力分别读取 `hlthmana.dc6` 帧 0、1，裁切高度限制在 0～80 原始像素。

底栏、球体、按钮、技能图标使用原版 Sky 调色板；场景继续使用 Act1 调色板。腰带底行直接落在面板原有四个格子内，额外行使用 `ctrlpnl_popbelt.dc6`。

默认鼠标使用原 MPQ 的 `data/global/ui/cursor/ohand.dc6` 和 Units 调色板。游戏内与角色前端共用 `primitives.cpp::handCursorHotspot/cursorSprite`：按本地 OpenDiablo2 `gui_manager.go::renderCursor`／`animation.go::Render`，把普通手形的 `鼠标 + DC6 偏移 - 帧高` 转成纹理左上角坐标系的热点 `(-offsetX, height-offsetY)`。当前 MPQ 第 0 帧为 32×26、偏移 (-1,24)，故热点是 (1,2)，显示位置保持不变。此前误用 `gaunt.dc6` 后以边界颜色猜测透明索引的补丁已移除；正确图形使用 DC6 自身的透明像素。

鉴定卷轴／书使用原 `cursor/spells.dc6` 和 Units 调色板；帧号来自 Books.SpellIcon（当前 MPQ 鉴定为 0），其他物品读 Misc.spellicon，编号依据 D2MOO `ITEMS_GetSpellIcon` 和 `SKILLITEM_pSpell01_Initializer` 的 0x3F 目标光标请求。DC6 帧头有绘制偏移但没有独立热点字段；当前 MPQ 的九帧均为 32×33、X/Y 偏移均为 0。旧代码误套普通手形的减帧高规则，导致鉴定图案整体高于真实鼠标 33 像素。现按图案左上指向标记使用 (0,0) 热点，由共用 `cursorSprite` 直接在 `鼠标 - 热点` 处绘制原纹理，不再叠加 DC6 原点或扣整张图高。成功提交鉴定、右键／Esc 取消、关闭面板或来源卷轴／书失效后，随统一鉴定状态恢复普通指针及其热点。

显式热点接口参考本地 Diablerie `Engine/UI/SoftwareCursor.cs::SetCursor`：热点相对纹理左上角，缺省为零；其 `PlayerController.OnHandsItemChanged` 对手持物品另传图像中心，说明热点应由用途指定，不能把一个 DC6 绘制原点规则套到全部光标。此处 (0,0) 是上述接口与当前原图的适配，参考项目没有提供原版 D2Client 的完整目标光标热点表。库存拖动继续使用与目标占格一致的抓取偏移。2026-09-28 本次仅修改源码和文档，未构建、运行检查、测试或打包，等待用户画面验收。

正常游戏不常驻 D2X／MPQ 资源字样、等级调试文字或快捷键提示，这些保留在 Ctrl+F3 调试视图中；用于衬托顶部文字的黑色渐变已移除。Tab 开关角落地图，V 交换左右，默认关闭；细节与标记缺口见 [自动地图](../world/AUTOMAP.md)。

任务、角色、技能、交易、私人箱、方块和传送点侧栏复用 `classic_panel.hpp`／`panel_frame.cpp`。`800borderframe.dc6` 每侧五块大小不等，按 OpenDiablo2 `d2ui/frame.go` 的原坐标拼接，使用 Sky 调色板；不按等大方格拼接。每侧原尺寸 400×558，按可用高度等比例缩放并贴左右边缘，宽屏多出的宽度留给场景。内容与命中区域使用同一比例，场景中心随可见区域移动。

Q／红色 Quest Log 更新按钮进入任务日志，只显示已到达的第一幕页签；任务正文、剩余数、选中状态及已知边界见 [第一幕任务](../quests/ACT1.md)。这些侧栏和提示修改已构建；任务日志、商店、背包及 NPC 提示已在原 MPQ 运行中查看。

## 技能与操作

人物面板、技能树、技能菜单和HUD共用CharacterView：原服已知数据经projectCharacterDisplay和原character_display纯公式生成提示，不再有LocalCharacterClient／联机简化提示两条实现。已知法力、当前／下一等级、持续时间等沿MPQ定义显示，缺等级、装备或加成时对应数值显示“?”；未确认等级时Next Level不显示MAX。学习／消耗／伤害及任务奖励仍由原服处理。2026-10-07已统一Release构建／打包，未运行或冒烟；数值覆盖见[人物模块](../../modules/CHARACTER.md#本人-ui-投影)。

- 默认左右键普通攻击。点击左／右技能槽展开菜单，点击图标分配，点击外部、右键或 Esc 收起；选择菜单的鼠标手势不会继续施法或移动。
- 展开左／右技能菜单，悬停技能图标按 F1～F8 绑定到对应鼠标键；单按功能键只选择已绑定技能，不立即施法。技能 ID、图标、是否允许左键来自运行时 MPQ；绑定随当前存档保存。Shift + 左键可原地使用所选左技能。Ctrl+F1、Ctrl+F3、Ctrl+F4 分别为帮助、碰撞视图、走近储物箱。
- 左键候选项遵循 `Skills.txt` 的 `leftskill` 字段。点击怪物时使用左键技能，普通点击空地仍然移动。
- 左／右键首次按下怪物后按实体 ID 固定目标，按住期间继续对同一存活目标提交技能，鼠标移到空地、HUD 或侧栏不重新选敌。普通近战请求走近后执行一击，按住才继续请求；追击更新到怪物实时位置，不在路径用完前一直追旧落点。松键不追加下一次施法，已经开始的一次普通攻击／施法可完成；引导松键停止。目标死亡或失效后不自动改打光标下另一个目标，需松开再点。切换技能／武器、移动指令或模态界面中断当前锁定。
- 顶部怪物名字和血量条优先显示同一锁定目标，鼠标移开也继续更新；目标死亡／失效、松键、失焦、切换技能或换区后不保留旧锁定显示。没有锁定时沿用鼠标悬停选择。血量直接取当前怪物生命比例，不维护单独的缓存数值。
- 名称通过当前 MPQ `MonStats.NameStr`／`SuperUniques.Name` 查语言 TBL，不显示内部 ID、等级类型或替身调试文字。普通／随从白色、勇士蓝色、暗金／固定首领金色；白／蓝／金分类核对[暴雪怪物说明](https://classic.battle.net/diablo2exp/monsters/basics.shtml)，RGB 采用本地 OpenDiablo2 的 white／blue／gold token。顶部居中 Font16、150×20 基准、黑底及红色生命填充参考 Diablerie `EnemyBar.prefab`，长名扩宽。随机暗金独立姓名和词缀说明尚缺，使用其原底材怪物名称，不声称完整复刻客户端条目。
- 背包是非模态侧栏：打开时不提交停止移动、不清除锁定攻击、不禁用技能快捷键／技能菜单／腰带键，也不因面板存在而逐帧取消引导。未被面板遮挡的场景可继续点地移动、攻击、施法和悬停；普通面板热区消费鼠标，手持物品／鉴定／数量对话仍消费各自手势。依据 Diablerie `InventoryPanel.visible`、`PlayerController`、`MouseSelection` 的面板可见性与 `Ui.Hover` 分离。面板／弹窗／HUD 消费的左、右键按下持续归 UI 所有直到松开；在关闭或切换面板、场景视口改变前捕获归属，避免 X 关闭后仍按住或拖出界面触发移动／施法。该等待松键规则参考 `PlayerController.FlushInput/Update`，独立接入 `SceneController` 现有鼠标消费状态；覆盖角色、任务、技能树、佣兵、背包、储物、方块、商店、NPC、传送点及 mini panel。mini panel 的合成快捷键保留真实按下归属；松开后下一次按下重新判定，不额外吞掉场景点击。
- 技能选择菜单与底栏当前技能分别读取选择图标状态和当前施放状态：城镇禁施不把选择菜单的普通攻击／已拥有主动技能整片染红，底栏仍显示城镇禁施状态；Throw 无合格投掷武器或数量归零时显示红色，仍允许选择／绑定。本地未实现主动效果仍保留禁用提示。红色沿用原图乘色，未认证原版精确调色板；Diablerie `SkillInfo.GetPressedIcon` 的 `IconCel+1` 是按下帧，不作为禁用帧使用。
- 菜单按当前MPQ `SkillDesc.ListRow` 分行，跳过负行号；通用动作在底行，其余非空行向上排列。图标恢复48×48原尺寸并沿底栏比例缩放，左菜单向左对齐、右菜单向右对齐，技能ID从对应侧递增；同图的卷轴／书本候选按 `ListPool` 标记合并显示，普通攻击只显示一次。`SceneView::skillPickerSlots` 统一提供绘制、悬停、点击选择及F1–F8绑定的图标和热区。本地及联机均调用同一绘制与控制器，仅由各自客户端投影只读角色状态；依据用户两张对照截图、本地OpenDiablo2 `skill_select_panel.go` 与当前MPQ原表／图集。源码已随2026-10-06世界绘制批次Release构建并打包，未运行验证，画面待用户验收；完整充能／书本数量与目标光标规则未随此改动认证。
- 游戏中的 Esc 优先关闭当前面板／对话；没有待关闭面板时显示原 MPQ 三行菜单，世界暂停，默认选中 Return to Game。鼠标悬停或上下键选择，点击同项松开或 Enter 执行：Options进入原五行子菜单，Automap Options进入原地图设置页，Previous Menu返回上一级，各子菜单默认选中返回行，Esc关闭全部菜单；Save and Exit Game保存有归属角色并返回列表。地图设置的实现和Fade Auto／多人限制见[自动地图](../world/AUTOMAP.md)。声音／视频／配置控制入口尚未实现。保存失败保留原会话与菜单并显示错误；菜单内不透传玩法或快速读档按键。文字和选择标记读取原MPQ DC6，沿本地OpenDiablo2 escape_menu.go/d2gui双向旋转和选择规则适配。返回列表先销毁旧会话、视图和管道；返回游戏隔离菜单手势。角色列表的Back／Esc、关闭窗口及调试quit仍可退出程序。
- 左键从空地开始按住，只更新移动目的地，不在途中悬停怪物、物品或出口时自动切换操作；右键空地按住更新所选法术朝向。已锁定怪物的原法术在实际出手时读取目标当前位置，持续引导在模拟步中追踪单位；这些目标引用仅属当前角色运行状态，不进入 D2S。
- 1～4 饮药，B 展开腰带；点击走跑按钮或空格切换走跑；I 打开包裹。底栏中央原按钮开关单人 mini panel，使用原 MPQ 的 `minipanel_s.dc6`、`minipanelbtn.dc6` 和 `menubutton.dc6`；七个图标分别进入角色、背包、技能树、自动地图、消息、任务日志和游戏菜单。消息尚未实现，图标置灰并提示不可用；游戏菜单图标接与 Esc 相同的菜单。球体悬停显示当前值／上限。
- 走跑与 mini panel 的开关是客户端偏好，保存在运行目录的 `client-settings.json`，返回角色列表、进入另一角色及成功保存后重启客户端仍保持；它们不写入 D2S。首次运行默认步行并关闭 mini panel。配置采用原子替换，失败保留旧文件及待保存状态并限频重试，正常离开会话时补存；不可写时只能保留当前内存选择。该 JSON 是本项目的本地配置，不声称采用原版客户端的 ini 文件布局。
- 资料片背包手部槽位有 I／II 两组，点击两侧原标签或按 W 切换；装备属性、主动武器伤害、弹药和角色手部外观使用当前组，另一组保存在角色存档。左右鼠标技能选择在本局按武器组分别记住；F1–F8 快捷绑定仍为角色级记录。
- `A`／`C` 打开角色面板，`S`／`T` 打开当前职业三页技能树；未用属性／技能点出现时，底栏 MPQ 红色按钮分别进入对应面板。方向键辅助移动。`--skills` 启动时打开技能树。节点、图标、页签和学习门槛来自运行时 MPQ，详见 [七职业技能树](../skills/COMMON.md)。底栏经验条按当前级区间进度填充，悬停显示当前经验与下级阈值。

技能图标通过 `Skills.txt` 的技能名和 `skilldesc` 关联 `SkillDesc.txt` 的 `IconCel`；旧表有直接 IconCel 时仍支持读取。图集根据职业选取，普通攻击使用通用图集。缺少原始素材明确报错，不以自绘图标补齐。未实现的主动技能使用禁用色并提示效果未实现，指向敌人或空地都不执行替代攻击；已接入女巫四项被动，其余只记录点数。

## 传送点菜单
