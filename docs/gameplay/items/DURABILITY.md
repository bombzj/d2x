# 耐久、数量消耗与自恢复

更新：2026-10-09。本页维护物品耐久／数量恢复与战斗损耗；堆叠和书页归[INVENTORY](INVENTORY.md)，充能消耗归[物品技能](../skills/ITEM_SKILLS.md)，维修报价／扣款归[ECONOMY](ECONOMY.md)。

## 当前损耗与恢复

普通成功近战4%武器耐久损耗、防御命中10%加权防具损耗、Impale专有数量消耗、投掷数量和充能维修已接；不可摧毁／无形等条件沿原规则。耐久变化发原3E基础属性及必要资格更新。公共items/replenishment按原优先级先自修耐久，再补数量；未鉴定不禁自恢复，破损不自行修复。初次为整数除法2500/rate后再加1帧，后续取该值与125帧的较大值；无主地面恢复不伪造原主人3E，后续准入／拾取携带真实值。

基础最大耐久与实际属性修饰分开；无形、不可摧毁、损坏与活动装备资格沿原规则处理，实际最大值不在保存后再次累加。装备贡献见[EQUIPMENT](EQUIPMENT.md)，地面寿命与落地代次见[GROUND](GROUND.md)。

## 状态与缺口

items统一按GUID持恢复时钟，inventory负责本人库存的恢复提交；地面／本人转移延续时钟，删除原件清理时钟，运行时钟不写D2S或私有包。库存、装备、地面及商店维修的属性更新不能复用旧句柄，也不能让属性revision变化取消同一次落地的待拾取。

普通耐久维修、自补标枪和充能修理有有限代表证据，见[EVIDENCE](EVIDENCE.md)。全部手位／双持／投掷／品质／永久货架／死亡转移与背压、原服损耗概率和逐整数维修报价仍未全面认证；未完成的战斗来源不由本页假定实现。
