# 金币、钱包与仓库存取

更新：2026-10-09。本页维护金币作为人物余额和地面金堆的区别。所有金额、上限、扣费与最终余额由服务端决定；商店扣款归[ECONOMY](ECONOMY.md)，死亡惩罚的自研执行归[死亡领域](../../modules/SERVER_SYSTEMS.md#死亡与尸体)、原服显示见[人物死亡](../characters/PLAYER_DEATH.md)，地面寿命归[GROUND](GROUND.md)。

## 当前执行

原0x50丢金币同时规划钱包扣款与地面金堆；类型／最大堆数由ItemCatalog准备，必要时按上限拆堆。碰撞、世界容量或身份不足时不扣钱包，金堆与人物余额一次提交。普通拾取支持实际可接收量，满额余量留地，不因移除通知单独认定到账。

仓库存取沿原0x4F、原钱包／stashGoldLimit与有效私人箱授权，不能从未打开页面绕过校验。余额与上限相关显示只能使用已知原属性；0x19与绝对余额分别归并，2A服务金额不重复加到钱包。

## 缺口与证据

同局队伍分金与完整归属尚未实现，不能按多客户端存在自动分配。全部等级／容量／最大金堆、死亡与存取组合、多人争用／异常断线尚未完整验收。钱币不采用自选分堆私有协议。

原丢100金币并拾回等有限证据见[EVIDENCE](EVIDENCE.md)，保存字段及资格由[存档](../../modules/SAVES.md)负责。管理grant-gold只准备余额，不能代替正常交易／掉落／死亡扣款验证。
