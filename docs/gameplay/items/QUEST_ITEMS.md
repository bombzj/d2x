# 任务物品、奖励消耗与加工

更新：2026-10-09。本页维护物品一侧的任务携带／拾取、消耗与加工资格；个人阶段／奖励生产、机关与旅行由[任务系统](../quests/SYSTEM.md)链接各幕负责页。本页不复制任务流程和奖励位编码。

## 当前任务拾取

[inventory/ground.cpp](../../../src/server/systems/inventory/ground.cpp)的questPickup按当前MPQ questTag与准备的实际代码筛选，不把“任务物品”作为统一禁令。已开放第一幕树皮／译文、马勒斯、腿／方块；第二幕法杖材料／成杖、技能书，以及准备的第三至第五幕雕像／鸟／生命药剂、基德宾／古书、克林姆材料／意志、灵魂石／锤、解冻药／抗性卷轴等。其他未准备任务物品明确暂缓。

ItemMode::sub_6FC425F0／sub_6FC428F0核对完成记录与携带互斥，保留原questTag的交叉任务条件；仓库不计互斥，尸体与随身库存计入。已领取／已使用、个人难度与携带冲突复验后才拾取，不因为物品在地面就授予新的任务资格。

## 消耗与加工

技能书、生命药剂和抗性卷轴只消费当前难度已获得的一次性资格，奖励旗标、人物值与移除同笔提交；没有资格不消费、不发额外奖励。奖励数值与生产者分别见[第二幕](../quests/ACT2.md)和[第三至第五幕](../quests/ACT3_5.md)，不在物品页写第二份数值表。Token为普通配方／背包退款入口，不伪造Akara免费重置资格。

Charsi灌注、Larzuk打孔、Anya署名使用原38(action=0,npc,item)及7字节58；空Cursor先沿既有移物序列取原件，58是服务结果，不把9C／9D当领奖确认。联机菜单按原个人任务字的RewardPending显示，沿master已有选择界面与MPQ说明，两种服务端共用。服务端复验交谈revision、个人难度阶段及原物品资格；真实掷值、材料、任务阶段与产物一次提交，满背包按原落点落地，未授予任务奖励不能加工。

operation28法杖／连枷组装的材料与产物由[CUBE](CUBE.md)规划，quests拥有对应阶段；插杖、破珠、熔炉与其他任务机关消费各自真实条件，不由库存模块猜目标完成。牛门／Pandemonium材料与旅行事务也见CUBE，目的地怪物／任务完整度另由怪物目录和总计划维护。
