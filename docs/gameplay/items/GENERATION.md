# 基底、品质与实际物品生成

更新：2026-10-15。本页负责生成入口、基底／品质与实际掷值的冻结；词缀／属性程序归[AFFIXES](AFFIXES.md)，来源概率归[LOOT](LOOT.md)，配方输出归[CUBE](CUBE.md)。

## 当前品质范围

原品质1–8的劣质／普通／超强／魔法／套装／稀有／暗金／Crafted已有生成入口；网络品质通过公共映射转换，不把内部enum顺序当原编号。基底、等级、类型、可生成标记、专用品质记录、无形、自然孔、StaffMods、AutoMagic与实际属性由当前MPQ准备。暗金一次生成限制与失败暗金／套装耐久倍数属于生成与来源共同条件，不以显示名称推断。

品质9 Tempered已有导入／保存及原网络投影，不自行增加当前MPQ没有的生成配方；耳朵、身体部件及其他特殊身份见[SPECIAL](SPECIAL.md)。表行、解析支持与实际生成资格分开登记。

## 生成与身份

hosting/item_content与loot／merchant／crafting内容准备调用既有生成器，冻结随机、词缀、属性层、稀有名、孔内子项与特殊品质身份；新根／子GUID由领域安装时分配。UseItem加工可保留原宿主，复制／新产物须取得独立身份。装备、提示、报价与保存重入不重新滚属性；不存在“未知孔内seed=0重掷”旁路。

原基底Armor／Weapons／Misc和ItemTypes覆盖定义，不代表全部基底／品质／级别／属性组合已运行。缺实际身份、资源或规则明确拒绝／暂缓；参数与随机依据先参考master，再核对当前MPQ与本地D2MOO Items／ItemsMagic，数据入口见[DATA](DATA.md)。

## 待补范围

自然掉落已通过loot::reserveSeeds按实际产物序号从实例全局流预留单位／物品属性双种子，重试复用原种子对；TC／MF使用来源流，数量／耐久／防御／外观使用单位流，词缀／属性及后续StaffMods／无形／天然孔／AutoMagic使用物品流。品质失败恢复该阶段低种子与高字666，并更新物品起始种子；装备架首次未指定品质失败还执行原创建品质重投。自然耐久、劣质二次耐久投掷、超强整表拒绝抽样、增强防御基底、强制无形先于不可破坏、低基伤增强伤害回退已有源码适配。

仍不满足整局原版逐种子一致：内容准备位于宿主advance之后，物品落点在生成后批量安装，而原版在出生前检查落点并在原事件时点消费全局随机；需要将完整准备后的物品规则迁入同帧服务端生成及原生逐件落点提交。原单位GUID／房间链、箱子对象控制流、全部强制任务／网络模式资格、原表全组合及原1.13c数值边界仍未完成逐项认证。当前双流接线不能代替这些时序与来源条件，不宣称完整精确一致。

逐操作掷值只在生成准备中临时存在，冻结后清除，沿已有原属性保存；旧物品不重掷。商店／任务／赌博／方块复用逐操作属性求值，各来源的整体随机顺序仍待原版对齐。

本地管理item-spawn已提供固定seed、显式Magic／Rare词缀、原范围内掷值，以及按Properties目标自动匹配合法词缀组合的properties模式。propertyQuery只读列候选与范围，preview完整准备及原D2S编码校验但不落地；实际生成复用同一冻结／地面安装入口。目标匹配不允许任意stat注入，不能用它改写暗金／套装固定身份；附带词缀／StaffMods／AutoMagic保留并返回实际属性。参数与限制见[调试管道](../../development/DEBUG_PIPE.md#按目标属性生成)。这是条件准备工具，不提供自然掉落概率依据；未改变存档格式，旧物品不重掷，全部来源／目标组合仍待核对。

完整特殊品质、全部职业专用变体、唯一物品重复边界、所有生成来源、难度／人数／MF组合与原随机流顺序仍待逐项对齐；定义导入或生成入口存在不代表全表行为已闭合。
