# 基底、品质与实际物品生成

更新：2026-10-09。本页负责生成入口、基底／品质与实际掷值的冻结；词缀／属性程序归[AFFIXES](AFFIXES.md)，来源概率归[LOOT](LOOT.md)，配方输出归[CUBE](CUBE.md)。

## 当前品质范围

原品质1–8的劣质／普通／超强／魔法／套装／稀有／暗金／Crafted已有生成入口；网络品质通过公共映射转换，不把内部enum顺序当原编号。基底、等级、类型、可生成标记、专用品质记录、无形、自然孔、StaffMods、AutoMagic与实际属性由当前MPQ准备。暗金一次生成限制与失败暗金／套装耐久倍数属于生成与来源共同条件，不以显示名称推断。

品质9 Tempered已有导入／保存及原网络投影，不自行增加当前MPQ没有的生成配方；耳朵、身体部件及其他特殊身份见[SPECIAL](SPECIAL.md)。表行、解析支持与实际生成资格分开登记。

## 生成与身份

hosting/item_content与loot／merchant／crafting内容准备调用既有生成器，冻结随机、词缀、属性层、稀有名、孔内子项与特殊品质身份；新根／子GUID由领域安装时分配。UseItem加工可保留原宿主，复制／新产物须取得独立身份。装备、提示、报价与保存重入不重新滚属性；不存在“未知孔内seed=0重掷”旁路。

原基底Armor／Weapons／Misc和ItemTypes覆盖定义，不代表全部基底／品质／级别／属性组合已运行。缺实际身份、资源或规则明确拒绝／暂缓；参数与随机依据先参考master，再核对当前MPQ与本地D2MOO Items／ItemsMagic，数据入口见[DATA](DATA.md)。

## 待补范围

当前生成器尚不满足原版逐种子一致：TC与品质之后的词缀／特殊属性仍推进来源随机流，prepareItem随后另取种子生成基础值。原版SUNIT_AllocUnitData从实例全局流分别建立单位种子与物品属性种子；基础数量／耐久／防御／外观使用单位流，词缀等使用物品流。精确接线需由实例随机与单位出生公共接口提供两个已预留种子，不能在异步内容准备中读取／回写共享实例流。当前满耐久初始化、StaffMods／无形／天然孔／AutoMagic阶段顺序、失败品质重置物品低种子并重置高字666，以及Properties各操作的独立随机／覆盖语义仍待完整迁移。不能将概率局部修正或可复现管理seed等同于原版整件物品一致。

本地管理item-spawn已提供固定seed及显式Magic／Rare词缀、原范围内掷值，走现有生成／冻结／地面安装入口；参数见[调试管道](../../development/DEBUG_PIPE.md)。这是条件准备工具，不是自然掉落概率证据；未改变存档格式，旧物品不重掷。

完整特殊品质、全部职业专用变体、唯一物品重复边界、所有生成来源、难度／人数／MF组合与原随机流顺序未全面认证。已有普通／Crafted／AutoMagic／暗金／套装代表路径只见[EVIDENCE](EVIDENCE.md)，不扩大为全表验收。
