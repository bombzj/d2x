# 掉落来源、TC与品质选择

更新：2026-10-12。本页负责掉落来源、TC、人数／MF／GF及首杀选择；实际物品生成归[GENERATION](GENERATION.md)，地面安装／拾取归[GROUND](GROUND.md)，任务专属来源资格归任务专题。

## 当前执行

普通TC、正负Picks、层级升级、品质／MF／GF、暗金一次生成限制、失败暗金／套装耐久倍数与装备架路径共用旧单机迁入的生成器。NoDrop采用原有效人数指数和怪物生成时人数上限；已入场人数包含死亡玩家，同区域存活队友提供完整人数贡献，其他玩家／虚拟人数按原折半规则处理，不以近距离代替同区域资格。

佣兵近战、技能、毒及伤口击杀沿实际来源记录佣兵MF／GF，再叠加主人的贡献；主人自己击杀不叠加佣兵装备。死亡时冻结佣兵贡献，后续移走装备或离开不改写已经排队的掉落。依据为D2MOO Items::ITEMS_DropItemByMonster；全面概率和各杀伤来源尚未逐项运行认证。

loot在死亡奖励结算时捕获真实怪物身份、rank、受益角色、MF／GF及独立种子，零经验死亡也可提交掉落准备。hosting复用master的resolveMonsterLoot／planItemLoot、原TC及物品生成步骤；有界准备同一来源只接受一次，失败／背压不重新取种子，成功产物进入items地面库存。安装前预先分配唯一物品记账与物件完成值，权威提交后只交换准备结果，不在已消耗钥匙／落地后才分配记账。

原NoDrop产生空批次时正常完成，不申请零条事件容量。野蛮人尸体搜索等待同一来源的原死亡掉落结算；Find Potion按原幕／难度药水表生成，Find Item沿真实怪物TC并在各层忽略NoDrop，成功或失败搜索均提交消耗与尸体禁止重用。规则和代表证据见[野蛮人](../skills/BARBARIAN.md)。

普通箱桶、可搜寻物件与装备架有各自来源准备；钥匙、物件状态和掉落安装须同一提交边界成功。任务固定物品或奖励不靠普通TC替代，门／宝箱／物件机关仍由[OBJECTS](../world/OBJECTS.md)持有。

首杀TC读取MonStats的TCQuestId／TCQuestCP及击杀时个人原任务字，不因异步生成或之后任务变化重新选择TC。来源准备不是首杀资格完整验收；替身保留真实身份也不认证真实Boss战斗或任务掉落组合。

## 待补范围与台账

2026-10-15源码按D2MOO DropTC将Picks=0作为一次选择；真实怪物身份hellbovine沿hosting/loot_content传入特殊品质选择，允许Sets原ID29的奶牛专属候选，其他来源仍排除。词缀概率修正及1.13c静态依据见[AFFIXES](AFFIXES.md)。这些改动未构建／运行，不表示全部来源或随机序列已与原版一致。

每个TC／来源登记区域／难度、等级、rank／固定身份、任务资格、人数／队伍、MF／GF、随机与输出／证据。完整近队友NoDrop、组队经验／归属、全部首杀／任务／特殊奖励、特殊箱／陷阱来源及全概率组合尚未完成或认证。来源未准备明确暂缓，不自行填写概率。

当前有限自然掉落／箱桶／TC代表路径见[EVIDENCE](EVIDENCE.md)；资源工具报告和管理员item-spawn不认证自然掉落。数据／原函数入口见[DATA](DATA.md)和[参考设计](../../architecture/REFERENCE_DESIGN.md)。
