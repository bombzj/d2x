# 掉落来源、TC与品质选择

更新：2026-10-09。本页负责掉落来源、TC、人数／MF／GF及首杀选择；实际物品生成归[GENERATION](GENERATION.md)，地面安装／拾取归[GROUND](GROUND.md)，任务专属来源资格归任务专题。

## 当前执行

普通TC、正负Picks、层级升级、品质／MF／GF、暗金一次生成限制、失败暗金／套装耐久倍数与装备架路径共用旧单机迁入的生成器。NoDrop采用原有效人数指数和怪物生成时人数上限；当前未建立队伍，因此没有近队友的额外人数贡献。

loot在死亡奖励结算时捕获真实怪物身份、rank、受益角色、MF／GF及独立种子，零经验死亡也可提交掉落准备。hosting复用master的resolveMonsterLoot／planItemLoot、原TC及物品生成步骤；有界准备同一来源只接受一次，失败／背压不重新取种子，成功产物进入items地面库存。安装前预先分配唯一物品记账与物件完成值，权威提交后只交换准备结果，不在已消耗钥匙／落地后才分配记账。

普通箱桶、可搜寻物件与装备架有各自来源准备；钥匙、物件状态和掉落安装须同一提交边界成功。任务固定物品或奖励不靠普通TC替代，门／宝箱／物件机关仍由[OBJECTS](../world/OBJECTS.md)持有。

首杀TC读取MonStats的TCQuestId／TCQuestCP及击杀时个人原任务字，不因异步生成或之后任务变化重新选择TC。来源准备不是首杀资格完整验收；替身保留真实身份也不认证真实Boss战斗或任务掉落组合。
