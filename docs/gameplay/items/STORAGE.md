# 私人储物箱

私人储物箱与赫拉迪克方块是不同容器。野外宝箱属于可交互物体，见 [野外物体](../world/OBJECTS.md)；方块见 [方块与金币](CUBE_AND_GOLD.md)。

## 使用

- 营地点击地图中已有的 `Private Stash`，或按 `Ctrl+F4`，人物自动走近后打开。远处不能直接存取。`Ctrl+F4` 是本项目的便捷导航键，不是声称原版使用这一按键。
- 左侧为原版私人储物箱，右侧为包裹。资料片读取 `tradestash.dc6` 与 `inventory.txt` 的 Big Bank Page 1，使用 6×8 格。存放的都是同一份权威物品实例，不创建界面副本。箱子上方第一条金币栏显示箱内金额，点击可取钱；点击右侧包裹金币栏可存钱。第二条显示箱子金币上限。
- 在两侧之间拖动，支持矩形占格、双方交换、同类堆叠合并、Ctrl 明确交换以及红绿预览。
- 储物箱打开期间，Shift 点击包裹／储物箱物品，会向另一边整件转移，先填兼容堆叠，再放剩余数量。整体容纳不了则全部不动。
- 选中箱内堆叠后，右侧 `SPLIT` 可在箱内拆分；来源容器没有完整空格则拒绝。药剂和腰带装备必须取出到包裹才能使用／穿戴。
- `I`、Esc 或任一面板关闭按钮关闭两侧；存在拖动／拆分手势时 Esc 先取消手势。也可以拖到两面板之间的世界区域丢到人物脚边。
- 离开操作范围、死亡、旅行、重置都会撤销储物箱访问，旧操作不能继续使用旧授权。面板打开不暂停世界；P 开发暂停已移除。
- 箱内物品在旅行、关闭再打开及存读档之后保留。

普通启动参数 `--stash` 会发出与 Ctrl+F4 相同的靠近／交互命令，不传送人物、不添加物品、不绕过距离或权限。适合直接进入整理流程；初始区域必须包含原始储物箱实体。

## 代码边界

| 模块 | 职责 |
| --- | --- |
| `world/region.hpp/.cpp` | 只读场景组装，按 DS1 的物件序号、坐标和预设建立实体；读取 MPQ objects.txt 的储物箱操作距离 |
| `gameplay/session/session_interaction.cpp` | 可取消的走近交互、距离与通路校验、临时 StorageAccess 授权及撤销；NPC 交互也不再远程触发 |
| `gameplay/items/collection.cpp` | 通用整件转移计划／提交，供拾取和储物箱共享，预览与执行使用同一计划函数 |
| `presentation/inventory/container_grid.hpp` | 仅处理任意容器的网格几何、格子命中和物品矩形，无存取规则 |
| `presentation/inventory/container_view.cpp` | 包裹、储物箱共用物品格绘制、数量及高亮 |
| `presentation/inventory/inventory_panel.cpp` | 当前可见容器注册和通用拖放意图，不再写死只向包裹移动 |
| `presentation/inventory/storage_view.cpp` | MPQ 储物箱面板及按钮绘制 |

`GameSession` 保留协调职责，资源加载、场景构造和交互实现已分离。`LootSystem` 接受数据型 `LootRequest`，不依赖战斗事件类型；野外宝箱的世界状态与 TC 掉落独立于私人箱容器，规则见 [交互物件](../world/OBJECTS.md)。

`TransferItem` 只携带来源 ID／版本和目标容器 ID。会话生成权限，物品层先规划所有目标堆叠和剩余占格、分配事件，之后才修改实例。没有为了储物箱复制一套堆叠规则。

`StorageAccess` 属于会话的临时授权；`InventoryState` 是持久物品状态，两者不能混用。原 D2S 保存已支持物品字段与容器位置，运行 ID／版本在恢复时重新建立；恢复时按当前 MPQ 的箱子尺寸校验，不恢复未经重新验证的“已打开箱子”授权。`WorldObject.contentKey` 为同一版本 DS1 中的物件序号，和区域／地图路径一起识别内容，不保证不同地图版本之间自动兼容。

## 原版素材与当前边界

私人箱子实体使用原 DS1 中的对象 102 → b6，位置没有移动；画面仍来自原版 COF/DCC。资料片界面从 MPQ 读取 `data/global/ui/panel/tradestash.dc6`，网格来自 `inventory.txt` Big Bank Page 1：6×8、29 像素单元、原坐标 74／82。操作距离由当前 MPQ `objects.txt` 的 bank 记录读取。

没有用新素材替换空白／缺失资源；缺少对应模式的原始面板会给出资源错误。金币存取已接入，点击包裹／箱内金币栏输入数额。按用户原版截图补上共用石雕外框、Units 调色板的 `goldcoinbtn.dc6` 金币按钮和 `buysellbtn.dc6` 关闭按钮；两侧与任务日志共用原比例，金币数和上限文字放回原栏。共享箱、额外箱页尚未实现，金币上限仍按当前规则，未根据截图人物的未知等级修改数值。赫拉迪克方块见 [方块与金币](CUBE_AND_GOLD.md)。

旧阶段的 Windows 构建及 `--stash` 截图观察过寻路、距离授权和原资料片 6×8 面板；本次外框／金币按钮调整已构建；本轮尚未实际覆盖箱子全部交互。存取／交换／满箱键鼠流程尚待人工验收，Linux 尚未实际编译运行。
