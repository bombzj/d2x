# 方块配方、材料与特殊门

更新：2026-10-12。本页负责CubeMain配方、授权、材料／输出与特殊门准备。原服和自研宿主使用同一原包客户端；物品尺寸、方块格子／原图来自当前MPQ。堆叠／书本归[库存](INVENTORY.md)，金额归[金币](GOLD.md)，镶嵌归[SOCKETS](SOCKETS.md)。

## 请求与授权

背包方块按pSpell=7提交打开，原77确认后开放3×4格。合成须已打开、持有方块、空Cursor及有材料，发送4F子24；关闭为子23。自研inventory保有Cube授权，死亡／换区／移走方块即失效；stash授权独立。位置响应的page为InvPage+1，放置请求使用原page=3。

原0x2A直接入方块支持Cursor及地面来源，第二个GUID必须是本人的已存放方块；自动找空格与物品移动同笔提交，不因未打开方块拒绝原版的直接放置，也不借此授予合成授权。地面来源仍校验区域、距离、碰撞、携带资格及当前身份。客户端发送层已修正仅远端配置才豁免地面来源归属的错误，零售同样允许这条原路径；依据PlrMsg::Rcv0x2A／sub_6FC86520的IMODE_ONGROUND分支与ItemMode::sub_6FC49DC0，目标方块归属和revision检查保留。

## 自研配方准备与提交

单机／TCP-IP沿原PlrTrade资格允许CubeMain的Ladder标记配方；原Realm的Ladder资格不由本地推测。

既有MPQ导入统计为146条启用配方、其中36条Crafted；实际条目以当前挂载表为准，统计不代表每条配方可执行或已验收。hosting/crafting_content按输入类型／代码、品质、孔数、无形、数量、难度、职业和原表顺序匹配；输出等级／词缀、升级、修复／充能、打孔、去孔、属性增改取原表。旧单机匹配与属性计算提取成公共函数，Crafted需求沿原品质8规则。

所有材料及输出在一个transactions库存事务提交；重新复验revision和容器资格，全部输出先确认能放下。失败不扣材料，背压不重取随机种子。原UseItem保留宿主GUID及真实子项；copy和新产物分配新根／子GUID，不允许多个输出占用同一原件身份。镶嵌保留宿主GUID，消费Cursor原件，按真实顺序检测符文之语。保存不重新滚词缀、宝石或条件套装值。

修复／补量的`useitem,rep,qty`按基底最大数量加实际`item_extra_stack`截取，书本不套投掷补量规则；`useitem`保留原品质及等级，劣质转普通使用原表`usetype`重新生成。Properties函数12／13／36可用于输出属性，18仍明确暂缓。

## 明确边界

operation28已接原赫拉迪克法杖／克林姆连枷组装和个人任务阶段，同笔提交材料、产物及任务事实。牛门经travel准备真实目的地图及原Objects红门，成功后才提交材料消耗与公共双向门；地图失败保留材料，容量背压保留请求和种子。牛门按普通／噩梦／地狱个人巴尔完成及牛王记录。本机零售1.13c的方块特殊输出表RVA FA5E8，第2／3项为70180／70170，均xor eax,eax;ret；钥匙门／最终门因此按原空分支完成本次请求，不消耗材料、不准备地图或创建门。实际MPQ两条配方同用op28；现已在配方匹配后、法杖／连枷任务组装及产物准备前识别零售空输出，避免误报Unknown original quest assembly。op28的材料难度资格仍在匹配时检查，复用当前MPQ nativeItemSave规则的quest＋questdiffcheck，不将全部任务物品一律当成带难度限制；依据D2MOO PLRTRADE_CheckCubeInput及PLRTRADE_CreateCubeOutputs的输出函数／成功后消费顺序。D2MOO带D2_VERSION_HAS_UBERS的1.14d扩展不是该版本依据。PD2仍使用已有专用门户准备及本局集合限制；地图准备不等于目的地怪物和任务已实现。零售钥匙样本已复现上述旧错误并验证修复后的无消耗分支，剩余验收见[缺口清单](../../development/ORIGINAL_GAPS.md#待验收方块)。

零售4F／24无通用结果包，匹配不到配方及空输出均可能没有物品更新。客户端现按SentNoAck记录发送，只有实际材料／产物事实才变为Updated，不因缺回包误报15秒超时，也不假定合成成功或自动重发。为保留原同步调用顺序，零售宿主在异步准备／输出等待时保留当前合成命令和受理结果，完成后不重新execute，后续命令与固定帧继续；暂停、退局和保存保留这个边界。此适配不新增玩法或存档字段；PD2仍沿原有请求门禁。新增继续点已通过Windows Release构建、三难度空输出重复请求、正常El升级、同帧合成后丢金及未执行即退出后的实际重入检查；普通难度牛门材料一次消费并经真实红门进入39区。其余验收见上述缺口清单；强制输出背压、其他牛门资格与跨客户端顺序仍待验证。

Token背包使用与一次性任务消耗归[QUEST_ITEMS](QUEST_ITEMS.md)，不伪造Akara免费重置资格。五幕个人任务的实现范围、原版依据与缺口由各幕任务页维护；牛王资格写入、目标版本未启用的Pandemonium分支不移植后续版本出生／奖励；完整世界活动与多人仍有独立核对边界，生成门户不认证这些依赖。

普通／Crafted、任务材料组装和Token已有执行入口；第三幕三器官／完整方块链、特殊门、全部配方／输出组合、三难度、多人和背压仍须逐项对齐。依据为master迁入参考、当前MPQ及本地D2MOO CubeParser、PlrTrade、ItemsMagic／Items。后续按每条CubeMain输入／operation／输出登记客户端／服务端实现、原版依据、已知差异与待核实项，不因匹配或导入成功批量标完成。
