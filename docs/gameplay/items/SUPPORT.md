# 物品显示与联机支持

原表导入、协议解码、提示和操作分别有边界；不能用旧单机“生成／保存成功”认定当前联机属性或服务已完成。当前请求范围见[库存模块](../../modules/INVENTORY.md)及[命令](../../development/DEBUG_PIPE.md#联网物品操作)。

## 已接入口

普通物品、品质／词缀、数量、耐久、防御、孔数、孔内／套装／符文之语列表、个性化名字等通过原位流及当前MPQ读取。面板与地面共用item_display；原图从invfile／flippyfile等实际字段选择，地面动画与背包图标分别缓存，地面原flippy恢复原25Hz播放一次停末帧；原action=2／新mode=5触发，普通地面同步不重播，mode=5仍不可拾取。品质编号映射、已鉴定特殊图覆盖与动画恢复仅在当前源码，尚未构建、运行或打包，旧包仍有品质错位及末帧静态显示。掉落何时出现取原服物品事件，不等附近怪物完整死亡动画。

宝石、符文、jewel及符文之语保留真实身份、顺序与原属性列表，显示／独立编码不重掷属性。carry1、任务互斥、职业需求和效果最终由原服决定；客户端只有已知资格检查，不能用旧执行器修正库存。

## 缺口

物品掉落声音由公共 SoundCatalog／SceneAudio 消费 ItemDropSoundEvent：原 item_flippy 在翻转起始播放，物品落地音读取当前 Weapons／Armor／Misc 的 dropsound／dropsfxframe（25Hz），已知暗金／套装索引使用原覆盖字段；未鉴定缺索引沿用已知基础配置。普通地面快照、属性更新及已消费事件不重播，过期或屏外事件跳过；缺声组／触发帧明确记录诊断，不使用替代 WAV。

拾取反馈覆盖同 GUID 进入本人容器／Cursor、金币堆移除且已知钱包增加、自动合堆、卷轴／书入书，以及手动合堆／卷轴入书。数量反馈以请求前已知基线及原服两侧变化核对，分包尚未对齐不提前报告；自动合堆后剩余物品进入本人容器时计入整次拾取，部分合入只提示确认增量，连续通知按顺序消费。Updated 仍不是 ACK，单独移除或属性变化不证明成功；初始快照、区域切换、死亡及中断不延续旧跟踪。上述音效／数量反馈仅在当前源码，未构建、运行或打包。

- 原特殊名称、全部说明函数、完整装备属性／技能来源、染色／孔位叠层和组合提示仍有限；缺少请求前基线、请求被替换／中断、过期或多人分金的数量关联仍不推断成功。完整空间音频与声音时序尚未人工验收。
- 未支持Properties函数、装备触发／充能、PvP／佣兵消费者不能据导入成功标为完成。
- 精确价格、赌博／多买、分堆、玩家交易、佣兵装备及任务物品特殊服务未完成。
- 未知或截断位流decoded=false并给reason，禁止操作；缺原图明确报告，不用几何物品替身。

独立存档的耳朵／自动词缀／Realm段及其他拒绝边界见[存档](../../modules/SAVES.md)，不是网络解码支持清单。有限原服库存／服务证据见[联网记录](../../modules/NETWORK.md#既有有限证据)，不认证全部物品组合或属性消费者。
