# 物品显示与联机支持

原表导入、协议解码、服务端执行和存档分别核对。当前两种服务端共用一套客户端；执行范围见[库存模块](../../modules/INVENTORY.md)，原请求见[命令](../../development/DEBUG_PIPE.md#联网物品操作)。

## 已接显示与反馈

普通物品、品质／词缀、数量、耐久、防御、孔数、孔内／套装／符文之语列表、自动词缀及个性化名字按原位流和当前MPQ读取。面板和地面共用item_display；已鉴定暗金／套装才使用真实fileIndex及特殊原图，未鉴定不推测第0行。网络品质显式转换，Tempered可解码显示但不代表D2S可保存。

地面flippy按原25Hz播放一次停末帧；action=2／新mode=5触发，静态快照和属性更新不重播，mode=5不可拾取。怪物／物件新生掉落和手动丢弃使用同一事实与原包入口。原item_flippy起始声、dropsound／dropsfxframe落地声由SoundCatalog和SceneAudio消费；缺声组或帧给诊断，不使用替代WAV。

拾取反馈核对请求前同GUID、所有权、钱包或合堆／装书两侧数量变化；单独移除、Updated、分包未对齐或未知属性不提前报告。初始快照、死亡、切区、中断不延续旧跟踪。连续通知有界排队；金币多人分配或缺基线不推测成功。

## 限制

- 原特殊名称、全部说明函数、染色／逐组件透明、孔位叠层及组合提示仍有限；库存无形图标alpha效果未认证原版逐像素一致。
- 普通／赌博买卖、维修和Shift批量请求使用原协议；完整原服报价逐整数一致性及全部组合未认证。
- 装备触发／充能施法、佣兵消费者、任务加工和自研玩家交易尚未接；属性列表能解码不等于效果执行。
- 原0x22不提供自选分堆；未知／截断位流decoded=false并禁止操作，缺原图明确报告。
- 音频时序听验、三难度、多人、全部随机分支不由有限冒烟替代。
