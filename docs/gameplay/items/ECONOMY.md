# 商店、赌博、维修与价格

更新：2026-10-10。本页负责物品经济的权威货架、报价、成交与周期；客户端商店交互见[NPC交易](../npc/TRADE.md)，加工奖励资格见[QUEST_ITEMS](QUEST_ITEMS.md)，维修恢复规则见[DURABILITY](DURABILITY.md)。

## 货架与成交

商店共享有限／永久库存；可转售原件保留属性并复制为新的NPC货架GUID，买入再分配本人新根／子GUID，保留已分配属性及套装规则。购买复制及批量复制每个单位消费两次游戏随机；身份和随机候选在成交接受后发布，不因可靠输出背压提前推进。完整v96复制与失败副作用仍未认证。全部玩家离开原城镇后刷新普通货架；240000ms原周期转换为6000个权威帧，只标记待刷新，下次单人交谈重新打开时准备货架，有其他观察者时保持原库存。merchant.step已进入固定步，不依赖客户端打开触发清理。赌博为各玩家独立预生成14件隐藏货品，实际品质不泄漏给客户端；原交易类型2购买。原0x32 mode高位multibuy支持Shift购买：药剂填腰带、卷轴填书、堆叠物填可兼容堆叠剩余容量，资金不足按可买数量处理；赌博不批量购买。

merchant准备请求及打开货架绑定交谈revision，持续复验NPC距离／视线、人物／区域代次；关闭／重开同一NPC、死亡／换区／离线使旧请求失效。成交前复验商品、库存及人物版本；出站背压保留待成交请求／种子，失败不会先扣金币或先移物。

后续源码把库存生成拆为NPCControl与实际物品双种子：普通数量、品质请求、难度升级及赌博等级／基础类型／升级／品质请求消费控制流；逐件调用公共指定品质构造，用游戏流的单位／属性双种子准备物品，不再为每次菜单派生独立子流。商店构造禁用自然无形但保留自然孔；普通商品保留最多五次Cracked重试，赌博只尝试一次。失败构造仍占候选身份序号；库存、两条随机流及GUID游标在通知接受后共同发布，过期候选重新准备，复用库存不额外消费随机。赌博首两槽固定rin／amu但仍消费基础选型随机；升级及品质概率按零售32位有符号正值门控，非正概率不抽签。

货架尺寸读取当前Inventory的Monster记录，各商店页独立占位：单行物品从右列向左列、每列自上向下，多行物品从左列向右列、每列自上向下。普通页1满后改试页2，失败计入原生成失败数；赌博满页停止后续生成。页号及格坐标经权威库存、原包和只读界面保留，不由界面重新排列。普通商品基础类型变化时丢弃并以普通品质再试一轮，每轮最多五次Cracked。限量唯一标记保留已构造但被丢弃的候选。普通难度保留各幕等级上限，其他难度以人物等级加五生成，不提前截断到99。

卖回资格排除Cracked、破损、玩家身体部件、个性化、无形、已镶子物品、carry1唯一、商人永久品及噩梦／地狱指定高级药剂；赌博交谈不回售。可复制原件按同一货架搜索放置，满架丢弃复制品但不拒绝出售；复制申请的新GUID及两次游戏随机消费随成交提交，背压重试不预先推进。完整v96复制副作用与物品再生事件仍未闭合。

赌博目录先排序完整MPQ表再取等级前缀；同等级顺序按零售内部排序的中值分区、等值跳过及最多八项的小区间选最大值交换，不用稳定排序或当前平台CRT。静态依据为1.13c D2Common VA6FDC2C50加载、6FD51BB0排序、6FD51B40小区间和6FDC12D0等级比较器；升级助手D2Game VA6FCDD040–6FCDD15D使用jle／jge，修正D2MOO反编译uint32类型导致的负概率错误，品质门控见6FCDE47F–6FCDE4DB。

同等级完整目录的种子轨迹、全部物品创建失败副作用及NPC服务的完整调用时点仍待对齐；目录按原可生成／商人数量条件保留，实际构造后才检查商店页。物品公共构造程序自身的未闭合边界仍有效，不能据双流接线宣称库存逐随机一致。

普通买卖、回购、赌博、批量、耐久／投掷数量／充能维修和Cain批量鉴定已有事务入口；出售覆盖本人背包、装备及Cursor原件，修订号封顶拒绝。服务端从实际商品、人物及原折扣重算，不信客户端金额。全人物离城刷新与定时待刷新属于NPC实例货架，赌博为个人状态，不持久化到人物D2S。鉴定目标规则见[IDENTIFICATION](IDENTIFICATION.md)。

单件维修的总金币不足时，按SUnitNpc的10位单位成本尝试部分维修：只消耗随身金币增加耐久，不恢复充能／堆叠，也不修复破损原件；能付全价时才按随身、银行顺序完成维修。原版Host有限对照为耐久3/7、报价12、随身5金币，成交后4/7且随身为0；不足一个单位成本则失败。成功维修的2A item字段为FFFFFFFF，耐久更新仍指向实际原件。

购买未合并的新原件时，按原拾取装备规则尝试空槽自动装备，条件不满足再放腰带／背包；2A成功回执使用新购原件GUID及原版1.13c录包的flags4，不能回指货架原GUID。入书／合堆回执仍指向被增加数量的原件。

自动装备只排除未鉴定原件及原版Missile Potion（类型tpot），不能排除包含箭／弩矢的整个Missile（misl）类型族；弹药还需按MPQ Quiver／Shoots与已装备武器匹配。购买和拾取共用`inventory::Draft::autoEquip`。依据D2MOO ItemMode::sub_6FC42F20及原版先买Short Bow、再买箭矢自动装另一手的有限对照。

金币不足及失效上下文等拒绝回执使用item=FFFFFFFF、flags=0，不回指请求中的商品；成功买卖仍按其原结果携带物品。依据为D2MOO SUnitNpc的购买、出售、修理失败出口及原版1.13c Host随身0金币购买30金币hp1的result12实包。自动安置共用库存`Draft::space`的D2Common加权搜索：一行物品从右下按列扫描，多行物品从左上按行扫描，优先贴合已有物品或边界，同权重保留先到格；腰带另用原匹配列规则。不是商店／药剂专属坐标策略。

## 公共报价与原版依据

itemTradePrice／itemGamblePrice两端共用，只对完整已知值报价。自动词缀、未鉴定、StaffMods、词缀、孔内、符文之语、触发／充能、按时间属性、耳朵／身体部件、自修复与投掷售价按原字段计算。未知孔内掷值不以seed=0重掷。原1.13c D2Common MD5 EE1238806EF6D6D9801D12A09D128FE1提供整数顺序补证：RVA 0x29947–0x2996f自修复，0x29beb–0x29bfb投掷售价，0x258d2–0x25934充能成本；书本按Books索引核对配对及CostPerCharge。

报价程序共享不代表客户端可见未鉴定隐藏属性，未知报价不能填0当真实价格。原包／2A成功条件见[PRESENTATION](PRESENTATION.md)，服务请求与Cursor组合见NPC交易页。原规则依据为master、当前MPQ及D2MOO SUnitNpc／SUnitProxy、Items／ItemsMagic／PlrTrade。

## 玩家交易与其他缺口

玩家交易由独立server/trade执行双方物品／金币交换、确认锁、取消及断线恢复，客户端共用原包及面板。规则、当前MPQ尺寸、事务／保存边界及原版参考见[PLAYER_TRADE](PLAYER_TRADE.md)。

四类佣兵雇佣／装备／喂药／复活费用服务已接，范围、原版依据及缺口见[佣兵](../characters/HIRELINGS.md)；全部商人／难度／折扣／品质／属性／容量组合与原服逐整数报价仍待对齐。
