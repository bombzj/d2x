## 分类与交叉引用

幕／区域是出现场所，MonStats是实际类型，AI是执行家族，rank是阶级，SuperUnique是固定身份；这些维度不能相加为“怪物总数”。固定金怪可能复用普通家族，幕首领不自动属于SuperUnique，拥有技能槽也不自动会施放。跨幕复用同一类型或程序只链接原规则页，在所属幕登记实际引用、参数与新增差异。

COMMON维护公共规则，ACT页维护类型覆盖，ELITES／BOSSES只维护各自专用差异；PRESENTATION维护原包和原图，技能算法归skills目录。任务生成／波次／奖励／通关记录链接任务专题，物件机关链接OBJECTS，不在怪物页复制任务执行或库存掉落算法。具体结构证据仍归[参考设计](../../architecture/REFERENCE_DESIGN.md#第一幕怪物公共计算依据)。
