# 怪物目录与归档边界

PD2编译身份、MonProp、召唤／佣兵和新增首领的差异与未知项统一见[PD2怪物基线](../../pd2/MONSTERS.md)；本目录维护公共怪物规则及原版覆盖。

更新：2026-10-18。本目录覆盖五幕普通怪物、精英／固定身份、首领、人口、表现及特殊单位；服务端与原D2GS共用客户端。分类入口齐备不代表当前MPQ全部MonStats身份、三难度、技能或AI已逐项实现／验收。

## 当前实施范围

先完成Act1至Act5常规战役怪物，包含三难度实际人口／任务固定目标、普通与首领AI、其实际技能／飞弹、相关环境控制、出生／死亡及卸载恢复。第一、第二幕也按当前代码复核，不沿用历史接线数量判定完成。每次只推进一个缺口，规则先读D2MOO，资源与参数取当前MPQ。

钥匙／红门高级事件暂缓，包括Lilith、UberDuriel、UberIzual及UberMephisto／UberDiablo／UberBaal和事件专用召唤链；已有代码保留，其缺口不阻塞常规战役完成。共享程序在常规战役需要时仍继续修复。常规牛类／牛王按第一幕既有覆盖复核，不与这些高级事件合并计算。

按当前代码登记实际类型、准入、行为、三难度及恢复／随机边界，同时列出原版依据和缺口；统一口径见[总计划](../../architecture/MULTIPLAYER.md#21-统一状态口径)。构建和自研运行不构成完成等级，暂缓高级事件不能用来掩盖常规战役缺口。

## 分类与交叉引用

幕／区域是出现场所，MonStats是实际类型，AI是执行家族，rank是阶级，SuperUnique是固定身份；这些维度不能相加为“怪物总数”。固定金怪可能复用普通家族，幕首领不自动属于SuperUnique，拥有技能槽也不自动会施放。跨幕复用同一类型或程序只链接原规则页，在所属幕登记实际引用、参数与新增差异。

COMMON维护公共规则，ACT页维护类型覆盖，ELITES／BOSSES只维护各自专用差异；PRESENTATION维护原包和原图，技能算法归skills目录。任务生成／波次／奖励／通关记录链接任务专题，物件机关链接OBJECTS，不在怪物页复制任务执行或库存掉落算法。具体结构证据仍归[参考设计](../../architecture/REFERENCE_DESIGN.md#第一幕怪物公共计算依据)。
