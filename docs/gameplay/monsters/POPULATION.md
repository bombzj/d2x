# MPQ人口计划与权威出生

更新：2026-10-16。本页唯一维护候选、固定身份、出生与房间调度边界；战斗规范见[COMMON](COMMON.md)，按幕覆盖见[怪物目录](README.md)。

原服和自研都由原单位分配消息驱动客户端，客户端不运行人口计划、出生或AI。服务端`population`执行实时密度、已迁入预设及任务／物件出生；`world/population`仅保留工具和未迁入身份的旧规划适配，hosting在调用它之前排除已迁入的DS1源序号，不重复占位或掷数。

## 数据与所有权

Levels的mon／nmon／umon、MonDen、MonUMin／Max，MonStats／MonStats2、MonPreset、SuperUniques、MonPlace和MonUMod决定候选、密度、族群、随从／精英及固定身份。hosting从当前MPQ准备不可变规则、真实spawn key及DS1节点；server/population调度准入，monsters实际安装实体并持有区域组件池与运行态。server不直接读表。

战斗范围、精英准入及限制统一见[第一幕](ACT1.md)与[精英](ELITES.md)。固定表记录不等于当前地图有刷新点，中立单位和不可击杀墙面发射器不混入敌对战斗池。缺规则或无法放置的人口保留暂缓身份，任务清场不能跳过这些单位。

MonStats2.spawnCol决定出生掩码，飞行／Wraith移动掩码不能替代它。原房间Populate、DS1单位／path nodes保留；空间选位、全区域初始化、房间激活与随机消耗仍有项目适配，不能宣称同种子逐单位等价。动态占位由权威服务端处理。

普通难度精英候选按`MONSTERCHOOSE_GetPresetMonsterId`在umon选择后直接返回，不执行PlaceSpawn替换或消耗该替换随机；噩梦／地狱仍走区域稀有度选择及PlaceSpawn。`gameplay/monsters/region_generation`以纯值目录按关卡ID顺序执行NumMon删选、首个RangedSpawn最多20次重抽及组件池投掷。宿主从当前MPQ准备缓存规则，实例与宿主调用同一算法，首次人口准入校验蓝图目录与组件初值。密度机会／稀疏门控使用游戏流，区域选型／精英预算及搜索使用活动房间流，族群、词缀、随从数量和姓名使用实际出生单位流。各阶段保留游标，异步规则准备不重掷、不推进游戏帧；这不代表完整全局初始化交错已经认证。

Levels的mon／nmon／umon现分别读取原25槽，在首个空／未链接MonStats条目处停止，不压缩空洞。Hit39另保留完整mon列表及isSpawn，不借用NumMon选择后的区域人口，也不改读噩梦／地狱的nmon。`nativeLevelSpawnClass`保留先随机索引、再前进一位才检查的顺序；只尝试首个合格类型，放置失败不换类型。

地图准备在房间瓦片完成后，按DRLG_CreateRoomForRoomEx多抽取一次原房间流，再以low／high=666准备独立活动房间种子；后续接缝选瓦片仍使用已前进的原房间流。生成数据只携带不可变初值，运行随机唯一归AreaStore::RoomState，RoomRandomLoan复验区域代次、房间随机revision及期望值。离区卸载清除运行流，重建使旧贷款失效；完整房间重建和原人口／对象对该流的消费顺序尚未迁完。

普通怪物与NPC的出生候选先从全局流创建实际单位种子，再完成组件选择、特殊DoomKnight组件抽样和HP投掷；HP使用单位流。非恶方按一人初始化，恶方人数包含已入场的死亡玩家及当前虚拟人数。组件池候选、Actor、房间登记和全局随机准备完成后一起安装，失败不提前消耗ID或组件池。四种原城镇居民跳过区域组件池。这只闭合上述出生阶段，MonProp／技能被动及初次AI等完整交错仍需后续迁移。

Hit39已接`monsters::prepareLevelSpawn`及独立NativeBirthPublication。非水面分支使用1.13c实际SpawnNormalMonster的半径3／6／…／15、随机周界起点、先移动后探测及首个成功即停止，复用同步动态碰撞和巢穴／石棺等附加占位检查；无落点仍发布已消费的房间随机。房间流、全局流、实际Actor、ID与组件候选共同发布，不借用巢穴子怪接口或玩家归属。缺原型、水面生成及附魔特殊出生明确未实现；不以沉沦魔或无操作认证该路径。固定D2MOO的SpawnNormalMonster函数体本身为空，普通落点分支因此以本地1.13c D2Game RVAEEF10移植，Hit39／列表选择依据RVA3BC00／EF6B0；字节材料在artifacts/missile-native-20261015/。本节新增源码未编译或运行。

## 显示与证据

活动房间按幕号升序、创建序号降序调度，对应原活动房间链头插。物件／NPC／预设怪物及环境陷阱共用DS1源序号，按SUNIT_SpawnPresetUnitsInRoom分两遍：物件先于NPC／怪物，各遍保留源序号。异步物件主题停留在Population阶段，不重复执行World／Social；NPC出生记录不由当前在场状态推导。`RoomPopulationLayout`的逻辑矩形、节点位及格索引已用于实时密度搜索和群组限制，地面数组用于水面出生；单地面元素的原越界边界明确暂缓。普通族群先完成领队自身party，再从其单位流决定剩余数量；精英／随从保留真实owner及头插minion链，BossXfer与UMod15死亡连锁分开。

实例启动分出NPCControl、QuestControl子流；石柱和日蚀用任务流，五类随机状态均可只读诊断。DS1普通预设、固定超级暗金、主要任务首领及吉得宾共用实时出生执行器。邪恶瓮按ObjectControl机会抽签，选区域首个具备行走模式的真实类型，在物件完成点推进同帧精英生成，不使用宿主预掷组或35帧陷阱延迟。精英基础生命／人数加成后在定点生命上执行UMod2及冠军修正，升级经统一Actor发布补装效果事件。完整逐修饰器跨随从链回调次序、首领特殊初始化和全部数值副作用仍待闭合。

任务出生请求可保存实际运行落点，异步推进和诊断使用同一坐标，不回退到宿主初始位置。Diablo使用真实类型及原预设出生的-1／5／10尝试参数。Init59余光在27帧对象事件中执行出生：蜘蛛森林的vilechild1只走一次普通出生，封印余光按实际坐标请求对应固定首领，放置失败每10帧重试。对象出生游标区分邪恶瓮精英与余光普通子体，后者不消费精英寻位／词缀随机；详细时序和未闭合边界见[物件](../world/OBJECTS.md#自然生成源码边界)。宿主旧questGroups预掷目录及任务出生回退已删除，缺真实规则明确返回未实现。

MonWndr游荡保留首个房间流`&0x7fff`、当前房间有客户端时退出、3%机会及每区域累计三只上限。当前MPQ的rogue2使用GoodNpcRanged，不是rogue3的TownRogue；读取真实友方阵营、远程攻击／动画和移动规则，不替换成敌人。出生成功才注册节点8头插顺序及计数，死亡移除节点。节点8主目标遍历以1.13c VA6FCD1EDD–6FCD1F4C的数组预读核实，节点9仍是独立替代目标链。房间创建批次触发与同步激活的完整调用交错仍未认证。

快照包含密度／预设／任务／物件出生阶段、原类型、领队、搜索次数、剩余数量及暂缓原因；游荡另列轮次、阶段、累计数量及节点8序号。2026-10-16当前工作区已完成Windows Release全目标构建与双包更新，鲜血荒地／邪恶洞穴的自然沉沦魔追击、攻击、受击／死亡及容器交互获有限观察；其中AI等待时旧随机提交造成的固定帧阻塞已修复并复验。包身份、截图、光照疑点和未覆盖范围统一见[运行包记录](../../development/BUILD_AND_RUN.md#运行包记录)，不认证全部出生程序或原版逐随机一致性。
