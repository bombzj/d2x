# MPQ人口生成与公共生命周期

更新：2026-10-17。本文维护自然人口与关联物件的当前实现、原程序依据和缺口。客户端只消费服务端单位分配与公开状态。规则准备在hosting，唯一自然生成执行器在server/population，实体构造、发布与恢复在server/monsters；旧world/population规划器、预掷出生队列及asset_tool人口模拟命令已删除。

## 自然生成工作总览

### 整体目标

以当前MPQ和原版1.13c程序还原自然怪物、野外宝箱／藏物、陷阱、祭坛／井及必要任务控制物件的生成：类型、位置、数量与预算、保护范围、次序、随机流、初始化、失败重试及卸载／恢复。D2MOO用于定位；差异和可疑转录须由同版本原程序核实。源码接入、编译、有限运行与原版逐随机等价分别记录。

### 工作范围

自然密度／族群／精英、DS1／MonPreset／MonPlace／SuperUniques、任务／物件关联出生、随机物件主题与房间生命周期均属此范围。伙伴和经济仅处理共享生成状态的必要边界；地形生成及客户端重建见[地图](../world/MAPS.md#对照与验证边界)，职业／伙伴功能仍由各专题维护。

### 注意事项与验收

原参数从当前MPQ准备；缺资源或证据明确暂缓。服务端不读取MPQ／设备／GPU，UI只读状态并提交命令。中立单位不可替换为敌人，唯一敌对替身为保留真实身份的沉沦魔。异步等待保留当前发生及候选，发布复验区域／房间代次、revision、身份和共享随机；过期候选不得覆盖新流。管理生成不认证自然分布，编译成功不认证原版一致性。既有包身份与有限观察统一见[运行包记录](../../development/BUILD_AND_RUN.md#运行包记录)，文档不携带持续构建／运行授权。

## 数据与所有权

Levels的mon／nmon／umon、MonDen、MonUMin／Max，MonStats／MonStats2、MonPreset、SuperUniques、MonPlace和MonUMod决定候选、密度、族群、随从／精英及固定身份。hosting从当前MPQ准备不可变规则、真实spawn key及DS1节点；server/population调度准入，monsters实际安装实体并持有区域组件池与运行态。server不直接读表。

战斗范围、精英准入及限制统一见[第一幕](ACT1.md)与[精英](ELITES.md)。固定表记录不等于当前地图有刷新点，中立单位和不可击杀墙面发射器不混入敌对战斗池。缺规则保留暂缓来源；尚未生成房间由coverage阻止提前清场，原程序已完成的无落点发生不伪造活怪物。

MonStats2.spawnCol决定出生掩码，飞行／Wraith移动掩码不能替代它。原房间Populate、DS1单位／path nodes保留；空间选位、全区域初始化、房间激活与随机消耗仍有项目适配，不能宣称同种子逐单位等价。动态占位由权威服务端处理。

允许的敌怪替身仍使用真实MonStats2.spawnCol／SizeX执行出生检查，保留水面出生及鸟巢、石棺、吸吮者巢和邪恶小屋的附加占位；精英升级不覆盖这些真实类型条件。邪恶之母的2格0x3c01附加检查只在实际出生执行，普通探测跳过，批量关联出生虽延迟构造仍执行该检查。MonPlace8的蛆虫女王按原调用设置不计数。普通交互NPC保留原坐标，准入时先原点、再4次环搜索；不在hosting中按自定义15格最近点挪动。非交互中立／友军预设保留真实身份，不替换为敌人；已支持GoodNpcRanged按真实友军AI安排初始事件。

传送点保护是出生选点规则，不是永久无怪物区域：密度领队／普通族群领队及所属原精英入口检查Warp坐标、TileInfo11和当前Levels.WarpDist，比较平方距离小于表值；固定预设、群组后续成员和移动各执行自身规则。随机物件另按DUNGEON_HasWaypoint跳过整个waypoint房间，两者不可混为通用避让半径。

普通难度精英候选按`MONSTERCHOOSE_GetPresetMonsterId`在umon选择后直接返回，不执行PlaceSpawn替换或消耗该替换随机；噩梦／地狱仍走区域稀有度选择及PlaceSpawn。`gameplay/monsters/region_generation`以纯值目录按关卡ID顺序执行NumMon删选、首个RangedSpawn最多20次重抽及组件池投掷。宿主从当前MPQ准备缓存规则，实例与宿主调用同一算法，首次人口准入校验蓝图目录与组件初值。密度机会／稀疏门控使用游戏流，区域选型／精英预算及搜索使用活动房间流，族群、词缀、随从数量和姓名使用实际出生单位流。各阶段保留游标，异步规则准备不重掷、不推进游戏帧；这不代表完整全局初始化交错已经认证。

Levels的mon／nmon／umon现分别读取原25槽，在首个空／未链接MonStats条目处停止，不压缩空洞。Hit39另保留完整mon列表及isSpawn，不借用NumMon选择后的区域人口，也不改读噩梦／地狱的nmon。`nativeLevelSpawnClass`保留先随机索引、再前进一位才检查的顺序；只尝试首个合格类型，放置失败不换类型。

地图准备在房间瓦片完成后，按DRLG_CreateRoomForRoomEx多抽取一次原房间流，再以low／high=666准备独立活动房间种子；后续接缝选瓦片仍使用已前进的原房间流。生成数据只携带不可变初值，运行随机唯一归AreaStore::RoomState，RoomRandomLoan复验区域代次、房间随机revision及期望值。离区卸载清除运行流，重建使旧贷款失效；完整房间重建和原人口／对象对该流的消费顺序尚未迁完。

普通怪物与NPC的出生候选先从全局流创建实际单位种子，再完成组件选择、特殊DoomKnight组件抽样和HP投掷；HP使用单位流。非恶方按一人初始化，恶方人数包含已入场的死亡玩家及当前虚拟人数。组件池候选、Actor、房间登记和全局随机准备完成后一起安装，失败不提前消耗ID或组件池。四种原城镇居民跳过区域组件池。鸟巢／石棺AI的时间起点保留真实准入帧，不延后到首次思考；普通中性敌怪首个AI事件在有客户端可见的相邻房间按出生后2帧安排，无客户端时保留AIdel及非正值15帧回退。客户端换房间先加新相邻房间、再移除旧房间；首位客户端登记重排中性及原特殊家族AI到2帧后，末位离开删除AI／再生事件。拓扑缓存重建保留实际客户端登记，不伪造重入。S1、召唤专用期限及完整全局事件交错尚未闭合。

MonProp从当前MonStats引用、MonProp难度六槽及Properties准备纯值，首个空属性结束。机会0不抽签，非零机会消费单位流；属性函数1／8／17按原范围、首值复用和参数规则消费同一流，固定范围不抽签。普通／NPC及公共召唤属性准入在初始技能后应用独立非扩展列表，保留原物品owner类型；Actor保存已掷列表，属性刷新复用，重新准入才重新掷值。真实类型缓存和允许的敌怪替身回填真实MonProp，不继承替身属性。当前MPQ使用的淡化、速率、压碎、火焰精通、击退、荆棘和致盲已接；其他属性函数明确拒绝，完整属性逐写回调、专用佣兵出生及所有召唤初始化仍未闭合。构建覆盖见运行包记录，完整运行行为尚未认证。

怪物动作开始及逐帧动画推进读取完整原生速率属性，MonProp与装备的攻速／施法速率不再只存在于属性列表；attackrate和other_animrate的原基值100转换成公共速率函数的增量，武器基础速度仍从选中武器投影读取。此处不认证全部模式、双持及召唤组合。

MonEquip的on-init记录由当前表按MonStats.inventory资格、连续类型段、首条oninit、等级门槛和原身体槽位准备。普通准入在MonProp后以PendingContent暂停等待宿主构造真实物品，调度通过公共isDeferred判断内容等待／容量背压；写入准备队列的接口不再声明const。MonEquip、召唤装备及商店共用prepareNativeItem的双种子／品质／生成入口，保留装备与商店各自的孔数和修复策略；选槽、种子、区域组件池和HP抽签由构造与返回校验共用纯算法。真实物品构造规则：选槽消费单位流，单选也抽签；实际物品分配与属性种子消费游戏双流值。返回校验单位／游戏流、物品身份区间、实际选中代码／槽位、等级和属性列表，出生发布才一起提交Actor、装备身份和随机终值。品质降级可合法重置物品nativeSeed，不将其误判为原分配种子不一致。当前血乌的sbw、飞行弯刀的scm均按原品质6构造稀有装备；强制装备绕过需求，不改变原鉴定状态，保留NOSELL和修复耐久。NOSOCKETS保留普通／超强品质的机会抽签但不自然加孔，不拒绝属性提供的孔数；NEVERETH不抽自然无形。近战／飞弹采样同一选中武器属性来源，词缀升级保留该来源。限定暗金按准备时冻结的整局记录生成，装备内及同批后续Actor读取前面已选项，Actor出生复验真实整局基线后登记。物件批次的地面与装备登记先合并再发布，不提前改变自身基线；跨来源生成次序造成的重复选择仍在发布前拒绝，不能认证全部联合生成。特殊物品光环尚不能在此出生通道联合发布时明确暂缓；创建失败副作用、全部装备回调及召唤专用MonEquip仍未闭合，不认证完整装备出生。乌鸦初始化在公共出生属性之后消费实际单位流：普通初始化与公共召唤各调用一次，保留两次投掷，以第二次结果决定环绕方向并缓存，属性重算不重掷。亚马逊召唤MonProp按运行难度准备。敌怪规则移除仅接受固定knock的旧MonProp闸门，统一由出生属性解释器决定支持范围；近战／投射物击退读取实际属性快照，不保留第二份类型布尔缓存。构建覆盖见运行包记录，完整运行行为尚未认证。

Hit39已接`monsters::prepareLevelSpawn`及独立NativeBirthPublication。非水面分支使用1.13c实际SpawnNormalMonster的半径3／6／…／15、随机周界起点、先移动后探测及首个成功即停止，复用同步动态碰撞和巢穴／石棺等附加占位检查；无落点仍发布已消费的房间随机。房间流、全局流、实际Actor、ID与组件候选共同发布，不借用巢穴子怪接口或玩家归属。缺原型、水面生成及附魔特殊出生明确未实现；不以沉沦魔或无操作认证该路径。固定D2MOO的SpawnNormalMonster函数体本身为空，普通落点分支因此以本地1.13c D2Game RVAEEF10移植，Hit39／列表选择依据RVA3BC00／EF6B0；字节材料在artifacts/missile-native-20261015/。构建覆盖见运行包记录，完整运行行为尚未认证。

## 显示与证据

活动房间按幕号升序、创建序号降序调度，对应原活动房间链头插。物件／NPC／预设怪物及环境陷阱共用DS1源序号，按SUNIT_SpawnPresetUnitsInRoom分两遍：物件先于NPC／怪物，各遍保留源序号。异步物件主题停留在Population阶段，不重复执行World／Social；NPC出生记录不由当前在场状态推导。`RoomPopulationLayout`的逻辑矩形、节点位及格索引已用于实时密度搜索和群组限制，地面数组用于水面出生；单地面元素的原越界边界明确暂缓。普通族群先完成领队自身party，再从其单位流决定剩余数量；精英／随从保留真实owner及头插minion链，BossXfer与UMod15死亡连锁分开。

实例启动分出NPCControl、QuestControl子流；石柱和日蚀用任务流，五类随机状态均可只读诊断。DS1普通预设、固定超级暗金、主要任务首领及吉得宾共用实时出生执行器。邪恶瓮按ObjectControl机会抽签，选区域首个具备行走模式的真实类型，在物件完成点推进同帧精英生成，不使用宿主预掷组或35帧陷阱延迟。精英基础生命／人数加成后在定点生命上执行UMod2及冠军修正，升级经统一Actor发布补装效果事件。完整逐修饰器跨随从链回调次序、首领特殊初始化和全部数值副作用仍待闭合。

NPCControl现供整局共享佣兵名单及普通／赌博库存的控制抽签；物品属性改用实际游戏双种子，内容准备返回的两条流经复验后发布。货架按MPQ Monster网格逐件放置，失败影响后续生成与随机消费；具体回退与重试见[经济](../items/ECONOMY.md)。佣兵奖励复用共享名单首个可用槽位，不再由宿主另掷名单；名单槽位与代次可只读诊断。完整商人初始化时点、物品创建失败副作用及NPC／任务交错尚未闭合，不能据这些消费者存在认证全局随机顺序。

任务出生请求可保存实际运行落点，异步推进和诊断使用同一坐标，不回退到宿主初始位置。Diablo使用真实类型及原预设出生的-1／5／10尝试参数。Init59余光在27帧对象事件中执行出生：蜘蛛森林的vilechild1只走一次普通出生，封印余光按实际坐标请求对应固定首领，放置失败每10帧重试。对象出生游标区分邪恶瓮精英与余光普通子体，后者不消费精英寻位／词缀随机；详细时序和未闭合边界见[物件](../world/OBJECTS.md#自然生成源码边界)。宿主旧questGroups预掷目录及任务出生回退已删除，缺真实规则明确返回未实现。
