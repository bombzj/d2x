# 技能树实施

## 原始数据与边界

运行时读取原 MPQ 的 `Skills.txt`、`SkillDesc.txt`、`CharStats.txt`、英文 TBL 字符串和七套 `skltree_*_back.dc6`／职业图标。当前资料片原表中，七个职业各有 30 个技能，分布在 `SkillPage` 1–3、`SkillRow` 1–6、`SkillColumn` 1–3。节点身份是原 `Skills.Id`，位置、图标和页签名称来自原表及原图，不维护抽取后的技能清单。用户提供的角色／法师技能树截图保存在忽略的 `artifacts/character-skill-layout-reference-cn.png`，仅用于核对版面。

女巫的传送、火弹、火球、冰弹、冰风暴、冰霜新星、闪电新星、静电力场已从原 MPQ 读取实际法力、等级伤害与弹体数据；暖气、火焰支配、闪电支配、冰冷支配读取原表被动参数。其余现有演示效果仍沿用 MVP 参数。技能树提供完整节点、升级点数、等级／前置门槛与施放入口；其他原技能尚无效果实现。未实现的主动技能在敌人目标上按普通攻击处理，非敌人目标不产生效果、消耗或假动画。除这四项外，被动技能只记录等级，效果暂缓。技能名称和页签使用英文原资源。

## 顺序

1. **已构建并核对 MPQ。** 从 MPQ 导入七职业技能与页签、图标和三页位置，校验节点数量、坐标及前置引用，形成只读内容目录。原表核对每职业 30 条且 30 个位置互不重复。
2. **已构建。** 玩家持有未用技能点和原技能等级；升级每级得一点，分配时核验职业、等级、前置与原最大等级，切换职业重置；同步快照。调试管道提供 `skills`、`learn-skill`、`reset-skills`，`Ctrl+Alt+T` 归还技能点。
3. **已构建并截图。** 使用每职业 MPQ 原背景绘制三页技能树、节点、等级、点数及页签；`T` 打开树，原位置点击分配，`--skills` 打开树。鼠标技能菜单只列当前角色可用的主动技能，左键遵循原 `leftskill` 字段。七职业共 21 页截图保存在忽略的 `artifacts/skill-smoke/`。
4. **源码修订，未构建或运行验收。** 已逐项核对下述八项女巫主动技能及四项被动，修正新星、命中图形、施法叠层、动作时序和部分数值规则。其余既有演示效果保留；本轮未扩充女巫其他技能，未编写测试脚本或用例，按用户要求未构建、运行游戏或打包。

每步完成后检查代码边界和对应文档，再开始下一步。未列出的技能的真实法力、动画、伤害、Buff、加成与一般装备授予技能留待完整技能系统；面板等级不暗示这些效果已实现。

## 出生通用动作与基础远程攻击

`CharStats.txt` 每职业的 `Skill 1` 至 `Skill 10` 列给出通用动作；`StartSkill` 仅女巫和死灵法师有值，原版由第一件初始装备提供，而非无条件送一点技能等级。当前源码按这些原列建立通用技能和初始装备授予关系，装备仍在手中且满足需求时可选择初始职业技能。普通攻击、Throw、Kick、Unsummon、允许的左手动作使用 MPQ 的原图标；卷轴／书本技能继续通过物品使用入口，辨识目标与书本施法暂缓。Kick 暂沿用普通攻击伤害；未有召唤物时 Unsummon 无目标。

点击左／右技能槽展开菜单，鼠标悬停目标图标后按 `F1–F8` 绑定到该鼠标键；之后单按对应功能键只切换技能，不立即施法。已绑定技能在菜单图标上标注功能键，绑定写入当前存档。调试管道的 `skills` 返回当前 MPQ 的技能 ID、前置及现有绑定；`bind-skill-hotkey` 使用同一会话规则，可用于快速检查。`grant-experience` 升级后按原门槛调用 `learn-skill` 可逐项解锁传送等技能。原操作依据[暴雪 Arreat Summit 控制说明](https://classic.battle.net/diablo2exp/basics/controls.shtml)。

普通攻击根据当前武器自动走近战或弓／弩射击；Throw 和 Left Hand Throw 使用对应已装备投掷武器。基础武器／投掷伤害、箭袋匹配、堆叠上限和弹体 ID 来自运行时 `weapons.txt`、`itemtypes.txt`；弹体速度、寿命与原 DCC 图形来自 `missiles.txt`。射击消耗匹配的已装备箭袋，投掷消耗武器堆叠；无弹药不产生攻击或假弹体。人物使用原攻击／投掷 COF 动画。伤害命中沿用目前已支持的普通怪物防御分支；攻击间隔和更完整的技能、弹体碰撞规则仍待核实。

## 女巫优先技能

### 逐项补全

当前按原技能 ID 顺序补全剩余技能，每项单独打包、简短运行验证和提交，未通过前不开始下一项。

| 技能 | 实现与包内验证 |
| --- | --- |
| 充能弹（38） | 原 `min(24,ln12)` 弹数、闪电协同和支配、D2MOO `PATH_ComputePathChargedBolt` 的方向选择与随机偏转序列、两格路径点及 77 帧寿命上限；逐段碰撞，命中消失并播放原 lightning 叠层。使用原 DCC、Units 调色板、中段动画循环和声音。包 `artifacts/sorceress-charged-bolt-20260926/` 已验证第 7 帧释放 3 颗、耗蓝、分叉轨迹、到期清除、真实怪物生命 12→8.2421875，以及 D2S 等级重载。精确原引擎碰撞掩码／尺寸、动态光照和逐像素对照仍未覆盖。 |

`content/sorceress_data.cpp` 从当前 MPQ 的 `Skills.txt`、`Missiles.txt`、`Overlay.txt`、`Sounds.txt` 和 `AnimData.d2` 生成类型化定义。玩法不读取 MPQ 或 GPU 资源。等级伤害、法力定点数、基础等级协同依据 D2MOO `D2Common/src/D2Skills.cpp`；武器授予等级与已分配等级叠加，装备加技能不计入基础等级协同。

### 共同施法与显示

- 原 `SC` 动作按当前武器查 `AnimData`；当前 MPQ 的女巫记录均为 14 帧、速度 256、索引 7 的动作标志 1。快速施法按 D2MOO `UNITS_UpdateCastAnimRateAndVelocity` 的递减收益及 175% 上限改变速率，不再统一使用 0.32 秒。法术到出手帧才扣蓝和生效；死亡、受击中断、换区域或读档清除未释放的动作。
- `Skills.castoverlay` 绑定火、冰、闪电或传送原叠层，附着施法者；新星的 `Missiles.ProgOverlay` 附着受击目标。叠层读取原帧数、偏移及 `AnimRate`，使用 Units 调色板。叠层客户端精确时间仍待画面对照，当前没有采用 Diablerie 的经验性 1.5 倍速。
- 弹体速度按 D2MOO `Missiles.cpp` 的 8.8 路径速度和 75% 系数换算；新星每 5 个游戏帧应用 `Accel`，受 `MaxVel` 限制。寿命读取 `Range/LevRange`。图形按弹体自身时间、`animrate/1024`、`AnimLen`、`LoopAnim` 播放，不再使用全局时钟或对非循环动画取模。
- 移除按亮度生成透明度的处理。非零 `Missiles.Trans` 参照 Diablerie 的弹体柔和叠加材质，以原像素色计算 `source * (1 - destination) + destination`；这不是把 `Trans=1` 解释为通用 50% alpha。此共享弹体绘制路径也影响原怪物／武器弹体，未做实机回归。
- `stsound` 在施法开始播放；`TravelSound` 在出手时每次施法播放一次，新星不会叠播 64 次；直射弹体碰撞时播放 `HitSound`，并生成独立计时的原命中动画。无 `AlwaysExplode` 的弹体寿命到期不再额外结算范围伤害。

### 未核实边界

此前八项主动技能修订时只核对源码、当前 MPQ 和编辑器诊断，后续物品审查已构建，但不能据此声称所有技能画面或逐帧行为已与原版等价。新增技能的逐项包内验证见上表。火球 `CltHitSubMissile1=fireexplosion2` 的额外散布图块、静电力场目标专属命中表现、弹体动态光照、精确原版碰撞尺寸／阻弹掩码、叠层完整客户端时序仍待核实；不凭空生成这些细节。

当前仅保存原版 D2S v96 的角色技能等级、选择和八个快捷键；弹体、叠层、未完成施法和怪物临时状态不写入磁盘。格式固定，支持度变化不升级格式，详见[存档说明](SAVES.md)。此前的技能树截图与存读档记录不代表本轮战斗效果已验收。
