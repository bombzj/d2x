# 技能树实施

## 原始数据与边界

运行时读取原 MPQ 的 `Skills.txt`、`SkillDesc.txt`、`CharStats.txt`、英文 TBL 字符串和七套 `skltree_*_back.dc6`／职业图标。当前资料片原表中，七个职业各有 30 个技能，分布在 `SkillPage` 1–3、`SkillRow` 1–6、`SkillColumn` 1–3。节点身份是原 `Skills.Id`，位置、图标和页签名称来自原表及原图，不维护抽取后的技能清单。用户提供的角色／法师技能树截图保存在忽略的 `artifacts/character-skill-layout-reference-cn.png`，仅用于核对版面。

女巫的传送、火弹、火球、冰弹、冰风暴、冰霜新星、闪电新星、静电力场已从原 MPQ 读取实际法力、等级伤害与弹体数据；暖气、火焰支配、闪电支配、冰冷支配读取原表被动参数。其余现有演示效果仍沿用 MVP 参数。技能树提供完整节点、升级点数、等级／前置门槛与施放入口；其他原技能尚无效果实现。未实现的主动技能在敌人目标上按普通攻击处理，非敌人目标不产生效果、消耗或假动画。除这四项外，被动技能只记录等级，效果暂缓。技能名称和页签使用英文原资源。

## 顺序

1. **已构建并核对 MPQ。** 从 MPQ 导入七职业技能与页签、图标和三页位置，校验节点数量、坐标及前置引用，形成只读内容目录。原表核对每职业 30 条且 30 个位置互不重复。
2. **已构建。** 玩家持有未用技能点和原技能等级；升级每级得一点，分配时核验职业、等级、前置与原最大等级，切换职业重置；同步快照。调试管道提供 `skills`、`learn-skill`、`reset-skills`，`Ctrl+Alt+T` 归还技能点。
3. **已构建并截图。** 使用每职业 MPQ 原背景绘制三页技能树、节点、等级、点数及页签；`T` 打开树，原位置点击分配，`--skills` 打开树。鼠标技能菜单只列当前角色可用的主动技能，左键遵循原 `leftskill` 字段。七职业共 21 页截图保存在忽略的 `artifacts/skill-smoke/`。
4. **此前已构建。** 女巫五项优先技能走下述 MPQ 原表分支；冰弹、暖气、火焰支配、闪电新星、闪电支配、冰冷支配和冰风暴已接入源码，尚未构建或运行验收。其余既有演示效果保留，未实现的主动技能仅在指向敌人时走普通攻击，指向空地无效果；其余被动技能只记录等级。本轮未编写测试脚本或用例。

每步完成后检查代码边界和对应文档，再开始下一步。未列出的技能的真实法力、动画、伤害、Buff、加成与一般装备授予技能留待完整技能系统；面板等级不暗示这些效果已实现。

## 出生通用动作与基础远程攻击

`CharStats.txt` 每职业的 `Skill 1` 至 `Skill 10` 列给出通用动作；`StartSkill` 仅女巫和死灵法师有值，原版由第一件初始装备提供，而非无条件送一点技能等级。当前源码按这些原列建立通用技能和初始装备授予关系，装备仍在手中且满足需求时可选择初始职业技能。普通攻击、Throw、Kick、Unsummon、允许的左手动作使用 MPQ 的原图标；卷轴／书本技能继续通过物品使用入口，辨识目标与书本施法暂缓。Kick 暂沿用普通攻击伤害；未有召唤物时 Unsummon 无目标。

点击左／右技能槽展开菜单，鼠标悬停目标图标后按 `F1–F8` 绑定到该鼠标键；之后单按对应功能键只切换技能，不立即施法。已绑定技能在菜单图标上标注功能键，绑定写入当前存档。调试管道的 `skills` 返回当前 MPQ 的技能 ID、前置及现有绑定；`bind-skill-hotkey` 使用同一会话规则，可用于快速检查。`grant-experience` 升级后按原门槛调用 `learn-skill` 可逐项解锁传送等技能。原操作依据[暴雪 Arreat Summit 控制说明](https://classic.battle.net/diablo2exp/basics/controls.shtml)。

普通攻击根据当前武器自动走近战或弓／弩射击；Throw 和 Left Hand Throw 使用对应已装备投掷武器。基础武器／投掷伤害、箭袋匹配、堆叠上限和弹体 ID 来自运行时 `weapons.txt`、`itemtypes.txt`；弹体速度、寿命与原 DCC 图形来自 `missiles.txt`。射击消耗匹配的已装备箭袋，投掷消耗武器堆叠；无弹药不产生攻击或假弹体。人物使用原攻击／投掷 COF 动画。伤害命中沿用目前已支持的普通怪物防御分支；攻击间隔和更完整的技能、弹体碰撞规则仍待核实。

## 女巫优先技能

`content/sorceress_data.cpp` 从运行时 `Skills.txt`、`Missiles.txt`、`Sounds.txt` 导入传送、火弹、火球、冰弹、冰风暴、冰霜新星、闪电新星、静电力场的原技能身份、`mana/minmana/lvlmana/manashift`、`EMin/EMax/EMinLev*/EMaxLev*/HitShift`、`EDmgSymPerCalc` 所指的基础技能协同，以及弹体 ID、速度、寿命、原 DCC 图形与施法声音。等级增量分段和法力定点算法依据本地 D2MOO `D2Common/src/D2Skills.cpp`；传送目的地／区域许可依据 `D2Game/src/SKILLS/SkillSor.cpp` 和运行时 `Levels.txt.Teleport`。玩法只接收类型化定义，不直接读取 MPQ。女巫初始法杖所授予的火弹与分配技能点叠加等级。

传送不再使用 MVP 的 22 格上限或 0.8 秒技能冷却；目标需在当前区域且为可站立格，原区域表的 `Teleport` 非零。传送两端效果读取运行时 `Overlay.txt` 的 Teleport 原图及帧数。火弹与火球按原导弹图飞行，火球命中半径取原 `Missiles.sHitPar1`；冰弹按原 `icebolt` 弹体命中结算冰冷伤害，冰弹与冰霜新星的冰冷时间按 `Skills.ELen` 和 `ELevLen1–3` 分段累加等级增量。冰霜新星使用原技能等级伤害及导弹速度／寿命推导的覆盖范围，视觉扩散改用 MPQ 原导弹图。静电力场的扣除比例与等级范围来自 `Skills.txt`，各难度生命下限来自 `DifficultyLevels.txt.StaticFieldMin`，原服务端分支参照 D2MOO `SkillSor.cpp`。当前施法动画时长仍沿用既有约 0.32 秒，冰霜新星伤害在施法时结算、原导弹图随后扩散；静电力场暂无专属命中图形。完整原版施法帧、逐弹冰霜新星命中、完整抗性规则及其他大师系加成尚未实现，不能视为逐帧等价。

暖气为原表被动技能，`passivestat1=manarecoverybonus`、`passivecalc1=ln12`；有效等级的基础 30% 与每级 12% 增量和装备回蓝百分比相加，再按角色法力上限计算恢复速度。技能点分配、重置、装备变化和读档时重算，不生成施法动作。火焰支配的原表 `passivestat1=passive_fire_mastery`，基础 30%、每级增加 7%；在技能协同后提高已实现的火弹与火球伤害，面板和施法共用结果。其他火系技能尚无原技能效果，不能以此视为已实现。冰弹、暖气、火焰支配与闪电新星尚未构建、运行或逐项战斗验收。

闪电新星按本地 D2MOO `SKILLS_SrvDo022_NovaAttack` 的 64 方向生成导弹，读取原 MPQ `nova` 的速度、寿命、图形、闪电伤害和 `NextDelay`（当前为 4 帧），导弹穿过目标并对同一目标限制短时重复命中；墙体仍阻挡导弹。该间隔仅属于本局区域战斗状态，不存入角色档。当前使用既有约 0.32 秒施法时长，未核对逐帧施法、命中范围和原版画面；尚未构建或运行验收。

闪电支配读取原表 `passivestat1=passive_ltng_mastery`、`passivecalc1=ln12`，基础 50%、每级增加 12%；在技能协同后提高已实现的闪电新星伤害，面板与施法共用结果。静电力场按当前生命比例结算，不接受此伤害加成；其他闪电技能仍待单独实现。闪电支配尚未构建或运行验收。

冰冷支配读取原表 `passivestat1=passive_cold_pierce`、`passivecalc1=ln12`，基础 20%、每级增加 5%；玩家冰系法术与武器冰伤命中时降低非冰免怪物的有效冰抗，冰冷时长使用相同抗性，冰抗达到 100% 的怪物不会被此被动击破免疫。原版穿透分支参照本地 D2MOO `SUnitDmg.cpp`。原表导弹 `Trans=1` 的图形在上传时按像素亮度生成透明度、用普通 alpha 合成绘制，覆盖冰霜新星与火弹的逐帧底色；其他 `Trans` 值暂不处理。此项视觉处理、冰冷支配与此前技能均尚未构建或运行验收；充能弹需要专门的 `PATHTYPE_CHARGEDBOLT` 路径，暂不以直线弹体代替。

冰风暴使用原表 `iceblast` 的伤害、协同、法力、冰冷帧数、弹体与施法声音；原导弹 `pSrvDmgFunc=4` 将冰冷时长转为冻结。普通怪物按 `MonStats.ColdEffect` 与 `DifficultyLevels.MonsterFreezeDivisor` 限制冻结；首领等目标只受冰冷减速，冰免不被冰冷支配击破，冻结期间暂停怪物行动并显示静止的冰色帧。当前沿用既有的弹体碰撞及约 0.32 秒施法时长，未核对逐帧施法与原版命中画面；尚未构建或实机验收。

当前源码保存初始物品授予技能、飞行中的实体／原技能弹体和八个技能快捷键，格式与规则版本见[存档说明](SAVES.md)，旧档不迁移。Windows Release 构建、七职业三页技能树截图、女巫技能选择菜单截图与快捷键存读档已冒烟。弓、弩、投掷及女巫技能的逐项战斗效果仍需后续实机验收。
