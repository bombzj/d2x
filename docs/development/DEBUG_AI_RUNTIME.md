# 调试AI执行契约

本页维护调度、动作交接、结果与恢复。命令／策略参数归[使用入口](DEBUG_AI.md)，路径算法归[导航结构](../architecture/CLIENT_NAVIGATION_REDESIGN.md)，任务步骤归[任务配方](DEBUG_AI_QUESTS.md)，字段格式归[诊断](DEBUG_AI_DIAGNOSTICS.md)。不另列缺陷或运行流水。

## 权限与状态

AI及子导航只持[online_actions.hpp](../../src/client/online_actions.hpp)的`OnlineObservation`、`IOnlineControl`、`IOnlineCombat`、`IOnlineInventory`及只读`RemoteTown`。允许直接查询客户端已有地图／碰撞／自然图元，不要求从画面识别；不读取Host、server-snapshot、本地角色档或隐藏预设，不发包、注入键鼠、更新副本或推进动画。

手动输入和AI共用RemoteControl／RemoteCombat／RemoteInventory的功能语义、资格与续接。前端负责副本投影、资源准备及调度，`OnlineObservation::read()`可读最新普通回执，不暴露RealmSession。缺功能入口时先提取共用功能，不能借诊断命令绕过边界。

## 调度与时钟

每轮先观察子导航、药剂、门、传送点、位移、任务库存和旅行结果，再仲裁新输入。动作契约由领域真实pending派生，不复制确认状态。优先消费实际结果及通行续接；危险避让、饮药、任务、补给与战斗仍受输入锁约束。

| 等待种类 | 计时与中断 |
| --- | --- |
| 父目标／补给、子导航总预算与移动无进展 | 面板、最小化、表现暂停、地图输入不可用及显式AI暂停停计；不靠换子目标重置局部预算 |
| 未受理输入 | 共用submitInput及物品／战斗适配，通常200ms复试、12秒执行预算；蓝门2秒后可转普通旅行。未受理不创建服务端pending |
| 已提交门、位移、药剂、库存、任务与旅行 | steady_clock现实期限继续推进；暂停中仍观察，已到结果先于超时处理，恢复后才提交下一输入 |
| 被动世界事件 | 执行时间预算；现场相关进展可按事件规则续期，仍受高层目标总预算约束 |

[decision_cadence.hpp](../../src/app/debug/decision_cadence.hpp)的常态周期为危险／段尾约40ms、交战80ms、稳定导航160ms、空闲250ms、被动观察最多500ms。结果变化可提前唤醒，通常合并40ms内观察，紧急变化可缩至20ms；后台结果在下一显示帧检查。周期不是发包间隔或硬实时保证，不改变25Hz玩法时钟。

RemoteScene按当前MPQ动画及FHR／FBR／FCR投影攻击、施法、受击、格挡和击退恢复；伤害包不等于受击动作。恢复期仍观察死亡、换区、库存和资源并允许合格药剂Use，暂停独立施法、换装、交互及重寻路；持续输入保留原语义。解除阻塞的首次前端观察直接唤醒，缺动画保留未知，不编时长。子导航同时暂停输入与无进展计时，已提交请求现实期限不变。

库存Take／Equip等另等本人动作回包稳定600ms；仅无动画投影时使用施法后1500ms后备。技能书Use不套此等待。它是调试输入节奏，不认证宿主将全部技能执行视为库存忙碌的原版一致性。

## 提交与结果

请求受理、位移、菜单、物品归属和任务完成各自确认。未知结果不重放消费、合成、插杖或领奖；迟到回包按身份、请求序号及场景代次复验。普通交易、技能、物品及NPC门禁仍由客户端功能层裁决。

- 任务物件的新0x13提交凭据匹配目标及代次后立即登记，不等子导航completed；02／04接近不计操作。`operationPending`保留移动／技能／交互／菜单输入，直到同一指派模式改变、对应界面或任务结果出现，药剂仍可用。效果到达后再进入可防御的剧情等待。
- NPC开窗完成只证明该次会话曾打开。治疗后同商人可续菜单，换商人先正常关闭；新会话失效旧完成子目标。实际货架、资源和私人位分别确认。
- 自动对白31在台词开始时由普通功能提交，AI只按显示时长结束当前条，等待续接；服务和旅行等台词结束。Q面板与AI共用私人任务刷新，同局未返回查询合并，关闭后可再查；回执不是完成位。
- 已提交跨幕NPC旅行保留移动／技能／交互／菜单占用至目的场景和任务结果确认。结束对白不释放旅行，药剂和观察继续；不重发未知旅行服务。
- 库存工作从收纳／合成接收到所有物品、Cursor及方块收妥期间独占事务。灌注取材料、插杖租约也有保护；仅“赶往目标”不锁战斗。工作流契约见[库存模块](../modules/INVENTORY.md#客户端物品工作流)。

## 通行与事件

[ai_events.cpp](../../src/app/debug/ai_events.cpp)的PassageWait统一普通门、任务入口、自有蓝门及补给回程。初等后每1秒复试，实际成功立即推进，不重置总期限。活动接近先于攻击；停稳等换场时可单次防御。卷轴创建只复查已有请求／真实门户，不重复未确认消费；超时且未使用门户时保留未知，改用合法普通路线或传送点。

门户旅行提交后收到本人新0x15，仍在来源场景、原门户指派未变且已停在范围外时，可恢复正常接近；每来源／指派最多两次。换门、换区和同层传送台不借此重放。机关激活与旅行分开；OPERATING不是OPENED，静默ENDANIM复用客户端显示／碰撞的MPQ期限投影，不写副本。

WorldWait只负责实际入口、NPC、首领、遭遇结束或终局的被动观察，与已提交QuestPending分离。第一次实际见证位置固定为锚点，见证离场不拖动锚点；配方提供完成条件、相对偏移和等待覆盖，公共等待器不硬编码幕ID。

观察站位在配置环带内筛选已知地面、观察射线、危险及暂缓证据，再由共用路线选择；不限人物一次传送范围。Partial只保留最终objective，不将中继当作到场。接近确认后锚定；战斗／避险保留现场范围，被打散可正常返回，补给可中断被动等待。待事件及锚定阶段不插入可选传送点激活。

遭遇进展仅含相关新敌对指派、跟踪死亡或净生命新低，最多跟踪256个身份；玩家移动、敌人一直存在、退订及无关包不续期。王座阶段声音只唤醒观察，真实状态／门户仍决定通行；专用条件归[第五幕配方](DEBUG_AI_QUESTS.md#第五幕任务配方)。

## 战斗与路段交接

选敌归[ai_combat_targets.cpp](../../src/app/debug/ai_combat_targets.cpp)，主攻／群攻／备用及提交归[ai_attack_strategy.cpp](../../src/app/debug/ai_attack_strategy.cpp)，静电场／光环／冰甲归[ai_combat_support.cpp](../../src/app/debug/ai_combat_support.cpp)，站位归[ai_tactics.cpp](../../src/app/debug/ai_tactics.cpp)，危险响应归[ai_defense.cpp](../../src/app/debug/ai_defense.cpp)。

出城按配置主／备用顺序选满足有效等级、手别与装备类型的主动技能，整趟锁定；缺蓝、冷却和目标变化不改出城选择。未指定技能时按已学Frozen Orb、Fire Ball、Zeal、Attack选择。实际输入仍检查资源／状态／目标。非首领群体达到策略阈值时优先可用groupSkill，群体变小或无净进展后恢复主攻；清路群攻不要求贴身拥挤阈值。

| 场景 | 接战与交还 |
| --- | --- |
| Hunt／Clear／到场Encounter | 必要目标，不能暂避后宣称完成；SearchDrop可交战但不要求杀光所有遭遇者 |
| 普通赶路 | defensive仅处理实际压力，压力解除释放可选交战；具备Teleport时跳过沿途可选战斗 |
| 步行清路 | 仅接收当前路段真实阻挡身份；可原生绕行则绕，阻挡解除即续行，不清屏 |
| 传送途经 | 下一落点附近达到拥挤阈值时，选更短且向前的合法安全站位；确认位移后单次技能，再恢复旅行；同落点只中断一次 |
| 进入战斗 | 当前脚点合格立即攻击，否则合法局部移动、确认落点后交回原战斗目标 |
| 停留等待 | 原任务先推进；无新操作且输入允许时，远程对waitDefenseRadius内射线可达敌人原地单次防御，不追怪、不取消导航、不等全歼 |

路段任务由[ai_route_execution.cpp](../../src/app/debug/ai_route_execution.cpp)持有意图和预算。清路暂停原子行走，闪避替换旧撤退／换位；失去可攻击阻挡时恢复原路线。补弹事务可接管，完成后续原任务；禁用自动补给也不放弃已开始的装备事务。传送途经的Resume只去重，不占输入。等待防御结束即挂起战斗，不发Stop打断已受理攻击，也不让残留目标阻止导航位移。

接敌使用真实身份、当前技能射程／射线及可站立地面，怪物中心不是落脚点。远程射线复用MPQ飞弹链接和nativeMissileContactMask；普通1／2／3／5／6类型检查屏障4，类型8另查墙1，近战保留墙检查。原MonStats2.isAtt、潜地／离地模式等资格沿普通RemoteCombat，不靠无伤害猜免疫或按怪物ID屏蔽。

效果观察从首次实际受理攻击开始，仅同指派生命比例新低计净进展；回升、命中标志、受理次数都不证明伤害归因。无反馈保留未知。已复查射线仍无进展时按配置尝试合格备用，不循环重试已用策略；技能正延迟不计无进展预算，战术位移本身也不计伤害进展。策略随指派变化或实际死亡后复活重置。

无安全路线或策略耗尽时，必杀／清场／仍阻挡的清路明确失败；沿途非必杀可暂避10秒，并须本人离开或目标实际移动后再试。临时释放目标保留同指派策略并补偿非交战时间，不改变原生请求期限。

远程风筝先评估原地安全，候选须改善敌人间距或危险余量，最多四个步行候选进入后台求路。沿途已知、直线可走、无危险且不缩短敌人距离时，才比较当前移速与实际Teleport动画耗时选择步行；变更FCR、装备、外观或状态会失效旧时长。跨墙、危险脱困和射线恢复不受此比较限制。

后撤兼顾生命、近期掉血和剩余药剂，16向已知路线择安全点，最多2秒、至少4秒间隔。危险预测只读实际重建弹体的速度、ClientCol／Size和寿命，并保留已核首领持续效果及不可攻击敌对来源的距离避让；不是服务端未来轨迹或伤害预判。普通非实体怪物不自行生成持续危险区。

静电场在主攻首次施放后的冷却空档穿插，使用当前MPQ有效半径与难度比例下限，不额外贴近、不延后主攻。普通怪物原包仅有生命比例，`targetAbsoluteLife=null`，不能以MonStats基础值假装现场绝对HP。普通交战保持同技能／目标时沿repeat，清路与途经单次输入；持续技能沿channel分类，动作／冷却和费用均由原功能入口裁决。

## 药剂与补给执行

当前资源读原包，上限借普通HUD投影，未知则不猜阈值。只取本人腰带／背包已解码药剂；MPQ分类先区分回复药，再红／蓝药，普通恢复状态期间避免叠喝，危急生命例外。强瓶排序只用表恢复量提示，不在客户端结算恢复。

Use冻结物品及请求序号，实际消费与随后12秒内恢复状态／资源增长分别记录；瓶子消失不等于恢复，超时未知不重用。药剂仅占库存输入，观察与其他动作仍按合同仲裁。

补给在无冲突未决操作时插入，保留原目标执行余量，独立600秒预算。城镇先治疗，再药剂、书页及弹药；出城前生命低于90%才找治疗者，已观察治疗完成不会因稍后掉血被否认，12秒无结果明确失败。第二幕Lysander不治疗，使用Fara／已指派Atma，回城书另找Drognan；其他幕按正常商人身份及货架。

采购通过交谈、TradeOpen、报价和Buy，资金不足不免费补齐。Shift药剂采购按腰带家族／空列、可负担价格和配额决定；书页按Misc.maxstack及实际页数确认。有界货架超时仅在本商人开店待定且无购买未决时重谈一次。每次买卖都等成交和库存增长。

弹药按装备及ItemTypes.Shoots／Quiver匹配，储备计已装备与背包；活动副手腾空后正常Take／Equip换弹并等位置确认，箱内不计随身储备，无后备交回补给。

野外资源不足或已观察首领压力可触发补给，回城阶段优先脱离，饮药及紧急避险继续。回程不固定优先旧蓝门：城内重新观察任务条件，统一比较普通路线、真实门户和合法传送点；普通区域目标仍返回其目的地，无区域的局部目标保留补给前区域。显式restock留城，要求enabled及buy开启。旅行评分细节只维护在[导航结构](../architecture/CLIENT_NAVIGATION_REDESIGN.md#旅行与传送点)。
