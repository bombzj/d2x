# 腰带与物品使用（第 4 项）

## 操作

| 输入 | 行为 |
| --- | --- |
| `1`～`4` | 饮用对应腰带列中最下方的物品；无物品或尚未实现使用效果时提示 |
| `B` | 展开／收起腰带；打开包裹时自动显示全部可用行 |
| 右键点击包裹／腰带中的药水 | 饮用该瓶；拖动或拆分过程中右键仍是取消 |
| `Shift` 点击包裹药水／卷轴 | 优先填充同类腰带列，再找空列；不改变其他列 |
| `Shift` 点击腰带物品 | 自动移入包裹 |
| 在包裹与腰带格间拖动 | 移动或交换；双方都必须适配目标容器 |
| 右键／`Shift` 点击包裹里的腰带装备 | 穿戴或替换腰带；也可拖到原版装备栏中央的腰带槽 |
| 右键／`Shift` 点击已穿戴腰带 | 脱下，放入包裹 |
| `F1`～`F8` | 悬停技能菜单图标绑定左右鼠标技能；之后按键切换技能，数字键留给腰带 |

`Ctrl+F2` 旅行菜单打开时，数字 `1`～`4` 仍选择场景，不会饮药。暂停、帮助、旅行菜单、死亡状态下不能饮药。鼠标位于包裹／腰带上时，右键不会穿透到世界施法；拖动期间不会使用腰带快捷键。

## 容量、拾取与补位

基础腰带有 4 格；Sash、Light Belt 为 8 格，Belt、Heavy Belt 为 12 格，Girdle 为 16 格。这五种普通腰带已加载美术资源，掉落执行尚未接通；，使用对应的 MPQ 图标和落地动画。目录中的五种扩展等级腰带定义有 16 格元数据，当前不加入掉落池，也未实现其装备属性。

腰带是四列、从下往上存放的容器，逻辑 `y=0` 为准备行。自动放入优先查找同类列：生命药水各等级为一类、法力药水各等级为一类、两种回复药水为一类，其他物品按定义代码匹配。满列不会挤出原物品。手动拖放允许混合列。

拾取生命／法力药水时可自动占用空列；其他腰带适用物品只自动进入已有同类列。不能自动入带就使用原有包裹拾取事务；两处都不能容纳时留在地面。`Shift` 点击是明确的整理操作，允许为回复药水、卷轴等使用空列。

饮用后删除实例，同一列其余物品向下补齐，其他列保持原样；也可直接右键饮用展开行中的药水。手动整理产生的空洞不会使快捷键失效，快捷键始终选择该列最低的物品。

换小腰带或脱下腰带时，超出新容量的物品自动尝试放入包裹。预先在库存快照上规划装备交换、溢出物品位置和版本变化，全部成功才提交；包裹没有足够的完整空格时拒绝整笔操作。不会删除溢出物品，也不会自动扔到地面。界面显示的容量始终读取真实容器。

## 药剂效果及复刻边界

LoD 运行时从原 MPQ `misc.txt` 识别五级生命、五级法力、回复、全面回复及耐力药剂。物品美术按实际实例的 `invfile`／`flippyfile` 路径载入；旧自定掉落权重已停用。试玩 1.04 的 `misc.txt` 缺少这些效果字段，该版本药效暂缓。

当前 LoD 表的基础生命恢复量为 30／60／100／180／320，野蛮人按原引擎职业倍率得到 60／120／200／360／640；法力为 20／40／80／150／250。回复药剂的 35%／100% 与耐力药剂的 750 帧持续时间也来自 `misc.txt`。效果执行仍须统一验收。

生命和法力在固定 25 Hz 玩法更新中恢复。同一种资源的连续药剂排队生效，不叠加恢复速度；达到上限会丢弃未使用的恢复量，满值时仍可饮用并消耗药水。持续时间现按 LoD `misc.txt` 各物品的 `len` 帧换算，不再给所有生命药剂固定 8 秒。混用与属性影响下的双倍恢复概率仍未验证为原版逐帧等价行为。

初始物品代码、数量与装备位置从 MPQ `charstats.txt` 的野蛮人行读取；当前 LoD 行给出四瓶生命药剂、城镇传送与辨识卷轴，以及武器／盾。旅行保留药效、库存和装备；死亡、`R` 或阿卡拉治疗清除持续药效，后两者恢复角色但不补发消耗品。

背包中的回城卷轴和有页数的回城书可使用；鉴定卷轴／书通过右键选择未鉴定物品。解毒、解冻、投掷药剂及其他未实现的物品效果会明确拒绝，数量不变。腰带穿戴校验原表需求并改变容量；直接加值词缀已在角色属性阶段接入，其他效果仍只展示。没有雇佣兵喂药功能。私人储物箱和赫拉迪克方块的存取已实现；方块合成未实现。

## 扩展入口与验证范围

`items/belt.cpp` 负责列选择、容量事务和饮用后的库存补位；`potions.hpp/.cpp` 定义药效及固定步更新；`session_consumables.cpp` 负责访问校验、消耗与应用效果。穿戴容器 `BeltEquipment` 仍使用唯一物品位置，普通移动／交换接口不能绕过装备事务修改它。

`EquipBelt`、`UseItem`、`UseBeltColumn` 是意图命令，权限由会话生成；`ItemUsed` 和 `BeltEquipped` 驱动音效。药效状态属于 `PlayerState`，MPQ 纹理属于 `SceneAssets`，以后存档保存前者及库存，不保存 GPU 对象。

只进行 Windows C++ 构建、普通启动、原版资源及单个精简 MPQ 的截图检查和代码审查。未编写测试脚本、测试用例或专用交易程序；实际饮药、换带、拖拽未做交互自动化验证。Linux 保持标准 C++20／CMake 接口，但本机未实际编译运行 Linux 版本。
